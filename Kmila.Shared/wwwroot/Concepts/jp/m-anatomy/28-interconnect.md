# 配線と I/O

**配線（インターコネクト）**はセル間のプログラマブルな結線です：**配線チャネル**、交点でそれらをつなぐ**スイッチボックス**、端でピンへ届く **I/O ブロック (IOB)**。

<div class="lesson-figure"><iframe src="/_content/Kmila.Shared/anatomia/28-interconnect.html" title="インタラクティブな図" loading="lazy"></iframe></div>

信号は I/O ブロックから、チャネルに沿い、スイッチボックスを通って CLB へ配線されます——点灯した経路です。スイッチボックスをプログラムすることが、設計をつなぐことです。

FPGA の面積と遅延の大半は、実は論理ではなく**配線**です。配置配線がどのセルを使いどう結ぶかを決めます——合成のあとの、遅くて巧妙な工程です。
