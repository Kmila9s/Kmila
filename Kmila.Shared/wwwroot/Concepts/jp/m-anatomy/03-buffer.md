# バッファ (BUF)

**バッファ**は入力をそのまま出力へ写します（Y = A）。論理は変えません——信号を**駆動**するために使います。信号を強めたり、制御された遅延を加えたりします。

<div class="lesson-figure"><iframe src="/_content/Kmila.Shared/anatomia/03-buffer.html" title="モジュール台の上のインタラクティブな論理ゲート" loading="lazy"></iframe></div>

カーソル（または矢印キー）を動かして、すべての入力の組み合わせを順に試します。モジュールが結果を計算し、出力ランプ **Y** が真理値表どおりに点灯します。

VHDL では：

```vhdl
y <= a;
```

これは純粋な**組合せ**論理です。出力は現在の入力だけで決まり、クロックもメモリもありません。 出力に反転バブルが無いことに注目してください——NOT ゲートとの唯一の違いです。
