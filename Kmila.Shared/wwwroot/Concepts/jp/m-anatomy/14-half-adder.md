# 半加算器

**半加算器**は 2 ビット A と B を足し、**和** S と**桁上げ** C を出します。

<div class="lesson-figure"><iframe src="/_content/Kmila.Shared/anatomia/14-half-adder.html" title="モジュール台の上のインタラクティブな組合せ回路" loading="lazy"></iframe></div>

カーソル（または矢印キー）を動かして、すべての入力の組み合わせを順に試します。入力プランジャがビットを設定し、モジュールが計算し、出力ランプが点灯し、**表の現在行がハイライト**されるので、関数をそのまま読み取れます。

VHDL では：

```vhdl
s <= a xor b;   -- sum
c <= a and b;   -- carry
```

これは純粋な**組合せ**論理です。出力は現在の入力だけで決まり、クロックもメモリもありません。 和は **XOR**、桁上げは **AND**：半加算器はまさにこの 2 つのゲートを並べたものです。桁上げ入力がないので最初の段だけです。
