# D フリップフロップ

**D フリップフロップ**は 1 ビットを記憶し、クロックの**立ち上がりエッジ**で取り込みます。Q はエッジの瞬間の D の値を取り、次のエッジまで保持します。 これはラダー最初の**順序**素子です：ゲートと違い、その出力は現在の入力だけでなく、クロックと自身の過去に依存します。

<div class="lesson-figure"><iframe src="/_content/Kmila.Shared/anatomia/19-d-ff.html" title="ライブなタイミング図付きのインタラクティブな順序素子" loading="lazy"></iframe></div>

この素子は**記憶**を持ちます。タイミング図を見てください：上でクロック（**CLK**）が刻み、出力 **Q** はクロックのときだけ変化し——その間は入力が何をしようと値を**保持**します。Q は色で描かれ、破線がクロックエッジを示します。

VHDL では：

```vhdl
process (clk)
begin
  if rising_edge(clk) then
    q <= d;          -- sampled on the edge
  end if;
end process;
```

D フリップフロップは同期設計の**基本**部品です——レジスタもパイプライン段も状態ビットも 1 個以上の DFF です。D の前に MUX を置けばロードイネーブルや同期リセットになります。
