# エンコーダ

**エンコーダ**はデコーダの逆です：ワンホット入力（一本が有効）に対し、その線の**二進アドレス**を出力します。

<div class="lesson-figure"><iframe src="/_content/Kmila.Shared/anatomia/13-encoder.html" title="モジュール台の上のインタラクティブな組合せ回路" loading="lazy"></iframe></div>

カーソル（または矢印キー）を動かして、すべての入力の組み合わせを順に試します。入力プランジャがビットを設定し、モジュールが計算し、出力ランプが点灯し、**表の現在行がハイライト**されるので、関数をそのまま読み取れます。

VHDL では：

```vhdl
a <= "11" when i3 = '1' else
     "10" when i2 = '1' else
     "01" when i1 = '1' else
     "00";
```

これは純粋な**組合せ**論理です。出力は現在の入力だけで決まり、クロックもメモリもありません。 **優先**エンコーダは複数の有効入力を最上位を採って解決します——一つの要求を選ばねばならない割込みコントローラに便利です。
