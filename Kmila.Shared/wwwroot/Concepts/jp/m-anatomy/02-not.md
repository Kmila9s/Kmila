# NOTゲート (インバータ)

**NOTゲート**は最も単純な論理です。入力ひとつ、出力ひとつ、そして出力はつねに入力の**反対**になります——0 を入れれば 1、1 を入れれば 0 が出ます。

**カーソルを動かして**入力 **A** を 0 か 1 に設定します。図は腕の長さが等しいシーソーです。入力（A）を押し下げると出力（Y）が上がり、その逆も同様——等しく反対に動きます。出力側の小さな丸が反転のバブルです。

## バブル

出力側のその**丸**が*反転バブル*で、あらゆる回路図における NOT の記号です。ゲートの出力でこれを見かけたら（NAND、NOR、XNOR…）、意味はいつも同じ――「そのうえ、反転する」。

| A | Y |
|---|---|
| 0 | 1 |
| 1 | 0 |

VHDL ではインバータは `not` 演算子です：

```vhdl
y <= not a;
```

これは純粋な**組合せ**論理です。出力は現在の入力だけで決まり――クロックもメモリもありません。入力が変われば、わずかな伝搬遅延のあとで出力が反転します。
