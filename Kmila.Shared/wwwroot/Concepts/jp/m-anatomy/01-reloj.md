# クロック：回路の鼓動

**クロック**（clock）は、すべてのテンポを刻む信号です。固定周波数で 0 と 1 を交互に繰り返す**方形波**です。ゲートやフリップフロップを学ぶ前に、動く様子を見ておくと理解が進みます。

**カーソルを左右に動かす**と周波数が変わります。歯付きバーは波形を形にしたものです。追従子は各歯に乗り上げ（レベル **1**）、各溝に落ち（レベル **0**）、はずみ車が一定の速度を保ちます。表示には現在のレベルと周波数が出ます。

## 本当に大切なのは：エッジ

順序回路——フリップフロップ、レジスタ、カウンタ——はクロックの*レベル*ではなく、その**エッジ**に反応します。0 から 1 へ跳ぶ瞬間（**立ち上がりエッジ**）や 1 から 0 へ跳ぶ瞬間（**立ち下がりエッジ**）です。VHDL では：

```vhdl
process (clk)
begin
    if rising_edge(clk) then
        q <= d;          -- 立ち上がりエッジでちょうど取り込まれる
    end if;
end process;
```

- **周波数**——毎秒のサイクル数（Hz）。はずみ車が速いほど波は詰まります。
- **周期**——1 サイクル全体：歯ひとつと溝ひとつ。
- **デューティ比**——周期のうち 1 の割合；ここでは 50%。
