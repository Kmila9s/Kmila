# マルチプレクサ (MUX)

**マルチプレクサ**は複数のデータ入力のうち一つを出力へ通します。**選択**線 **S** がどれを通すか決めます：ここでは S = 1 なら Y = D1、そうでなければ D0 です。

<div class="lesson-figure"><iframe src="/_content/Kmila.Shared/anatomia/10-mux.html" title="モジュール台の上のインタラクティブな組合せ回路" loading="lazy"></iframe></div>

カーソル（または矢印キー）を動かして、すべての入力の組み合わせを順に試します。入力プランジャがビットを設定し、モジュールが計算し、出力ランプが点灯し、**表の現在行がハイライト**されるので、関数をそのまま読み取れます。

VHDL では：

```vhdl
y <= d1 when s = '1' else d0;
```

これは純粋な**組合せ**論理です。出力は現在の入力だけで決まり、クロックもメモリもありません。 VHDL の `if/then/else` や `case` は合成後みな MUX になります。レジスタのロードイネーブルも同じで、MUX が新しい値と古い値の保持を選びます。
