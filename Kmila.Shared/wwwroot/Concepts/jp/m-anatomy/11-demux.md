# デマルチプレクサ (DEMUX)

**デマルチプレクサ**は MUX の逆です：一つの入力 **D** を複数の出力のうち一つへ通し、**選択**線 S が選びます。

<div class="lesson-figure"><iframe src="/_content/Kmila.Shared/anatomia/11-demux.html" title="モジュール台の上のインタラクティブな組合せ回路" loading="lazy"></iframe></div>

カーソル（または矢印キー）を動かして、すべての入力の組み合わせを順に試します。入力プランジャがビットを設定し、モジュールが計算し、出力ランプが点灯し、**表の現在行がハイライト**されるので、関数をそのまま読み取れます。

VHDL では：

```vhdl
y0 <= d when s = '0' else '0';
y1 <= d when s = '1' else '0';
```

これは純粋な**組合せ**論理です。出力は現在の入力だけで決まり、クロックもメモリもありません。 選ばれなかった出力は 0 のままです。デコーダとデマルチプレクサは近い親戚で、demux はデータ入力が有効出力をゲートするデコーダです。
