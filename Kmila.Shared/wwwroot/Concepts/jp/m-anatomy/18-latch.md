# D ラッチ

**D ラッチ**は 1 ビットを記憶します。イネーブル（ここではクロック）が高い間は**透過的**で Q は D に従い、低くなると最後の値を**凍結**します。 これはラダー最初の**順序**素子です：ゲートと違い、その出力は現在の入力だけでなく、クロックと自身の過去に依存します。

<div class="lesson-figure"><iframe src="/_content/Kmila.Shared/anatomia/18-latch.html" title="ライブなタイミング図付きのインタラクティブな順序素子" loading="lazy"></iframe></div>

この素子は**記憶**を持ちます。タイミング図を見てください：上でクロック（**CLK**）が刻み、出力 **Q** はクロックのときだけ変化し——その間は入力が何をしようと値を**保持**します。Q は色で描かれ、破線がクロックエッジを示します。

VHDL では：

```vhdl
process (en, d)
begin
  if en = '1' then   -- transparent while enabled
    q <= d;
  end if;
end process;
```

**レベル感応**なので、ラッチはクロックの 1 フェーズのあいだずっと透過的で、その窓での D のグリッチも通ります。だから同期設計はエッジトリガのフリップフロップを好みます。
