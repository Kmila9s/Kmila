# デコーダ

**デコーダ**は n ビットのアドレスを**ワンホット**出力に変えます：2ⁿ 個の出力のうちちょうど一つが 1 になり、それはアドレスが指すものです。

<div class="lesson-figure"><iframe src="/_content/Kmila.Shared/anatomia/12-decoder.html" title="モジュール台の上のインタラクティブな組合せ回路" loading="lazy"></iframe></div>

カーソル（または矢印キー）を動かして、すべての入力の組み合わせを順に試します。入力プランジャがビットを設定し、モジュールが計算し、出力ランプが点灯し、**表の現在行がハイライト**されるので、関数をそのまま読み取れます。

VHDL では：

```vhdl
with a select y <=
  "0001" when "00",
  "0010" when "01",
  "0100" when "10",
  "1000" when others;
```

これは純粋な**組合せ**論理です。出力は現在の入力だけで決まり、クロックもメモリもありません。 デコーダはアドレス線を駆動します：メモリ、7 セグメント表示、命令ディスパッチはこうして多数の中から一本を選びます。
