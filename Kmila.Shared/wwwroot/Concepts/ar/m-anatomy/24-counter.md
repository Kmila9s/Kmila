# عدّاد

**العدّاد** يضيف واحدًا إلى قيمته المخزّنة عند كل حافة، فيمرّ 0 و1 و2 … ثم يلتفّ. إنه مسجّل مع جامع +1 معاد تغذيته.

<div class="lesson-figure"><iframe src="/_content/Kmila.Shared/anatomia/24-counter.html" title="كتلة تتابعية متعددة البتات تفاعلية تقودها الساعة" loading="lazy"></iframe></div>

تنبض ساعة حرّة على اليسار؛ وتظهر حالة الـ4 بتات كصفّ من **مصابيح Q** وكقيمة حيّة (عشري + ثنائي). عند كل حافة ساعة تتحدّث الحالة؛ وبينها تُحتفظ.

في VHDL:

```vhdl
process (clk)
begin
  if rising_edge(clk) then
    q <= q + 1;   -- increment every edge
  end if;
end process;
```

العدّادات تقيس الزمن والأحداث، وتولّد العناوين، وتقسم الساعات. راقب البت الأدنى ينقلب كل حافة وكل بت أعلى بنصف المعدّل — عدٌّ ثنائي متحرّك.
