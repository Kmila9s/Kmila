# مسجّل

**المسجّل** بنك من القلّابات يخزّن كلمة كاملة دفعة واحدة. عند حافة الساعة (عند التحميل) تُلتقط كل بتات D معًا في Q.

<div class="lesson-figure"><iframe src="/_content/Kmila.Shared/anatomia/22-register.html" title="كتلة تتابعية متعددة البتات تفاعلية تقودها الساعة" loading="lazy"></iframe></div>

تنبض ساعة حرّة على اليسار؛ وتظهر حالة الـ4 بتات كصفّ من **مصابيح Q** وكقيمة حيّة (عشري + ثنائي). عند كل حافة ساعة تتحدّث الحالة؛ وبينها تُحتفظ.

في VHDL:

```vhdl
process (clk)
begin
  if rising_edge(clk) then
    if ld = '1' then q <= d; end if;  -- load on edge
  end if;
end process;
```

في المسجّلات يحفظ المعالج قيم عمله، وكل مرحلة أنبوب مسجّل. ضع مازجًا أمامه (القيمة الجديدة مقابل Q الحالية) فيصير تمكين التحميل احتفاظًا.
