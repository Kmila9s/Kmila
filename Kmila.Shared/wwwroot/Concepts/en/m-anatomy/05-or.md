# OR gate

The **OR** gate outputs 1 when **either** input is 1.

<div class="lesson-figure"><iframe src="/_content/Kmila.Shared/anatomia/05-or.html" title="Interactive logic gate on a module bench" loading="lazy"></iframe></div>

Move the cursor (or the arrow keys) to step through every input combination. The module computes the result and the output lamp **Y** lights according to the table.

In VHDL:

```vhdl
y <= a or b;
```

It is purely **combinational** — the output depends only on the current inputs, with no clock and no memory. Think of two switches in parallel: the lamp lights if either one is closed.
