# 非门（反相器）

**非门**是最简单的逻辑：一个输入、一个输出，而输出永远是输入的**相反值**——输入 0 则输出 1，输入 1 则输出 0。

**移动光标**即可把输入 **A** 设为 0 或 1。图形是一个等臂跷跷板：把输入（A）压下去，输出（Y）就升起来，反之亦然——等量而相反。输出上的小圆圈就是反相小圆圈（气泡）。

## 那个小圆圈

输出上的那个**圆圈**就是*反相气泡*，它是所有电路图中“非”的符号。每当你在某个门的输出端看到它（与非、或非、同或……），含义都一样：“并且取反”。

| A | Y |
|---|---|
| 0 | 1 |
| 1 | 0 |

在 VHDL 中，反相器就是 `not` 运算符：

```vhdl
y <= not a;
```

它是纯**组合**逻辑：输出只取决于当前输入——没有时钟，也没有记忆。输入一变，输出便在很短的传播延迟后翻转。
