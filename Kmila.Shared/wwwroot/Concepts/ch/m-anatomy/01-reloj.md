# 时钟：电路的心跳

**时钟**（clock）是为一切定拍的信号：一个在固定频率下于 0 与 1 之间交替的**方波**。在认识门电路和触发器之前，先看它动起来会很有帮助。

**左右移动光标**即可改变频率。齿条就是方波的实体化：触杆爬上每个齿（电平 **1**），落入每个凹槽（电平 **0**），而飞轮保持恒定的速度。读数显示当前的电平与频率。

## 真正重要的是：边沿

时序逻辑——触发器、寄存器、计数器——并不对时钟的*电平*作出反应，而是对它的**边沿**：从 0 跳到 1 的瞬间（**上升沿**）或从 1 跳到 0 的瞬间（**下降沿**）。在 VHDL 中：

```vhdl
process (clk)
begin
    if rising_edge(clk) then
        q <= d;          -- 恰好在上升沿被捕获
    end if;
end process;
```

- **频率**——每秒的周期数（Hz）。飞轮越快，波形越密。
- **周期**——一个完整周期：一个齿加一个凹槽。
- **占空比**——周期中为 1 的比例；此处为 50%。
