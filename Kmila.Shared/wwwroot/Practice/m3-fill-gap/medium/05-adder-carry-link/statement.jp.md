## 2 ビット・リップル加算器 — キャリーチェーンを埋める

2 つの全加算器が部分的に書かれています。和ビットと最終キャリーアウトは
すでに記述済み。ビット 0 とビット 1 の間の **内部キャリー** `c1` だけが
未実装です。

`c1` にビット 0 全加算器のキャリー出力を割り当ててください:

```
c1 = (a0·b0) + cin·(a0 ⊕ b0)
```

### 仕様

* 入力:`a`, `b`(各 2 ビット)と `cin`。
* 出力:`sum`(2 ビット)と `cout`。
* 他の代入はすべて与えられています。

### 編集箇所

`-- BEGIN_EDIT` と `-- END_EDIT` の間だけを編集。

### ヒント

`c1 <= (a(0) and b(0)) or (cin and (a(0) xor b(0)));`
