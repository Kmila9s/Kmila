## 2 位行波加法器 — 填上进位链

两个全加器已部分写好:和位和最终进位都已就位,只缺第 0 位与第 1 位
之间的**内部进位** `c1`。

请用第 0 位全加器的进位输出来驱动 `c1`:

```
c1 = (a0·b0) + cin·(a0 ⊕ b0)
```

### 规范

* 输入:`a`、`b`(各 2 位)与 `cin`。
* 输出:`sum`(2 位)与 `cout`。
* 其他赋值都已给出。

### 在哪里写

只编辑 `-- BEGIN_EDIT` 与 `-- END_EDIT` 之间。

### 提示

`c1 <= (a(0) and b(0)) or (cin and (a(0) xor b(0)));`
