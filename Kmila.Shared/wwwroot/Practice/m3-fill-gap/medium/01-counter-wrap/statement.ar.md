## عدّاد 3 بت مع التفاف — املأ الفراغ

عدّاد متزامن من 3 بت **شبه** جاهز. الـ reset وكشف حافة الساعة وإسناد
`q` كلها موصولة بالفعل.

نفّذ جسم فرع `rising_edge(clk)` بحيث يمر العدّاد على
`000 → 001 → … → 111 → 000`، أي يعود إلى الصفر بعد الوصول إلى سبعة.

### المواصفات

* Reset غير متزامن: `count ← 000`
* عند `rising_edge(clk)`:
  * إذا `count = 111` → `count ← 000`
  * وإلا → `count ← count + 1`
* `q` يعكس `count` دائماً.

### أين تكتب

عدّل فقط بين `-- BEGIN_EDIT` و`-- END_EDIT`. باقي الملف هو هيكل ثابت
يتوقعه المصحّح كما هو.

### تلميح

قارن `count` بـ `to_unsigned(7, 3)` (أو `"111"`) ثم اختر بين
`(others => '0')` و`count + 1`.
