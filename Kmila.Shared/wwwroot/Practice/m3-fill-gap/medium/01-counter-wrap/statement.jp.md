## 3 ビット・ラップ・カウンタ — 穴埋め

3 ビット同期カウンタは**ほぼ**完成しています。リセット、クロックエッジ
検出、`q` への代入はすでに配線済みです。

`rising_edge(clk)` 分岐の本体を実装し、`000 → 001 → … → 111 → 000`
の順に進ませてください。7 に達したらきれいに 0 へ戻ります。

### 仕様

* 非同期リセット:`count ← 000`
* `rising_edge(clk)` で:
  * `count = 111` のとき → `count ← 000`
  * それ以外 → `count ← count + 1`
* `q` は常に `count` を反映。

### 編集箇所

`-- BEGIN_EDIT` と `-- END_EDIT` の間だけを編集してください。それ以外
はグレーダが固定のまま期待する足場です。

### ヒント

`count` を `to_unsigned(7, 3)`(または `"111"`)と比較し、
`(others => '0')` と `count + 1` のどちらかを選びます。
