## 3 位回绕计数器 — 填空

一个 3 位同步计数器**几乎**完成。复位、时钟边沿检测以及对 `q` 的赋值
都已经连好。

请实现 `rising_edge(clk)` 分支的主体,使计数器按
`000 → 001 → … → 111 → 000` 循环,在到达 7 之后干净地回到 0。

### 规范

* 异步复位:`count ← 000`
* 在 `rising_edge(clk)`:
  * 若 `count = 111` → `count ← 000`
  * 否则 → `count ← count + 1`
* `q` 始终反映 `count`。

### 在哪里写

只编辑 `-- BEGIN_EDIT` 与 `-- END_EDIT` 之间的部分。其余是评测器期望
保持不变的固定脚手架。

### 提示

把 `count` 与 `to_unsigned(7, 3)`(或 `"111"`)比较,然后在
`(others => '0')` 和 `count + 1` 之间选择。
