## 三状态 FSM — 下一状态

一个 Moore 型三状态有限状态机已经部分写好:状态寄存器、复位以及从
`"00"` 与 `"10"` 出发的转移都已就位。

请补完**状态 `"01"` 的下一状态赋值**:

* 若 `x = '1'` → `nxt ← "10"`
* 若 `x = '0'` → `nxt ← "00"`

### 规范

* 状态:`"00"`、`"01"`、`"10"`(直接编码)。
* 异步复位让 FSM 回到 `"00"`。
* `state` 输出当前状态。

### 在哪里写

只编辑 `-- BEGIN_EDIT` 与 `-- END_EDIT` 之间。`case` 的其他分支与
状态寄存器都被锁定。

### 提示

一个简短的 `if x = '1' then … else … end if;` 即可。
