## 3 状態 FSM — 次状態

3 状態の Moore 型 FSM が一部だけ書かれています。状態レジスタ、リセット、
そして `"00"` と `"10"` からの遷移はすでに実装済みです。

**状態 `"01"` の次状態代入**を完成させてください:

* `x = '1'` → `nxt ← "10"`
* `x = '0'` → `nxt ← "00"`

### 仕様

* 状態:`"00"`, `"01"`, `"10"`(直接符号化)。
* 非同期リセットで FSM は `"00"` へ。
* `state` は現在状態を出力。

### 編集箇所

`-- BEGIN_EDIT` と `-- END_EDIT` の間だけを編集。`case` の他の分岐や
状態レジスタはロック済み。

### ヒント

短い `if x = '1' then … else … end if;` で十分です。
