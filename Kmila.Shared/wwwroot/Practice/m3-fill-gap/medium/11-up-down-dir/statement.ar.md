## عدّاد صعود/هبوط — املأ سطر الاتجاه

عدّاد متزامن 4-بت **شبه** جاهز. الـ reset وكشف الحافة الصاعدة
والمخرج `q <= std_logic_vector(count)` كلها موصولة.

نفّذ التحكم بالاتجاه عند الحافة الصاعدة:

* `dir = '1'` → `count ← count + 1`
* `dir = '0'` → `count ← count - 1`

### المواصفات

* Reset غير متزامن: `count ← 0000`.
* يلتفّ العدّاد بحرية (حساب unsigned 4-بت).

### أين تكتب

عدّل فقط بين `-- BEGIN_EDIT` و`-- END_EDIT`. الـ reset والمخرج مقفلان.

### تلميح

`if dir = '1' then … else … end if;` قصير يكفي.
