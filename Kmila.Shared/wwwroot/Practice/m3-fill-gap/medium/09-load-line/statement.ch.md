## 4 位可加载寄存器 — 填上加载分支

一个 4 位同步加载寄存器已部分写好:复位、上升沿检测和 `q <= qi`
都已就位。

请在上升沿块内实现**加载分支**:

* 若 `load = '1'` → `qi ← d`
* 若 `load = '0'` → `qi` 保持原值

### 规范

* 异步复位:`qi ← 0000`。
* 在 `rising_edge(clk)`:
  * `load = '1'` 捕获 `d`。
  * `load = '0'` 保持。
* `q` 始终反映 `qi`。

### 在哪里写

只编辑 `-- BEGIN_EDIT` 与 `-- END_EDIT` 之间。复位与输出已锁定。

### 提示

`if load = '1' then qi <= d; end if;` 即可 — 没有赋值时 VHDL 自动
保持 `qi`。
