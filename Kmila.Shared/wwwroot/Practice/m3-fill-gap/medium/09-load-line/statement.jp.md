## 4 ビット・ロード可能レジスタ — ロード分岐を埋める

同期ロード付き 4 ビットレジスタが部分的に書かれています。リセット、
立ち上がりエッジ検出、`q <= qi` は既に実装済み。

立ち上がりエッジ内で **ロード分岐** を実装してください:

* `load = '1'` → `qi ← d`
* `load = '0'` → `qi` は保持

### 仕様

* 非同期リセット:`qi ← 0000`。
* `rising_edge(clk)` で:
  * `load = '1'` で `d` を取り込む。
  * `load = '0'` で保持。
* `q` は常に `qi` を反映。

### 編集箇所

`-- BEGIN_EDIT` と `-- END_EDIT` の間だけ。リセットと出力はロック。

### ヒント

`if load = '1' then qi <= d; end if;` で OK — 代入が無ければ VHDL は
`qi` を保持します。
