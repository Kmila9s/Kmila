## T フリップフロップ — トグル代入を埋める

T フリップフロップは**ほぼ**完成。リセット、立ち上がりエッジ検出、
出力 `q <= qi` は既に配線済み。

立ち上がりエッジ分岐内でトグル動作を実装してください:

* `t = '1'` → `qi` が反転
* `t = '0'` → `qi` は保持

### 仕様

* 非同期リセット:`qi ← '0'`。
* `rising_edge(clk)` で:`qi ← qi xor t`。

### 編集箇所

`-- BEGIN_EDIT` と `-- END_EDIT` の間だけ。リセットと出力はロック。

### ヒント

`qi <= qi xor t;`
