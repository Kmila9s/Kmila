## قلّاب T — املأ سطر التبديل

قلّاب T **شبه** جاهز: الـ reset وكشف الحافة الصاعدة والمخرج
`q <= qi` موصولة بالفعل.

عليك تنفيذ سلوك التبديل داخل فرع الحافة الصاعدة:

* إذا `t = '1'` → `qi` يقلب قيمته
* إذا `t = '0'` → `qi` يبقى كما هو

### المواصفات

* Reset غير متزامن: `qi ← '0'`.
* عند `rising_edge(clk)`: `qi ← qi xor t`.

### أين تكتب

عدّل فقط بين `-- BEGIN_EDIT` و`-- END_EDIT`. الـ reset والمخرج مقفلان.

### تلميح

`qi <= qi xor t;`
