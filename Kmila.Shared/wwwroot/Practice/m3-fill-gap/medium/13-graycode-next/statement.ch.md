## 二进制 → 格雷码转换 — 填上转换

一个 3 位二进制计数器 `b(2..0)` 已经在运转,复位会清零。输出总线 `g`
由格雷码向量 `gi` 驱动。请用 `b` 计算 `gi`。

### 规范

标准的二进制 → 格雷码转换:

```
gi(2) = b(2)
gi(1) = b(2) xor b(1)
gi(0) = b(1) xor b(0)
```

它产生序列 `000, 001, 011, 010, 110, 111, 101, 100, …`,每一步只
改变一位。

### 在哪里写

只编辑 `-- BEGIN_EDIT` 与 `-- END_EDIT` 之间。计数器、复位以及
`g <= gi` 都已锁定。

### 提示

三条并发赋值,或一条合并赋值:
`b(2) & (b(2) xor b(1)) & (b(1) xor b(0))`。
