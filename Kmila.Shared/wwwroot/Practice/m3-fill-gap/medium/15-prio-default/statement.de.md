## Prioritäts-Coder — Default füllen

Ein 4-Bit-Prioritäts-Coder wählt das höchste gesetzte Bit und gibt seinen Index aus. Die vier Prioritätsfälle sind bereits verdrahtet. Liefere den **Catch-All-Default**, wenn kein Bit gesetzt ist.

Implementiere die Zeile zwischen `-- BEGIN_EDIT` und `-- END_EDIT`:

```vhdl
y <= "00";
```

Nur die markierte Zeile wird bewertet.
