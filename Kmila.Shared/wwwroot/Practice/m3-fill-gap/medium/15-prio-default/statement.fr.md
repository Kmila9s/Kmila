## Encodeur de priorité — compléter le défaut

Un encodeur de priorité 4 bits choisit le bit haut actif et sort son index. Les quatre cas prioritaires sont déjà câblés. Fournis le **cas par défaut** pour quand aucun bit n'est actif.

Implémente la ligne entre `-- BEGIN_EDIT` et `-- END_EDIT` :

```vhdl
y <= "00";
```

Seule la ligne marquée est évaluée.
