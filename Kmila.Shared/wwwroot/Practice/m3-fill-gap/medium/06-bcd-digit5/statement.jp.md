## BCD → 7 セグメント — 数字 5 を埋める

BCD → 7 セグメント・デコーダは**ほぼ**完成:0-4 と 6-9 は `case` に
実装済み。数字 5 の分岐だけが欠けています。

`digit = "0101"` を 7 セグメント・パターンに対応づける行を書いて
ください。並びは `seg(6..0) = a..g`、**アクティブ・ハイ**(点灯=`'1'`)。

数字 5 で点灯するのは `a, c, d, f, g`(`b` と `e` は消灯):

```
seg = "1011011"
```

### 編集箇所

`-- BEGIN_EDIT` と `-- END_EDIT` の間だけ。その他の `case` 分岐は
ロック。

### ヒント

1 行だけ:`when "0101" => seg <= "1011011";`。
