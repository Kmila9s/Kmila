## BCD 转 7 段 — 补上数字 5

一个 BCD 转 7 段译码器**几乎**完成:0-4 和 6-9 都已在 `case` 中实现,
只差数字 5 的分支。

请编写把 `digit = "0101"` 映射到 7 段图案的那一行。顺序是
`seg(6..0) = a..g`,**高电平有效**(亮的段 = `'1'`)。

数字 5 点亮的段是 `a, c, d, f, g`(`b` 与 `e` 灭),即:

```
seg = "1011011"
```

### 在哪里写

只编辑 `-- BEGIN_EDIT` 与 `-- END_EDIT` 之间。其他 `case` 分支已锁定。

### 提示

只有一行:`when "0101" => seg <= "1011011";`。
