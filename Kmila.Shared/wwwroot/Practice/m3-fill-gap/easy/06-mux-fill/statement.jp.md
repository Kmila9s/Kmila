## 2-to-1 マルチプレクサ — 穴埋め

2-to-1 マルチプレクサは選択ビット `sel` に従って、2 つの入力の
うち 1 つを出力に送ります。

* `sel = '0'` のとき、`y` は `a` に従います。
* `sel = '1'` のとき、`y` は `b` に従います。

エンティティ、ポート、アーキテクチャの骨組みは既に揃っています。
`when ... else` 式を使って**唯一の並列代入**を書きましょう。

### 真理値表

| `sel` | `a` | `b` | `y` |
|:-----:|:---:|:---:|:---:|
|   0   |  0  |  X  |  0  |
|   0   |  1  |  X  |  1  |
|   1   |  X  |  0  |  0  |
|   1   |  X  |  1  |  1  |

### どこに書くか

採点されるのは `-- BEGIN_EDIT` と `-- END_EDIT` の間の行だけです。
それ以外はロックされた骨組みです。
