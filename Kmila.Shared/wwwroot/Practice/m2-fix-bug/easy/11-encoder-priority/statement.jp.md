## 4-2 プライオリティエンコーダ — バグを見つけて直そう

4-2 プライオリティエンコーダは `d` の中で**最も上位の `1` の
ビット位置**を出力します。作者の `when` チェーンはビットを
**逆順**で走査しているため、複数のビットが `1` のとき最上位
ではなく最下位のインデックスを返してしまいます。

バグを見つけて優先順位を直してください。

### 仕様

* `d(3) = 1` のとき → `y = "11"`
* そうでなく `d(2) = 1` のとき → `y = "10"`
* そうでなく `d(1) = 1` のとき → `y = "01"`
* それ以外 → `y = "00"`

### ヒント

`when ... else` は**上から順に**評価され、最初に一致した節が
勝ちます。
