## 2 対 1 MUX — デフォルト分岐が誤り

2 対 1 MUX は `sel = 0` のとき `a`、`sel = 1` のとき `b` を出
力すべきです。スターターは `sel = 0` のときには正しく `a` を
通しますが、`sel = 1` のときに `b` ではなく `'1'` を出力して
おり、`b` は使われていません。

バグを見つけて、`else` 側で `b` を使ってください。

### 仕様

* `sel = 0` → `y = a`
* `sel = 1` → `y = b`

### ヒント

`else` の後ろのリテラルを見てください。そこには**信号**が来る
べきで、定数ではありません。
