## Inversor — encuentra y corrige el error

Se pidió al autor escribir una compuerta NOT (inversor): `y`
debe ser el **complemento lógico** de `a`. Ahora mismo sólo
copia `a` directamente a `y` — funciona como un buffer.

Encuentra el error y conviértelo en un inversor real.

### Especificación

| `a` | `y` |
|:---:|:---:|
|  0  |  1  |
|  1  |  0  |

### Pista

Un único operador VHDL hace todo el trabajo.
