## 3 ビットグレイコード

3 ビットの 2 進入力 `b` をグレイコード `g` に変換します。グレイコードでは、連続する値の間で 1 ビットだけが変化します。

### 式

- `g(2) = b(2)`
- `g(1) = b(2) XOR b(1)`
- `g(0) = b(1) XOR b(0)`

### 真理値表

| `b` | `g` |
|:---:|:---:|
| 000 | 000 |
| 001 | 001 |
| 010 | 011 |
| 011 | 010 |
| 100 | 110 |
| 101 | 111 |
| 110 | 101 |
| 111 | 100 |
