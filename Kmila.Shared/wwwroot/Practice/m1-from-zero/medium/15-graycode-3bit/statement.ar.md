## شيفرة غراي 3 بت

حوّل دخلًا ثنائيًا بعرض 3 بتات `b` إلى شيفرة غراي `g`. في شيفرة غراي يتغيّر بت واحد فقط بين قيمتين متتاليتين.

### المعادلات

- `g(2) = b(2)`
- `g(1) = b(2) XOR b(1)`
- `g(0) = b(1) XOR b(0)`

|:---:|:---:|
| 000 | 000 |
| 001 | 001 |
| 010 | 011 |
| 011 | 010 |
| 100 | 110 |
| 101 | 111 |
| 110 | 101 |
| 111 | 100 |
