# 示例：你的第一个 entity（2-to-1 MUX）

**多路选择器**（multiplexer）是最简单的带"选择"的组合器件。2-to-1 版本根据一个 `sel` 位在两个输入之间选一个：

```
  sel = 0  →  y = a
  sel = 1  →  y = b
```

对应的 VHDL 就一行：

```vhdl
y <= a when sel = '0' else b;
```

## 示例做了什么

打开示例，你会得到一个名为**你的第一个 entity**的项目，其中包含：

- `mux21.vhd`（上面那个设计）
- 一个配套的仿真配置，用 40 µs 驱动 `sel`、`a`、`b`

点击 Run，Waveforms 标签会显示四行 —— 三个输入和一个输出。随着 `sel` 切换，观察 `y` 在 `a` 与 `b` 之间翻动。

## 值得注意的事

赋值 `y <= a when sel = '0' else b;` 是一条**并发语句**：它位于任何进程之外，描述的是一段永久的连线。不存在"这一行何时执行？" —— 它就是那样存在。

`when/else` 中的条件可以是任何布尔表达式：

```vhdl
y <= a when sel = '0' else
     b when enable = '1' else
     'Z';
```

这样的链会综合为一个优先级多路选择器（前面的条件优先胜出）。

## 轮到你了：扩展它

看过示例运行之后：

1. 把 entity 改成 **4-to-1 MUX** —— `sel` 变为 2 位，在 `a`、`b`、`c`、`d` 之间选一。
2. 加一个第五个端口 `output_enable`。当它为 `'0'` 时，无论 `sel` 取何值，都驱动 `y <= 'Z'`（高阻）。
3. 把 `when/else` 和下一模块里要见到的 `with/select` 版本做对比。

Kmila 的编辑器会高亮 VHDL 关键字并认识 `std_logic` —— 把光标悬停在 `when` 上可以看到内置文档。
