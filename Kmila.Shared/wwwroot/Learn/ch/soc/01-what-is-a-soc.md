# 什么是 System-on-Chip？

你在前面课程里写的 8 位 CPU 能独立运行。它会计算，但不与外界通信。**片上系统**（System-on-Chip，SoC）是更大一号的东西：一颗 CPU 加上若干外设，再加上让它们互相通信的结构，全部在同一枚 die 上。

## 三个必备部分

每一颗 SoC，从 Kmila CPU 的扩展版到造价 500 万美元的 Apple A 系列，都可以归结为：

1. **一个或多个处理单元** —— CPU、DSP、GPU、加速器。
2. **存储器** —— 片上 SRAM、块 RAM，有时还有片外 DDR。
3. **互连** —— 线 + 仲裁，让 (1) 能与 (2) 以及各外设对话。

互连是不再纯属"RTL"而开始带有架构感的那一部分。它规定谁何时能说话，可以有多少笔事务在途，以及任何给定请求完成有多快。

## 常见的互连协议

行业已经收敛到少数几个：

| 协议            | 厂商      | 你会在哪看到                                           |
|-----------------|-----------|--------------------------------------------------------|
| AXI4 / AXI4-Lite | ARM      | RISC-V 核、Xilinx PS/PL 边界、大多数新 IP               |
| AHB / APB       | ARM       | 老款 ARM 核，低速外设                                   |
| Avalon MM / ST  | Intel     | NIOS-II、Qsys 生成的 SoC                                |
| Wishbone        | OpenCores | OpenRISC、许多开源 IP 核                                |

它们最终都归结为相同的三条通道：一个**地址通道**、一个**写数据通道**、一个**读数据通道**。差异在于握手协议、乱序支持以及突发语义。

## AXI4-Lite 到底是什么

AXI 家族中最简单的成员。去掉突发、乱序和 QoS 之类的所有东西，你得到的是五条独立通道，每条都有一个 `valid`/`ready` 握手：

```
  AW  (地址写)
  W   (写数据)
  B   (写响应)
  AR  (地址读)
  R   (读数据)
```

每笔传输是一拍。每条通道在对端未就绪（`ready`）时暂停。就这些。
