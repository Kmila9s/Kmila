# 什么是片上系统?

你之前那条线路里的 8 位 CPU 是独立运行的。它会算,但它不和外界对话。**片上系统**是上一档体量:一个 CPU + 一堆外设 + 让它们彼此对话的互连结构,全部都在同一颗芯片上。

## 三块必备零件

任何 SoC,从扩展过的 Kmila CPU 到一颗 500 万美元的 Apple A 系列,本质上就是:

1. **一个或多个处理单元** —— CPU、DSP、GPU、加速器。
2. **存储器** —— 片上 SRAM、block RAM,有时还有片外 DDR。
3. **互连结构** —— 让 (1) 能和 (2) 以及外设对话的线 + 仲裁。

互连结构是“不再只是 RTL、开始变成体系结构”的地方。它规定谁能在什么时候说话、最多有多少笔交易可以同时在飞,以及任意一次请求多快能完成。

## 常见互连协议

业界基本就用这几种:

| 协议           | 厂商      | 在哪里能见到                                            |
|----------------|-----------|---------------------------------------------------------|
| AXI4 / AXI4-Lite | ARM     | RISC-V 核、Xilinx PS/PL 边界、大多数新 IP               |
| AHB / APB      | ARM       | 老 ARM 核、低速外设                                     |
| Avalon MM / ST | Intel     | NIOS-II,Qsys 生成的 SoC                                |
| Wishbone       | OpenCores | OpenRISC、许多开源 IP 核                                |

它们最终都归结为同样的三条路:**地址通道**、**写数据通道**、**读数据通道**。差别在握手协议、是否支持乱序,以及 burst 语义。

## AXI4-Lite 究竟是什么

AXI 家族里最简单的成员。把 burst、乱序、QoS 全去掉,你得到五条独立通道,每条都有一个 `valid`/`ready` 握手:

```
  AW  (写地址)
  W   (写数据)
  B   (写响应)
  AR  (读地址)
  R   (读数据)
```

每次传输都是一拍。某条通道在对端不 `ready` 时就停住。仅此而已。
