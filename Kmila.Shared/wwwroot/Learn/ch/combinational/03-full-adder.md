# 示例:4 位行波进位加法器

把两个二进制数相加是数字算术里的“hello world”。这个示例构建一个 4 位、带进位输入和进位输出的加法器 —— 这正是你会在更大的 ALU 里、或在 CPU 的地址自增逻辑里平铺起来的那种单元。它是组合逻辑单元里的第一个电路(“加法器/减法器电路,circuito sumador/restador”),这是有原因的:一旦你会做加法,减法、比较和计数就都跟着来了。

## 从一位开始:全加器

在上 4 位版本之前,先搞懂它是由什么搭的 —— 单个比特的**全加器**。对第 `i` 位,带进位输入 `cin`:

```
sum  = a xor b xor cin
cout = (a and b) or (cin and (a xor b))
```

和是三个输入的 XOR(奇校验);进位是“三个输入里有两个或更多是 1”。把四个这样的单元串起来 —— 每个的 `cout` 喂给下一个的 `cin` —— 你就得到一个**行波进位(ripple-carry)**加法器。这名字是字面意义上的:进位必须从 LSB 一路涟漪到 MSB,最高位的和才算定下来,这也是为什么这个结构简单、但不是最快的。

## 接口

```vhdl
port (
  a    : in  std_logic_vector(3 downto 0);
  b    : in  std_logic_vector(3 downto 0);
  cin  : in  std_logic;
  sum  : out std_logic_vector(3 downto 0);
  cout : out std_logic
);
```

## 主体

与其手工接四个全加器,不如让 `numeric_std` 替你做算术,只去捕获进位:

```vhdl
signal t : unsigned(4 downto 0);
...
t    <= resize(unsigned(a), 5) + resize(unsigned(b), 5) + ("0000" & cin);
sum  <= std_logic_vector(t(3 downto 0));
cout <= t(4);
```

发生了什么:

- `unsigned(a)` 和 `unsigned(b)` 把向量重新解释成数值类型,这样才能用 `+` 运算符。
- `resize(…, 5)` 零扩展到 5 位,好让和有空间溢出到最高位。
- `("0000" & cin)` 构造一个只在 LSB 带 `cin` 的 5 位值,这样它能干净地加进去。
- 加完之后,`t(3 downto 0)` 是和,`t(4)` 是进位输出。

> 两种风格 —— 四个显式全加器,对比对 resize 过的 `unsigned` 做一次 `+` —— 综合成*同样的*行波进位硬件(现代工具甚至可能把它提升成更快的进位结构)。`+` 版本是你实际会写的;门级版本是你应该能*讲清楚*的。

## 为什么是 5 位?

两个 4 位数加一个进位输入,结果最大可以到 `1111 + 1111 + 1 = 11111` —— 五位。要是在一个 4 位容器里算,最高位会被悄悄丢掉。resize 到多一位是安全的惯用法,而第 4 位*就是*你的进位输出。

## 做一个减法器

课程把加法器和减法器配成一对,而在二进制补码里它们几乎是同一个电路。要算 `a − b`,把 `b` 按位取反再加上去,并把进位输入强制为 1:

```vhdl
t <= resize(unsigned(a), 5) + resize(unsigned(not b), 5) + "00001";
```

这就是 `a + (¬b) + 1 = a − b`。一个真正的加法器/减法器每位加一个 XOR(由一条 `add_sub` 线控制),并把那同一条线接到 `cin` —— 一位控制就能让整个单元在两种运算之间翻转。

## 示例做了什么

仿真 config 驱动 `a` 与 `b` 经过几种模式(`3+5 = 8`,然后一个会产生进位的 `10 + 6 = 16`,然后 `10 + 15 = 25`…)。波形显示 `sum` 与 `cout` 以**组合**方式变化 —— 不需要时钟,因为这个设计没有寄存器。

## 轮到你

- **参数化它。** 给 entity 加一个 `generic (N : integer := 4)`,在所有出现 `4` 的地方用 `N`。现在你有了一个可以在任意位宽上实例化的 `adder_N`。
- **搭出上面那个加法器/减法器**,带一个 `add_sub` 控制输入。
- **接两个起来。** 一个负责低半字节、一个负责高半字节,第一个的 `cout` 喂给第二个的 `cin`,你就得到了一个 8 位行波进位加法器 —— 顺便体会到为什么进位延迟会随位宽增长。

## 要点

- 一个全加器是 `sum = a xor b xor cin`、`cout = majority(a, b, cin)`;把它们串起来就能加宽位数的数。
- 算术总要多给一位(`resize`),这样进位才不会丢。
- 减法就是加上二进制补码:`a − b = a + not b + 1`。
- 行波进位结构简单,但它的延迟随位数增长。
