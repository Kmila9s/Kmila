# 修一修：总是在驱动的三态缓冲器

三态缓冲器是一个可开关的输出。当输出使能信号 `oe` 为高时，它把数据传递到总线上；当 `oe` 为低时，它**释放**总线 —— 驱动为高阻态（`'Z'`），以便其他设备能够通信。

## 问题出在哪

打开示例，看看主体：

```vhdl
y <= d when oe = '0' else 'Z';
```

大声读出来："`y` 等于 `d`，**当 `oe` 为 0**，否则为 `'Z'`。"方向反了。你希望的是：当使能**为高**时缓冲器传递数据，**为低**时释放总线。

## 你的任务

- 在编辑器中打开示例。
- 修正第 12 行（`y <=` 赋值）的条件。
- 运行仿真并在 Waveforms 标签页中验证：
  - 当 `oe = '0'` 时，`y` 应该是 `'Z'`。
  - 当 `oe = '1'` 时，`y` 应该跟随 `d`。

## 为什么三态重要

三态缓冲器是多个驱动器共享同一根线（总线）而不互相短路的方式。FPGA 内部结构中没有三态 —— 内部用多路选择器代替 —— 但**外部**三态（在 I/O 引脚处）仍然是 DDR 内存和 PCIe 端点共享引脚的方式。

## 额外内容：当心 `'X'`

如果两个三态缓冲器同时以不同值驱动同一条总线，真实电路会冒烟。仿真器会在波形上显示为 `'X'`（未知）。你可以尝试构建一个小测试台，把两个缓冲器接到同一个 `y` 上，看看会发生什么。
