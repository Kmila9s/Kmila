# 修复:总是在驱动的三态缓冲器

三态缓冲器是一个可切换的输出。当输出使能(`oe`)信号为高时,它把数据传给总线;当 `oe` 为低时,它**释放**总线 —— 驱动高阻态(`'Z'`),让别的设备可以发话。

## 哪里不对

打开示例,看主体:

```vhdl
y <= d when oe = '0' else 'Z';
```

把它念出来:“`y` 等于 `d` **当 `oe` 是 0**,否则 `'Z'`。” 这是反的。你想要的是:使能为**高**时通,**低**时释放。

## 你的任务

- 在编辑器里打开示例。
- 改第 12 行(`y <=` 那一行)的条件。
- 跑仿真,在 Waveforms 标签页里确认:
  - `oe = '0'` 时,`y` 应该是 `'Z'`。
  - `oe = '1'` 时,`y` 应该跟着 `d`。

## 为什么三态重要

三态缓冲器是多个驱动者共享同一根线(总线)而不互相短路的办法。FPGA 内部纤维里没有三态 —— 用的是多路选择器 —— 但**外部**三态(在 I/O 引脚上)仍然是 DDR 内存和 PCIe 端点共享引脚的方式。

## 附加:留意 `'X'`

如果两个三态缓冲器同时以不同的值驱动同一条总线,真实电路会冒烟。仿真器把它显示成波形上的 `'X'`(未知)。试着写一个小测试台,把你的两个缓冲器接到同一个 `y` 上,看看会发生什么。
