# 示例:3-8 解码器

解码器把一个小的二进制码转成 **one-hot** 输出:恰好一条输出线为高,它的位置正好对应这个码。它是组合逻辑单元里被点名的电路之一(“编码器与解码器,codificador y decodificador”),也是编码器的天然搭档 —— 编码器做的正好相反。

```
  sel  │  y
  000  │  00000001
  001  │  00000010
  010  │  00000100
  011  │  00001000
  100  │  00010000
  101  │  00100000
  110  │  01000000
  111  │  10000000
```

每个存储系统内部都住着解码器 —— 地址线驱动一个解码器,而那个“行匹配”输出恰好使能一条字线。每当你听到“地址解码器”,底下就是这玩意。同样的结构还实现了一整套最小项:一个 n 输入解码器输出其输入的全部 2ⁿ 个最小项,所以任何布尔函数都可以靠把对的那几条解码器输出 OR 起来搭出来。

## VHDL

解码器是 `with/select` 的教科书案例:

```vhdl
with sel select
  y <= "00000001" when "000",
       "00000010" when "001",
       "00000100" when "010",
       "00001000" when "011",
       "00010000" when "100",
       "00100000" when "101",
       "01000000" when "110",
       "10000000" when others;
```

注意末尾的 `when others`。`sel` 是一个 `std_logic_vector(2 downto 0)` —— 3 位 —— 所以有 2³ = 8 种*本意上的*值,但因为每一位都是九值的 `std_logic`,编译器看到的可能组合远不止这些,于是需要 `others` 来做到详尽无遗。这里 `others` 和 `"111"` 那一行并到了一起(它综合成同样的输出)。

## 可扩展的替代写法

对一个 3-8 解码器来说写满八行没问题,但它不可扩展。用一次移位,把同样的功能写成一行:

```vhdl
y <= std_logic_vector(shift_left(to_unsigned(1, 8), to_integer(unsigned(sel))));
```

从里往外读:把 `sel` 当成一个数,在一个 8 位的字段里把一个 `'1'` 向左移那么多位,再 cast 回 `std_logic_vector`。两个版本综合出来完全一样 —— 哪个你觉得更易读就挑哪个。(显式的表格对新手来说更容易对着真值表核验;移位形式才是你扩到 32 或 64 个输出时会用的。)

## 示例做了什么

示例把 `sel` 在所有八种 3 位值之间循环,每个值 10 µs。在 Waveforms 标签页里你会看到 `y` 的 8 位变成一个走动的 `'1'` —— 一个数字版的“跑马灯”。

## 加一个使能(并认识多路分配器)

真实的解码器都有一个**使能(enable)**。被禁用时,所有输出都为低:

```vhdl
y <= (others => '0') when enable = '0' else
     std_logic_vector(shift_left(to_unsigned(1, 8), to_integer(unsigned(sel))));
```

这里有个很妙的联系:一个带使能的解码器,当使能是一条*数据*线而不是常量时,**就是一个多路分配器** —— 使能的值被路由到地址挑中的那一个输出,其余的停在 `'0'`。解码器和多路分配器是同一个硬件,只是贴着不同的标签。

## 要点

- 一个解码器把一个 n 位的码映射到一个 one-hot 的 2ⁿ 输出;它的输出就是输入的最小项。
- 带一个必需的 `when others` 的 `with/select` 是写它的清晰、真值表形状的方式。
- `shift_left(to_unsigned(1, N), …)` 这个惯用法是能扩到任意位宽的版本。
- 一个使能由数据驱动的解码器就是一个多路分配器;它的镜像是编码器。
