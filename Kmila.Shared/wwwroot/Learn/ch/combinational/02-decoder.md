# 示例：3-to-8 译码器

译码器接受一个较小的二进制编码，并将其转换为**独热**（one-hot）输出：只有一个输出为高，且其位置与输入编码相对应。

```
  sel  │  y
  000  │  00000001
  001  │  00000010
  010  │  00000100
  011  │  00001000
  100  │  00010000
  101  │  00100000
  110  │  01000000
  111  │  10000000
```

译码器存在于每一个存储系统内部 —— 地址线驱动译码器，而"行匹配"输出恰好使能其中一行。每当你听到"地址译码器"，下面的就是它。

## VHDL 代码

译码器是 `with/select` 的教科书级案例：

```vhdl
with sel select
  y <=
    "00000001" when "000",
    "00000010" when "001",
    "00000100" when "010",
    "00001000" when "011",
    "00010000" when "100",
    "00100000" when "101",
    "01000000" when "110",
    "10000000" when others;
```

注意末尾的 `when others`。`sel` 是 `std_logic_vector(2 downto 0)` —— 3 位 —— 因此有 2³ = 8 个二进制取值；但由于 `std_logic` 有 9 种状态，编译器需要 `others` 分支来覆盖所有组合（它会综合为与 `"111"` 相同的结果）。

## 这个示例做了什么

示例让 `sel` 每 10 µs 取一个值，遍历全部 8 个 3 位取值。在 Waveforms 标签页上，你会看到 `y` 的 8 位变成一个走马灯般移动的 `'1'` —— 一个数字版"追逐灯"。

## 轮到你了

在示例跑通后：

- 把译码器扩展为 4-to-16 版本。你可以手动改写，也可以把主体改为 `y <= std_logic_vector(shift_left(to_unsigned(1, 16), to_integer(unsigned(sel))));`。两者综合结果一致 —— 选你觉得更易读的那个。
- 增加一个 `enable` 输入。当 `enable = '0'` 时，无论 `sel` 取何值，所有输出都为低电平。
