# 示例:3-8 解码器

解码器把一个小的二进制码转成 **one-hot** 输出:恰好一个输出为高,位置正好对应这个码。

```
  sel  │  y
  000  │  00000001
  001  │  00000010
  010  │  00000100
  011  │  00001000
  100  │  00010000
  101  │  00100000
  110  │  01000000
  111  │  10000000
```

每个存储系统内部都有解码器 —— 地址线驱动解码器,“行匹配” 输出恰好使能一行。每当你听到 “地址解码器”,底下就是这玩意。

## VHDL

解码器是 `with/select` 的教科书示例:

```vhdl
with sel select
  y <=
    "00000001" when "000",
    "00000010" when "001",
    "00000100" when "010",
    "00001000" when "011",
    "00010000" when "100",
    "00100000" when "101",
    "01000000" when "110",
    "10000000" when others;
```

注意末尾的 `when others`。`sel` 是 `std_logic_vector(2 downto 0)` —— 3 位 —— 所以有 2³ = 8 种二进制值,但因为 `std_logic` 有九种状态,编译器需要 `others` 子句来覆盖所有组合(它会综合成跟 `"111"` 一样的东西)。

## 示例做了什么

示例把 `sel` 在所有八种 3 位值之间循环,每个值 10 µs。Waveforms 标签页里你会看到 `y` 的 8 位变成一个移动的 `'1'` —— 数字 “跑马灯”。

## 轮到你

跑起来之后:

- 把解码器扩到 4-16。手工写,或者把主体改写成 `y <= std_logic_vector(shift_left(to_unsigned(1, 16), to_integer(unsigned(sel))));`。两者综合出来完全一样 —— 哪个你觉得更易读就选哪个。
- 加一个 `enable` 输入。当 `enable = '0'` 时,所有输出都为低,无视 `sel`。
