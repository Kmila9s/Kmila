# 示例:带异步复位的 D 触发器

D 触发器(DFF)是数字设计里最常见的存储单元。一颗现代 FPGA 上有数万到数十万个。每个寄存器、计数器、流水线段都用 DFF 搭出来。

## 它在做什么

`clk` 的每一个上升沿,`d` 上的值都被复制到 `q`。两个上升沿之间,即便 `d` 变了,`q` 仍保持。

`reset` 为高时,`q` 立刻被强制为 `'0'` —— 这就是**异步**复位。

## 代码

```vhdl
process(clk, reset)
begin
  if reset = '1' then
    q <= '0';
  elsif rising_edge(clk) then
    q <= d;
  end if;
end process;
```

逐行看:

- **敏感列表 `(clk, reset)`** —— process 在任一信号变化时醒来。这就是让 reset 异步的关键。
- **`if reset = '1'`** —— reset 优先。reset 引脚为高时,我们不关心时钟和 `d` 在干什么。
- **`elsif rising_edge(clk)`** —— 只有时钟从 0 到 1 时才采样 `d`。

## 波形走读

示例前 5 µs 把 `reset = '1'`,然后释放。`d` 在 10、30、50 µs 处翻转。Run 之后切到 Waveforms 标签页注意:

- 5 µs 之前,`q = '0'`(被 reset 钳住)。
- reset 释放后,`q` 只在时钟上升沿变 —— 沿上 `d` 的值被捕获。
- 两个沿之间 `d` 怎么变,都没影响。

## 同步 vs 异步复位

两派看法:

**异步复位**(`if reset = '1'` 写在 edge 块外面,如上):
- 优点:即便时钟没跑也能复位。上电过程干净处理。
- 缺点:很高时钟频率下时序更难收敛;Xilinx 在 7-series 及之后建议尽量不要用。

**同步复位**(`if rising_edge(clk) then if reset = '1'…`):
- 优点:行为像任何其他时钟沿输入;跟综合器合得来。
- 缺点:必须有时钟才能复位。

学习阶段异步更容易推理。生产 FPGA 工作里读你厂商的指引。

## 轮到你

- 加一个 **enable** 输入。`q` 只在 `enable = '1'` 的上升沿更新。
- 把它做成**寄存一条 4 位总线**而不是单 bit。把 `d` 和 `q` 改成 `std_logic_vector(3 downto 0)`,复位值改成 `(others => '0')`。
- 加一个 `q_not` 输出,它永远是 `q` 的反相。彩蛋:把 `q_not` 接回 `d`,看它变成一个二分频时钟。
