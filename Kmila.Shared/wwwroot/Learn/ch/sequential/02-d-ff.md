# 示例：带异步复位的 D 触发器

D 触发器（DFF）是数字设计中最常见的存储单元。一颗现代 FPGA 拥有数万到数十万个。每个寄存器、计数器、流水线段都由 DFF 构建。

## 它做什么

每当 `clk` 上升沿到来时，`d` 上的值被复制到 `q`。在两次边沿之间，即使 `d` 变化，`q` 也保持不变。

当 `reset` 为高时，`q` 立即被强制为 `'0'` —— 这就是**异步**复位。

## 代码

```vhdl
process(clk, reset)
begin
  if reset = '1' then
    q <= '0';
  elsif rising_edge(clk) then
    q <= d;
  end if;
end process;
```

逐行解读：

- **敏感信号列表 `(clk, reset)`** —— 进程在任一变化时被唤醒。正是这一点让复位成为异步的。
- **`if reset = '1'`** —— 复位具有最高优先级。如果复位脚为高，我们不关心时钟或 `d` 在做什么。
- **`elsif rising_edge(clk)`** —— 只有时钟从 0 变到 1 的那一刻，`d` 才被采样。

## 波形走读

示例在前 5 µs 内驱动 `reset = '1'`，之后释放。`d` 在 10、30 和 50 µs 切换。Run 之后切换到 Waveforms 标签，注意：

- 5 µs 之前，`q = '0'`（被复位保持）。
- 复位释放后，`q` 只在时钟上升沿变化 —— 边沿时刻的 `d` 值被捕获。
- 时钟沿之间 `d` 的变化没有效果。

## 同步复位 vs 异步复位

有两种观点：

**异步复位**（`if reset = '1'` 在边沿块之外，如上所示）：
- 优点：即使时钟没有运行也能复位。干净地处理上电。
- 缺点：在非常高的时钟频率下更难满足时序；Xilinx 对 7 系列及以后的建议是避免使用它。

**同步复位**（`if rising_edge(clk) then if reset = '1'…`）：
- 优点：像任何其它输入一样在时钟沿上表现；与综合器相处融洽。
- 缺点：需要时钟在运行才能复位。

学习时，异步复位更易推理。生产 FPGA 工作中，请查看你厂商的指南。

## 轮到你了

- 加一个 **enable** 输入。`q` 应该仅在 `enable = '1'` 时于上升沿更新。
- 让它**寄存一条 4 位总线**，而不是单个位。把 `d` 和 `q` 改成 `std_logic_vector(3 downto 0)`，并把复位值调整为 `(others => '0')`。
- 加一个 `q_not` 输出，始终是 `q` 的反相。额外挑战：把 `q_not` 连回 `d`，看看它如何变成一个二分频时钟。
