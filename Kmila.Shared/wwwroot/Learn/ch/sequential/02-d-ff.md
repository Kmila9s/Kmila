# 示例:带异步复位的 D 触发器

D 触发器(DFF)是数字设计里最常见的存储单元 —— 第四单元“Flip-Flop 型存储元件”的主角。一颗现代 FPGA 上有数万到数十万个。每个寄存器、计数器、流水线段都是用 DFF 搭出来的。

## 触发器 vs 锁存器(必须钉死的一个区别)

两者都存一个比特,但它们“听”的方式不同:

- **锁存器(latch)**是*电平敏感*的:只要它的使能为高,输出就跟随输入(它是“透明”的);只有使能为低时它才保持。
- **触发器(flip-flop)**是*边沿敏感*的:它只在一个瞬间 —— 时钟沿 —— 采样输入,然后在周期的其余时间保持。

这节课搭的是一个触发器。下一道修复练习展示当你*意外*搭出一个锁存器时会发生什么。把这个区别记牢:边沿触发 = 触发器,电平触发 = 锁存器。

## 它在做什么

`clk` 的每一个上升沿,`d` 上的值都被复制到 `q`。两个沿之间,即便 `d` 变了,`q` 仍保持它的值。当 `reset` 为高时,`q` 立刻被强制为 `'0'` —— 这就是**异步**复位。

## 代码

```vhdl
process(clk, reset)
begin
  if reset = '1' then
    q <= '0';
  elsif rising_edge(clk) then
    q <= d;
  end if;
end process;
```

逐行看:

- **敏感列表 `(clk, reset)`** —— process 在任一信号变化时醒来。把 `reset` 列进去正是让复位异步的原因:它在 `reset` 一拉高的那一刻就动作,而不是等到下一个时钟沿。
- **`if reset = '1'`** —— reset 优先。如果 reset 引脚为高,我们就不关心时钟和 `d` 在干什么。
- **`elsif rising_edge(clk)`** —— 只有时钟从 0 到 1 时,`d` 才被采样进 `q`。

## 建立时间与保持时间:为什么时钟沿需要喘息空间

一个触发器只有在 `d` 于时钟沿**之前**(建立时间 setup)和**之后**(保持时间 hold)都保持稳定一小段时间时,才能可靠地捕获 `d`。违反这个窗口,输出就可能进入*亚稳态* —— 在 `'0'` 和 `'1'` 之间悬着,然后不可预测地才稳定下来。这个示例里你不建模这些时间,但它们正是为什么真实设计会把异步输入先穿过两个触发器(一个“同步器”)再使用的原因。现在先知道这个名字;你以后还会遇到它。

## 波形走读

示例头 5 µs 把 `reset = '1'`,然后释放。`d` 在 10、30、50 µs 处翻转。Run 之后切到 Waveforms 标签页,注意:

- 5 µs 之前,`q = '0'`(被 reset 钳住)。
- reset 释放后,`q` 只在时钟上升沿变 —— 沿上那一刻 `d` 的值被捕获。
- 两个时钟沿之间 `d` 怎么变,对 `q` 都没影响。

## 同步 vs 异步复位

有两派,而这个选择有实实在在的后果:

**异步复位**(`if reset = '1'` 写在 edge 块外面,如上):
- 优点:即便时钟没在跑也能复位;上电过程处理得干净。
- 缺点:复位的*释放*和时钟不对齐,所以不同的触发器可能在不同的沿上离开复位 —— 一种亚稳态风险 —— 而且它会限制最高时钟频率。

**同步复位**(`if rising_edge(clk) then if reset = '1' then …`):
- 优点:行为像任何其它同步输入;直接映射到触发器内建的复位,和时序收敛合得来。
- 缺点:必须有时钟在跑才能生效。

就*学习*而言,异步复位更容易推理,这也是这个示例用它的原因。就*生产 FPGA 工作*而言,厂商的指引(例如 AMD/Xilinx 的《Get Smart About Reset》白皮书及之后的方法学指南)通常偏向**同步**复位,而有些自由运行的逻辑根本不需要复位。按你的目标器件的建议来。

## 其它触发器

课程还讲 SR、JK、T 触发器。它们全都是在 D 触发器前面加一点计算下一状态的组合逻辑:

- **T(翻转):** `d = q xor t` → `t=0` 时保持,`t=1` 时翻转。
- **JK:** `d = (j and not q) or (not k and q)`。
- **SR:** 置位/复位,把 `s=r=1` 的情况定义掉。

所以一旦你会写一个干净的 D 触发器,这些你都能搭出来。

## 轮到你

- 加一个 **enable** 输入:`q` 只在 `enable = '1'` 的上升沿更新。
- 把它做成**寄存一条 4 位总线**:把 `d` 和 `q` 改成 `std_logic_vector(3 downto 0)`,复位值改成 `(others => '0')`。
- 加一个 `q_not` 输出,它永远是 `not q`。彩蛋:把 `q_not` 接回 `d`,看它变成一个**二分频**时钟 —— 一个伪装的 T 触发器。
- 把复位改成**同步**,比较两种在复位释放处的波形。

## 要点

- 一个 D 触发器在时钟沿采样 `d`、在沿之间保持 —— 是边沿触发的,不像电平敏感的锁存器。
- `process(clk, reset)` 把复位测试放在 `rising_edge` *之前*给出异步复位;放在沿*里面*就是同步复位。
- 尊重建立/保持时间;把异步输入同步化以避免亚稳态。
- SR、JK、T 触发器只不过是一个 D 触发器加上下一状态逻辑。
