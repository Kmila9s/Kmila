# 示例:8 位移位寄存器

移位寄存器是一排串在一起的触发器。每个时钟沿把存着的位平移一位,并在一端进入一个新位。它们是 UART、SPI 控制器、CRC 引擎以及基于 LFSR 的随机数发生器的核心 —— 是上一课那些触发器带来的实际回报。

## 这个示例做什么

`shift8` 是一个**串入并出(SIPO)**移位寄存器:

- `din` 是每个上升沿到达的新位。
- `r` 是内部的 8 位寄存器。
- `q` 把 `r` 作为一个并行字节呈现给外面。

“串入”是因为位一个一个地进来;“并出”是因为你可以一次读到全部八位。这正是一个 UART 接收器所做的:它从导线上一位一位地把位打进来,然后把拼好的字节交给系统的其余部分。

## 主体

```vhdl
signal r : std_logic_vector(7 downto 0) := (others => '0');
...
process(clk, reset)
begin
  if reset = '1' then
    r <= (others => '0');
  elsif rising_edge(clk) then
    r <= r(6 downto 0) & din;
  end if;
end process;

q <= r;
```

魔法在这一行:

```vhdl
r <= r(6 downto 0) & din;
```

`&` 是**拼接(concatenation)**运算符。`r(6 downto 0)` 是当前寄存器的低 7 位。我们把 `din` 粘到右端,得到一个新的 8 位值,再把它赋回给 `r`。因为这是时钟驱动 process 里的一条信号赋值,所以移位发生在每一个上升沿 —— 又因为信号在步末才更新,右端式用的是*旧*的 `r`,这正是移位所需要的。

## 它就是链在一起的八个触发器

别让这一行的主体把硬件藏起来。`r` 是八个 D 触发器。那条赋值把每个触发器的输出接到下一个触发器的输入,`din` 喂给第一个,而第 7 位从末端掉下去(这里被丢弃)。那条链*就是*移位寄存器 —— 拼接只是描述这个接线的一种紧凑写法。

## 波形走读

仿真 config 用一段模式驱动 `din`:`1, 0, 1, 1, 0, 1, 0, 1`。看 `q` 随时间变化:

- 第 1 拍之后:`q = 00000001`
- 第 2 拍之后:`q = 00000010`
- 第 3 拍之后:`q = 00000101`
- …以此类推。新位落在 LSB;老位向 MSB 行进。

把视图拉远,你会看到第一个 `din` 值正好在它到达之后 8 个时钟周期时抵达最高位(第 7 位)。这就是一颗 8 位移位寄存器的往返延迟 —— 也是为什么一条串行链路有一个固定、可预测的延迟。

## 一个坑:移错方向

新手常把方向搞反,结果丢了一位。如果你写 `r <= r(7 downto 1) & din;`,你保留的是*高*七位、丢掉了第 0 位 —— 那是*右*移,不是左移。先决定新数据从哪一端进、哪一端掉出去,再让那个切片匹配。两种正确的写法是:

```vhdl
r <= r(6 downto 0) & din;   -- 左移:din -> LSB,MSB 被丢弃
r <= din & r(7 downto 1);   -- 右移:din -> MSB,LSB 被丢弃
```

## 轮到你

- **改成右移。** 用上面第二种写法,确认那个走动的位现在往另一个方向移。
- **并行加载(PISO/通用)。** 加一个 `load` 输入和一条 `din_par` 总线。当一个时钟沿上 `load = '1'` 时,`r <= din_par`(一次吃下整条总线);否则就移位。这就是一个*并入串出*发送器的核心。
- **串行输出。** 加 `dout <= r(7);`。现在它是串入串出(SISO)—— 你在 `din` 上送的第一个位在 8 个周期之后出现在 `dout`,正是 UART RX 依赖的那个延迟。
- **做一个 LFSR。** 把 `r(7) xor r(5) xor r(4) xor r(3)` 反馈到输入,替代 `din`。你现在有了一个伪随机序列发生器 —— 和 CRC、测试码型用的是同一个结构。

## 要点

- 一个移位寄存器是一条 D 触发器的链;每个沿把每一位挪一格,并在一端接纳一个新位。
- `r <= r(6 downto 0) & din;` 是左移(新位进 LSB);把切片和顺序对调就是右移。
- 加上并行加载,它就变成一个 SIPO/PISO 转换器 —— UART、SPI 这类串行链路的核心。
- 把选定的抽头经 XOR 反馈回去,它就成了一个 LFSR,用于 CRC 和伪随机序列。
