# 示例:8 位移位寄存器

移位寄存器是一排串起来的触发器。每个时钟沿把存的位向某一边平移一位,并在一端进入一个新位。它是 UART、SPI 控制器、CRC 引擎以及 LFSR 伪随机数发生器的核心。

## 这个示例做什么

`shift8` 是一个**串入并出**的移位寄存器:

- `din` 是每个上升沿到达的新位。
- `r` 是内部 8 位寄存器。
- `q` 把 `r` 作为并行字节呈现到外面。

## 主体

```vhdl
signal r : std_logic_vector(7 downto 0) := (others => '0');
...
process(clk, reset)
begin
  if reset = '1' then
    r <= (others => '0');
  elsif rising_edge(clk) then
    r <= r(6 downto 0) & din;
  end if;
end process;

q <= r;
```

魔法在这一行:

```vhdl
r <= r(6 downto 0) & din;
```

`&` 是**拼接**运算符。`r(6 downto 0)` 是当前寄存器的低 7 位。我们把 `din` 粘到右端,得到一个新的 8 位值,再赋给 `r`。

因为这是时钟驱动 process 里的 signal 赋值,所以移位发生在每个上升沿。

## 波形走读

仿真 config 用一段模式驱动 `din`:`1, 0, 1, 1, 0, 1, 0, 1`。看 `q` 随时间:

- 第 1 拍后:`q = 00000001`
- 第 2 拍后:`q = 00000010`
- 第 3 拍后:`q = 00000101`
- …以此类推。新位落在 LSB;老位向 MSB 走。

把视图拉远点,你能看到最高位(bit 7)在第 8 个时钟周期之后,正好得到第一次 `din` 的值。这就是一颗 8 位移位寄存器的往返延迟。

## 轮到你

- **改右移**。把拼接换一下:`r <= din & r(7 downto 1);`。
- **并行加载**。加一个 `load` 输入和一个 `din_parallel` 总线。`load = '1'` 的时钟沿,寄存器把整条总线一口气吃下,不再做移位。
- **串行输出**。加 `dout <= r(7);`。现在它是串入串出(SISO)移位寄存器 —— 你在 `din` 上送的第一个位在 8 个周期之后从 `dout` 出来。UART 接收里那种 “逐位延迟" 就是这么工作的。
