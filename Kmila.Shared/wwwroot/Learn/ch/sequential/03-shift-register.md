# 示例：8 位移位寄存器

移位寄存器是一串级联在一起的触发器。每个时钟沿把存储的位移动一个位置，一个新位从一端进入。它们是 UART、SPI 控制器、CRC 引擎和基于 LFSR 的随机数发生器的核心。

## 本示例做什么

`shift8` 是一个**串入并出**的移位寄存器：

- `din` 是每个上升沿到来的新位。
- `r` 是内部 8 位寄存器。
- `q` 把 `r` 作为一个并行字节暴露给外部。

## 主体

```vhdl
signal r : std_logic_vector(7 downto 0) := (others => '0');
...
process(clk, reset)
begin
  if reset = '1' then
    r <= (others => '0');
  elsif rising_edge(clk) then
    r <= r(6 downto 0) & din;
  end if;
end process;

q <= r;
```

魔法都在这一行：

```vhdl
r <= r(6 downto 0) & din;
```

`&` 是**拼接**运算符。`r(6 downto 0)` 是当前寄存器的低 7 位。我们把 `din` 粘到右端，组成一个新的 8 位值，再赋回给 `r`。

因为这是时钟进程内的信号赋值，所以每个上升沿都会发生一次移位。

## 波形走读

仿真配置驱动 `din` 经过模式：`1, 0, 1, 1, 0, 1, 0, 1`。随时间观察 `q`：

- 第一拍之后：`q = 00000001`
- 第二拍之后：`q = 00000010`
- 第三拍之后：`q = 00000101`
- ……依此类推。新位落在 LSB，老位向 MSB 行进。

若把时间拉长，你会看到最高位（bit 7）恰好在首个 `din` 值到来 8 个时钟之后才获得它。那就是 8 位移位寄存器的往返延迟。

## 轮到你了

- **改为右移。** 交换拼接：`r <= din & r(7 downto 1);`。
- **并行加载。** 加一个 `load` 输入和一条 `din_parallel` 总线。当时钟沿上 `load = '1'` 时，寄存器整批接收总线值，而不是移位。
- **串行输出。** 加 `dout <= r(7);`。这样就变成串入串出（SISO）的移位寄存器 —— 你在 `din` 上送出的第一个位在 8 个周期后出现在 `dout`。这就是 UART RX 中按位延迟的工作方式。
