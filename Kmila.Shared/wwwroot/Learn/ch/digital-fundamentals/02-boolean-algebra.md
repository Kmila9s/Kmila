# 布尔代数与重要的定律

布尔代数是关于真/假值以及在其上可做运算的数学。每一个数字电路 —— 从单个门到一颗几百万晶体管的 CPU —— 最终都是一个布尔表达式。

好消息:你只需要记一小撮恒等式。靠这些你就可以手工化简几乎任何表达式。

## 三个基本运算

| 运算 | 数学符号 | VHDL 符号 | 读作 |
|-----|---------|-----------|------|
| AND | · 或并列 | `and` | “A 与 B” |
| OR  | +       | `or`  | “A 或 B” |
| NOT | 上划线(`Ā`)| `not` | “非 A” |

二元运算的真值表:

```
 A  B  │  A·B   A+B
──────┼────────────
 0  0  │   0     0
 0  1  │   0     1
 1  0  │   0     1
 1  1  │   1     1
```

## 你真的会用到的恒等式

**交换律** —— 顺序无关:

```
A · B = B · A
A + B = B + A
```

**结合律** —— 分组无关:

```
(A · B) · C = A · (B · C)
(A + B) + C = A + (B + C)
```

**分配律** —— OR 那个版本看起来很怪:

```
A · (B + C) = A·B + A·C
A + (B · C) = (A + B) · (A + C)   ← 是的,真的
```

**单位与吸收**:

```
A + 0 = A      A · 1 = A
A + 1 = 1      A · 0 = 0
```

**互补**:

```
A + Ā = 1      A · Ā = 0
```

**德摩根定律** —— 数字设计里最有用的两条变换:

```
非(A · B) = Ā + B̄
非(A + B) = Ā · B̄
```

德摩根能让你把一个 NAND 变成 “各取反后的 OR”,或把 NOR 变成 “各取反后的 AND”,或者抵消长长的取反线。所有 FPGA 工具链在优化时都在不断用它。

## 一步步化简

从这里开始:

```
Y = A·B + A·B̄·C + A·B̄·C̄
```

提出 `A`:

```
Y = A · (B + B̄·C + B̄·C̄)
```

里面提出 `B̄`:

```
Y = A · (B + B̄ · (C + C̄))
```

`C + C̄ = 1`(互补),所以:

```
Y = A · (B + B̄ · 1)
  = A · (B + B̄)
  = A · 1
  = A
```

四个项五次 AND-OR 操作,塌缩成了一根线。综合器会替你自动做这种事 —— 但理解它会让你读别人的网表时更敏锐。

## 要记住的

- AND / OR / NOT 就够了。NAND 和 NOR 是 AND/OR 后面挂个 NOT。
- 德摩根是瑞士军刀 —— 学会两个方向都能认出来。
- 当某个子表达式靠互补变成 `1` 时,整个乘积就能简化。
