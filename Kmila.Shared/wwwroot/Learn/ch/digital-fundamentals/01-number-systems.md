# 数制:位、十六进制、二补码

数字电路不知道 “七” —— 它知道一排排开或关的开关。要用它们做设计,你得能在人类喜欢的表示法(十进制)和硅芯片懂的表示法(二进制)之间自由切换,中间还有十六进制做实用的速记。

## 二进制(基数 2)

**位** 是一个开/关值,写作 `0` 或 `1`。**字节** 是八位。

一摞位按位置编码整数,就跟十进制一样 —— 每一位是 2 的某次幂:

```
  1 0 1 1 0
  │ │ │ │ └── 2⁰ = 1
  │ │ │ └──── 2¹ = 2
  │ │ └────── 2² = 0
  │ └──────── 2³ = 8
  └────────── 2⁴ = 16

  16 + 0 + 0 + 2 + 0 = 18
```

所以 `10110₂ = 18₁₀`。

## 十六进制(基数 16)

把 32 位写成二进制是没人校对得了的 32 字符一锅粥:

```
00000000 00000000 11001010 11111110
```

十六进制按 4 位一组分组。每个十六进制位正好覆盖一个 nibble(4 位),所以 32 位变成整齐的 8 字符串:

```
0x0000CAFE
```

对应表是固定的:

| bin  | hex | bin  | hex |
|------|-----|------|-----|
| 0000 | 0   | 1000 | 8   |
| 0001 | 1   | 1001 | 9   |
| 0010 | 2   | 1010 | A   |
| 0011 | 3   | 1011 | B   |
| 0100 | 4   | 1100 | C   |
| 0101 | 5   | 1101 | D   |
| 0110 | 6   | 1110 | E   |
| 0111 | 7   | 1111 | F   |

VHDL 里,长度是 4 的倍数的向量你会用十六进制字面量:

```vhdl
signal addr : std_logic_vector(7 downto 0) := x"CA";  -- 8 位:11001010
```

## 二补码(有符号整数)

上面这种二进制只能编**非负**数。要把负数塞进同样的位模式,数字设计师用**二补码**:

1. 把正数写成二进制。
2. 每一位取反。
3. 加 1。

要在 8 位里表示 `-5`:`+5 = 00000101`,取反 → `11111010`,加 1 → `11111011`。

为什么这套方案?因为不管有没有符号,加法都一样工作 —— 你不需要两套加法器。`-5 + 7`,8 位二补码:

```
  11111011   (-5)
+ 00000111   ( 7)
-----------
 100000010
```

第 9 位从顶上溢出,低 8 位是 `00000010 = 2`。这就是对的答案。

## 要记住的

- 位是原子;字节是 8 位一组。
- 二进制和十六进制是**同一个数**披着不同的皮。十六进制更易读。
- 二补码用 “取反+1” 编码负数 —— 也正因为这样,ALU 里的 `A + B` 不管有没有符号都对。
