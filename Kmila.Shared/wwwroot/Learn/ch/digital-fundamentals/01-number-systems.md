# 数制：位、十六进制、二进制补码

数字电路并不认识"七" —— 它们认识的是一排排或开或关的开关。要用它们做设计，你就必须能自如地在人类偏爱的表示方式（十进制）与硅片理解的表示方式（二进制）之间切换，中间用十六进制做桥梁。

## 二进制（基 2）

一个**位**（bit）是一个开/关值，写作 `0` 或 `1`。一个**字节**（byte）是八位。

一串位按位权编码整数，和十进制一样 —— 每个位置是 2 的幂：

```
  1 0 1 1 0
  │ │ │ │ └── 2⁰ = 1
  │ │ │ └──── 2¹ = 2
  │ │ └────── 2² = 0
  │ └──────── 2³ = 8
  └────────── 2⁴ = 16

  16 + 0 + 0 + 2 + 0 = 18
```

所以 `10110₂ = 18₁₀`。

## 十六进制（基 16）

用二进制写 32 位数会得到一串 32 个字符的"字符汤"，谁都校对不过来：

```
00000000 00000000 11001010 11111110
```

十六进制把位按四位一组。每个十六进制数字恰好覆盖一个 nibble（4 位），因此 32 位变成整齐的 8 字符串：

```
0x0000CAFE
```

对应关系是固定的：

| bin  | hex | bin  | hex |
|------|-----|------|-----|
| 0000 | 0   | 1000 | 8   |
| 0001 | 1   | 1001 | 9   |
| 0010 | 2   | 1010 | A   |
| 0011 | 3   | 1011 | B   |
| 0100 | 4   | 1100 | C   |
| 0101 | 5   | 1101 | D   |
| 0110 | 6   | 1110 | E   |
| 0111 | 7   | 1111 | F   |

在 VHDL 里，你会为位宽是 4 的倍数的向量写十六进制字面量：

```vhdl
signal addr : std_logic_vector(7 downto 0) := x"CA";  -- 8 位: 11001010
```

## 二进制补码（有符号整数）

上面展示的二进制只能编码**非负**数。为了让负数也塞进同样的位型里，数字设计师使用**二进制补码**：

1. 写出正数的二进制。
2. 逐位取反。
3. 加 1。

在 8 位下表示 `-5`：`+5 = 00000101`，取反 → `11111010`，加 1 → `11111011`。

为什么采用这个方案？因为加法对有符号和无符号完全一样 —— 不需要两个加法器。用 8 位二进制补码计算 `-5 + 7`：

```
  11111011   (-5)
+ 00000111   ( 7)
-----------
 100000010
```

第九位溢出抛弃，低 8 位是 `00000010 = 2`。正是正确答案。

## 关键要点

- 位是原子；字节是 8 位一组。
- 二进制和十六进制是**同一个数**的不同皮肤。十六进制更易读。
- 二进制补码通过"取反加一"编码负数 —— 这正是你 ALU 里的 `A + B` 不论符号都能正常工作的原因。
