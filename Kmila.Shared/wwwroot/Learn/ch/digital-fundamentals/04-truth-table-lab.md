# 实验：真值表探索器

这个实验是你第一次真正地驱动一个 VHDL 设计。这个 entity 有两个输入（`a`、`b`）和六个输出 —— 每个基本双输入门对应一个。

## 点击"在编辑器中打开"之后会发生什么

1. Kmila 创建一个用完即弃的项目，名字类似"实验：真值表探索器"。
2. 它把包含六条并发赋值的 `gates.vhd` 种进去。
3. 它加载一个**仿真配置**，对 `a` 和 `b` 的所有组合进行激励。
4. 编辑器工作台打开，顶部的胶囊里已经选好了该配置。

接下来：

- 点击 **Build** 对设计进行解析和精化。
- 点击 **Run** 运行仿真。
- 切换到底部工作面板里的 **Waveforms** 标签。

你会看到七行方波：顶部两行是输入，剩下六行是各输出的实时响应。

## 观察什么

用滚动条或键盘让输入的边沿与输出的跳变对齐。试着不回头看真值表，自己验证每个门的行为：

- `o_and`：在 `a` 和 `b` 都为 1 之前都保持低电平 —— 然后跳高。
- `o_nand`：相反。它通常为高，只有当两个输入都为 1 时才变低。
- `o_xor`：在两个输入不一致时恰好为高。

如果某一个与你预期不符，打开 **Output** 标签 —— 构建警告会在那里出现。

## 自己动手试

示例跑通后，做一些实验：

- 给 entity 加一个第三个输入 `c`，并计算 `a xor b xor c`（三输入奇偶校验）。
- 重命名一个输出并重新构建 —— **Ports** 标签会同步更新。
- 在配置里再加一行：让 `a` 和 `b` 同时翻转，看看哪些输出会变。

在动手写自己的设计之前多拉动这些操纵杆，VHDL 就会少一分"猜谜"的感觉。
