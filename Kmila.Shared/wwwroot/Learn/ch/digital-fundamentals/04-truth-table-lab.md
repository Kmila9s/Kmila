# 实验:真值表浏览器

这是你第一次驱动一个真实的 VHDL 设计。entity 有两个输入(`a`、`b`)和六个输出 —— 每个基本双输入门一个。

## 你点 *在编辑器中打开* 时会发生什么

1. Kmila 创建一个一次性项目,名字大概是 “实验:真值表浏览器"。
2. 它用一份 `gates.vhd` 初始化,里面是六条并发赋值。
3. 它加载一份**仿真配置**,在所有组合下激励 `a` 和 `b`。
4. 编辑器工作台打开,上方那颗胶囊里已经选好这份配置。

从这里:

- 点 **Build** 来解析并 elaborate 设计。
- 点 **Run** 来仿真。
- 切到底部 dock 的 **Waveforms** 标签页。

你会看到七行方波:上面两行是输入,下面每一行是一个输出在实时反应。

## 要看什么

用滚动条或键盘对齐输入沿和输出跳变。试着不看真值表去验证每个门的行为:

- `o_and`:在 `a` 与 `b` 都为 1 之前一直低 —— 然后跳高。
- `o_nand`:反过来。通常是高,只有两个输入都是 1 时才掉低。
- `o_xor`:输入不一致时为高。

如果有不符合预期的,打开 **Output** 标签页 —— 构建警告在那里。

## 自己试

跑通之后,自己试试:

- 在 entity 上加第三个输入 `c`,算 `a xor b xor c`(三输入奇偶)。
- 改个输出名再重建 —— **Ports** 标签页会跟着更新。
- 在配置里再加一行:让 `a` 和 `b` 同时翻转,看哪些输出变。

在写自己的设计之前,你越多动这些杠杆,VHDL 就越不会让你觉得是在猜。
