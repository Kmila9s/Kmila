# サンプル: ライトファーストリード付きシングルポート RAM

読み書き可能メモリは「BRAM の推論」のもう一方の半分です。同じ `type…array…of` パターンが動きますが、今度は配列は **signal** で、いくつかのクロックエッジで書き込み、他で読み込みます。

## テンプレート

```vhdl
type mem_t is array(0 to 31) of std_logic_vector(7 downto 0);
signal mem : mem_t := (others => (others => '0'));
...
process(clk)
begin
  if rising_edge(clk) then
    if we = '1' then
      mem(to_integer(unsigned(addr))) <= din;
      dout <= din;                             -- write-first read
    else
      dout <= mem(to_integer(unsigned(addr)));
    end if;
  end if;
end process;
```

## 3 つの読み出しポリシー

すべての同期 RAM は、**書き込み中の** `dout` がどうなるかを決めなければなりません。3 つの慣習が存在します:

- **ライトファースト (上に示したもの):** 書き込み時、`dout` は新しく書き込まれたデータを表示します。最もきれいなセマンティクス — 同じサイクルで同じアドレスを読み書きすると新しい値が得られます。
- **リードファースト:** 書き込み時、`dout` はセルの **古い** 内容を表示します。一部の CPU のレジスタファイルはこれを使います。
- **ノーチェンジ:** 書き込み時、`dout` は更新されません。一部の低消費電力設計。

3 つとも現代の FPGA のブロック RAM にマップされますが、シンセサイザはプロセスの正確な形状に基づいてモードを選びます。ライトファーストテンプレートが最もポータブル — 迷ったらこれを書きましょう。

## サンプルが行うこと

最初の 30 µs の間、シミュレーションは 3 つのアドレス (`0`、`1`、`2`) に 3 つの異なるバイトパターンで書き込みます。その後、`we` が落ち、`addr` は 40 µs で 0 にリセットされます。Waveforms タブは書き込み中に `dout` が `din` を追いかけ、その後読み出し時に保存された値を出力する様子を示します。

## 自分でやってみる

- **真のデュアルポート RAM にアップグレード。** `addr`/`din`/`dout`/`we` の完全なセットを 2 つ、両方とも `clk` でクロックします。これはすべてのベンダーの FIFO とデュアルクロック DPRAM が内部で使っているパターンです。
- **出力レジスタを追加する。** Xilinx のブロック RAM はメモリ配列の後に第 2 のパイプラインレジスタをサポートします。2 番目のクロック同期ブロックに `dout_reg <= dout;` を追加し、波形上で何が変わるかを見てください(ヒント: レイテンシが 1 サイクル増えるが、タイミングクロージャがずっと良くなる)。
- **初期内容を変える。** `signal mem` の初期化子を変えて、最初の数エントリに認識できるパターンをプリロードします。すべてのシンセサイザがポータブル VHDL で BRAM 初期化子を尊重するわけではありません — 本番で頼る前にターゲットを確認しましょう。
