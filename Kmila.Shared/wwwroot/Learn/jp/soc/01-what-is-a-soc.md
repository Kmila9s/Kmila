# System-on-Chip とは何か?

以前のトラックの 8 ビット CPU は単独で動きます。計算はしますが、世界と話はしません。**System-on-Chip (SoC)** は次の大きさのステップです: CPU に加え、いくつかの周辺機器、そしてそれらが互いに話せるようにするファブリック、これらすべてが同じダイの上にあります。

## 3 つの必須要素

Kmila CPU を拡張したものから 500 万ドルの Apple A シリーズまで、すべての SoC は以下に帰着します:

1. **1 つまたは複数の処理要素** — CPU、DSP、GPU、アクセラレータ。
2. **メモリ** — オンチップ SRAM、ブロック RAM、時にはオフチップ DDR。
3. **インターコネクト** — (1) を (2) と周辺機器に接続させるワイヤと調停。

インターコネクトは「単なる RTL」であることをやめ、アーキテクチャ的な感触を持ち始める部分です。誰がいつ話せるか、同時に飛行中のトランザクションはいくつ許されるか、任意のリクエストがどれだけ速く完了できるかを強制します。

## 一般的なインターコネクトプロトコル

業界は一握りに収束しました:

| プロトコル       | ベンダー  | 見かける場所                                            |
|------------------|-----------|---------------------------------------------------------|
| AXI4 / AXI4-Lite | ARM       | RISC-V コア、Xilinx PS/PL 境界、ほとんどの新規 IP       |
| AHB / APB        | ARM       | レガシー ARM コア、低速周辺機器                         |
| Avalon MM / ST   | Intel     | NIOS-II、Qsys 生成 SoC                                  |
| Wishbone         | OpenCores | OpenRISC、多くのオープンソース IP コア                  |

これらすべては同じ 3 つのレーンに帰着します: **アドレスチャネル**、**書き込みデータチャネル**、**読み出しデータチャネル**。差異はハンドシェイクプロトコル、順序外対応、バーストセマンティクスについてです。

## AXI4-Lite とは実際何か

AXI ファミリの最も単純なメンバー。バースト、順序外、QoS に関するすべてを取り除くと、`valid`/`ready` ハンドシェイクを持つ 5 つの独立したチャネルが得られます:

```
  AW  (address write)
  W   (write data)
  B   (write response)
  AR  (address read)
  R   (read data)
```

すべての転送は 1 ビート。各チャネルは相手が `ready` でないときに停止します。それだけ。

## Kmila カリキュラムの計画

このモジュールの後のレッスンでは、AXI4-Lite レジスタインタフェースをゼロから構築し、8 ビット CPU とメモリマップされた UART の間に配線して、CPU がアドレスに書き込むことで「印刷」できるようにします。これで、実際に頭に収められるサイズで、現代のあらゆる SoC の内部で何が起きているかのメンタルモデルが得られます。
