# 数体系:ビット、16 進、2 の補数

デジタル回路は「7」を知らない — オン/オフの並んだスイッチを知っている。それらで設計するには、人間が好む表現(10 進)とシリコンが理解する表現(2 進)の間を自在に行き来できる必要がある。中間に便利な省略形として 16 進がいる。

## 2 進(基数 2)

**ビット**は単一のオン/オフ値で、`0` または `1` と書く。**バイト**は 8 ビット。

ビットの積み重ねは、整数を位取り符号化する。10 進と同じ要領で、各位は 2 の冪乗:

```
  1 0 1 1 0
  │ │ │ │ └── 2⁰ = 1
  │ │ │ └──── 2¹ = 2
  │ │ └────── 2² = 0
  │ └──────── 2³ = 8
  └────────── 2⁴ = 16

  16 + 0 + 0 + 2 + 0 = 18
```

したがって `10110₂ = 18₁₀`。

## 16 進(基数 16)

32 ビットを 2 進で書くと、誰も校正できない 32 文字のスープになる:

```
00000000 00000000 11001010 11111110
```

16 進は 4 ビットずつグループ化する。16 進 1 桁がちょうどニブル(4 ビット)1 つに対応するので、32 ビットがすっきり 8 文字になる:

```
0x0000CAFE
```

対応表は固定:

| bin  | hex | bin  | hex |
|------|-----|------|-----|
| 0000 | 0   | 1000 | 8   |
| 0001 | 1   | 1001 | 9   |
| 0010 | 2   | 1010 | A   |
| 0011 | 3   | 1011 | B   |
| 0100 | 4   | 1100 | C   |
| 0101 | 5   | 1101 | D   |
| 0110 | 6   | 1110 | E   |
| 0111 | 7   | 1111 | F   |

VHDL では長さが 4 の倍数のベクトルに対して 16 進リテラルを書く:

```vhdl
signal addr : std_logic_vector(7 downto 0) := x"CA";  -- 8 ビット:11001010
```

## 2 の補数(符号付き整数)

上記の 2 進は**非負**数しか符号化しない。負数を同じビットパターンに収めるため、デジタル設計者は **2 の補数** を使う:

1. 正数を 2 進で書く。
2. 各ビットを反転。
3. 1 を足す。

8 ビットで `-5` を表す:`+5 = 00000101`、反転 → `11111010`、+1 → `11111011`。

なぜこの方式?加算が符号の有無に関わらず同じように動くから — 加算器を 2 つ作る必要がない。8 ビットの 2 の補数で `-5 + 7`:

```
  11111011   (-5)
+ 00000111   ( 7)
-----------
 100000010
```

9 ビット目が上から溢れ、下位 8 ビットは `00000010 = 2`。これが正解。

## 覚えておくべきこと

- ビットが原子;バイトは 8 つの組。
- 2 進と 16 進は外見が違うだけの**同じ数**。16 進の方が読みやすい。
- 2 の補数は反転して 1 を足すことで負数を符号化 — そして ALU で `A + B` が符号に関係なく動く理由がこれ。
