# 数値体系: ビット、16進数、2の補数

デジタル回路は「7」という概念を知らない — 知っているのは、オン・オフのどちらかになっているスイッチの並びだけです。デジタル回路で設計するには、人間が好む表現(10進数)とシリコンが理解する表現(2進数)の間を自在に行き来できる必要があり、中間の便利な略記として16進数が役立ちます。

## 2進数 (基数 2)

**ビット** は `0` か `1` で書かれる、オン・オフを表す1つの値です。**バイト** は 8 ビットです。

ビットを並べると、10進数と同じように各位が位取りで整数を符号化します — 各桁は 2 のべき乗です:

```
  1 0 1 1 0
  │ │ │ │ └── 2⁰ = 1
  │ │ │ └──── 2¹ = 2
  │ │ └────── 2² = 0
  │ └──────── 2³ = 8
  └────────── 2⁴ = 16

  16 + 0 + 0 + 2 + 0 = 18
```

したがって `10110₂ = 18₁₀` です。

## 16進数 (基数 16)

32 ビットを 2 進数で書くと、誰にも校正できない 32 文字の羅列になります:

```
00000000 00000000 11001010 11111110
```

16進数はビットを 4 つずつまとめます。1 桁の16進数は正確に 1 ニブル(4 ビット)をカバーするので、32 ビットはすっきりと 8 文字の文字列になります:

```
0x0000CAFE
```

対応は固定です:

| bin  | hex | bin  | hex |
|------|-----|------|-----|
| 0000 | 0   | 1000 | 8   |
| 0001 | 1   | 1001 | 9   |
| 0010 | 2   | 1010 | A   |
| 0011 | 3   | 1011 | B   |
| 0100 | 4   | 1100 | C   |
| 0101 | 5   | 1101 | D   |
| 0110 | 6   | 1110 | E   |
| 0111 | 7   | 1111 | F   |

VHDL では、長さが 4 の倍数であるベクタに対して16進数リテラルを書きます:

```vhdl
signal addr : std_logic_vector(7 downto 0) := x"CA";  -- 8 bits: 11001010
```

## 2の補数 (符号付き整数)

上で示した 2 進数では **非負** の数しか表現できません。同じビットパターンの中に負の数を収めるために、デジタル設計者は **2の補数** を使います:

1. 正の数を 2 進数で書く。
2. すべてのビットを反転する。
3. 1 を加える。

8 ビットで `-5` を表現するには: `+5 = 00000101`、反転 → `11111010`、1 を加える → `11111011`。

なぜこの方式かというと、数が符号付きでも符号なしでも加算がまったく同じように動作するからです — 加算器を2つ用意する必要がありません。8 ビットの2の補数で `-5 + 7` を計算すると:

```
  11111011   (-5)
+ 00000111   ( 7)
-----------
 100000010
```

9 ビット目は上位に溢れて捨てられ、下位 8 ビットは `00000010 = 2` です。これは正しい答えです。

## 覚えておくべきこと

- ビットは原子、バイトは 8 ビットのグループ。
- 2進数と 16進数は **同じ数の別の衣装**。16進数の方が読みやすい。
- 2の補数は反転して 1 を加えることで負数を符号化する — これがあなたの ALU の `A + B` が符号に関係なく動作する理由です。
