# ブール代数と重要な法則

ブール代数は真偽値とその上で行える演算の数学です。どんなデジタル回路も — 単一のゲートから100万トランジスタの CPU まで — 突き詰めればブール式です。

良いニュース: 覚えておくべき恒等式はほんの一握りです。それさえあれば、ほとんどどんな式でも手で簡約できます。

## 3つの基本演算

| 演算 | 記号 (数学) | 記号 (VHDL) | 読み方 |
|------|-------------|-------------|--------|
| AND | · または並置 | `and` | 「A かつ B」 |
| OR  | +           | `or`  | 「A または B」 |
| NOT | オーバーライン (`Ā`) | `not` | 「A でない」 |

二項演算子の真理値表:

```
 A  B  │  A·B   A+B
──────┼────────────
 0  0  │   0     0
 0  1  │   0     1
 1  0  │   0     1
 1  1  │   1     1
```

## 実際に使う恒等式

**可換性** — 順序は問わない:

```
A · B = B · A
A + B = B + A
```

**結合性** — グループ化は問わない:

```
(A · B) · C = A · (B · C)
(A + B) + C = A + (B + C)
```

**分配性** — OR 版は奇妙に見える方:

```
A · (B + C) = A·B + A·C
A + (B · C) = (A + B) · (A + C)   ← そう、本当に
```

**単位元と支配**:

```
A + 0 = A      A · 1 = A
A + 1 = 1      A · 0 = 0
```

**補元**:

```
A + Ā = 1      A · Ā = 0
```

**ド・モルガンの法則** — デジタル設計で最も有用な書き換えの2つ:

```
not(A · B) = Ā + B̄
not(A + B) = Ā · B̄
```

ド・モルガンを使うと、NAND を「補元の OR」に変えたり、NOR を「補元の AND」に変えたり、長い NOT のバーを打ち消したりできます。すべての FPGA ツールチェーンは最適化時にこれを絶えず使っています。

## 簡約の例

次から始めます:

```
Y = A·B + A·B̄·C + A·B̄·C̄
```

`A` をくくり出す:

```
Y = A · (B + B̄·C + B̄·C̄)
```

内側で `B̄` をくくり出す:

```
Y = A · (B + B̄ · (C + C̄))
```

`C + C̄ = 1` (補元)なので:

```
Y = A · (B + B̄ · 1)
  = A · (B + B̄)
  = A · 1
  = A
```

AND-OR 演算 5 個を含む 4 つの項が 1 本のワイヤに縮退します。これはシンセサイザが自動で行う種類の作業ですが、これを理解していると他人のネットリストを読むときに鋭くなれます。

## 覚えておくべきこと

- AND / OR / NOT があれば十分。NAND と NOR は AND/OR に NOT を付けただけです。
- ド・モルガンはスイスアーミーナイフ — 両方向で見分けられるようになりましょう。
- 補元を使って部分式が `1` に評価されると、積全体が簡約されます。
