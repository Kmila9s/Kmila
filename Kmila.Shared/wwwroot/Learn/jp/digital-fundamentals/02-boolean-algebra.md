# ブール代数と重要な法則

ブール代数は真/偽の値とその上で行える演算の数学。あらゆるデジタル回路 — 単一ゲートから 100 万トランジスタの CPU まで — は究極的にはブール式。

良い知らせ:覚えるべき恒等式は一握りだけ。それらでほぼあらゆる式を手で簡約できる。

## 3 つの基本演算

| 演算 | 記号(数学)   | 記号(VHDL) | 読み |
|------|---------------|--------------|------|
| AND  | · または並置  | `and`        | 「A かつ B」 |
| OR   | +             | `or`         | 「A または B」 |
| NOT  | 上線(`Ā`)    | `not`        | 「A でない」 |

2 項演算の真理値表:

```
 A  B  │  A·B   A+B
──────┼────────────
 0  0  │   0     0
 0  1  │   0     1
 1  0  │   0     1
 1  1  │   1     1
```

## 実際に使う恒等式

**交換則** — 順序は無関係:

```
A · B = B · A
A + B = B + A
```

**結合則** — グルーピングは無関係:

```
(A · B) · C = A · (B · C)
(A + B) + C = A + (B + C)
```

**分配則** — OR 側のは奇妙に見える:

```
A · (B + C) = A·B + A·C
A + (B · C) = (A + B) · (A + C)   ← そう、本当に
```

**単位と吸収**:

```
A + 0 = A      A · 1 = A
A + 1 = 1      A · 0 = 0
```

**補元**:

```
A + Ā = 1      A · Ā = 0
```

**ド・モルガンの法則** — デジタル設計で最も有用な 2 つの書き換え:

```
not(A · B) = Ā + B̄
not(A + B) = Ā · B̄
```

ド・モルガンを使えば NAND を「補元の OR」に、NOR を「補元の AND」に変えたり、長い NOT バーをキャンセルしたりできる。あらゆる FPGA ツールチェーンが最適化時に頻繁に使う。

## 手で簡約してみる

ここから:

```
Y = A·B + A·B̄·C + A·B̄·C̄
```

`A` をくくり出す:

```
Y = A · (B + B̄·C + B̄·C̄)
```

内側で `B̄` をくくり出す:

```
Y = A · (B + B̄ · (C + C̄))
```

`C + C̄ = 1`(補元)なので:

```
Y = A · (B + B̄ · 1)
  = A · (B + B̄)
  = A · 1
  = A
```

4 項 5 AND-OR 演算が 1 本の線に潰れた。シンセサイザが自動でやってくれる類の仕事 — だが理解しておくと他人のネットリストを読むのが鋭くなる。

## 覚えておくべきこと

- AND / OR / NOT があれば十分。NAND と NOR は AND/OR に NOT がくっついたもの。
- ド・モルガンはスイスアーミーナイフ — 両方向で認識できるよう学ぶ。
- 部分式が補元で `1` になるなら、積全体が簡約される。
