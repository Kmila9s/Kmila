# 7種類の論理ゲート

どんなデジタル回路も、最新の GPU まで含めて、7 つの基本セルの組み合わせです。各ゲートの振る舞いと VHDL での書き方を知っていれば、もうハードウェア設計を始めたと言えます。

## 6つの2入力ゲート

| ゲート  | VHDL での記号 | 読み方 | 出力が `1` になるのは… |
|---------|---------------|--------|------------------------|
| AND   | `a and b`      | 「A かつ B」 | 両方の入力が 1 のとき |
| OR    | `a or b`       | 「A または B」 | 少なくとも一方の入力が 1 のとき |
| XOR   | `a xor b`      | 「A xor B」 | 入力が異なるとき |
| NAND  | `a nand b`     | 「not (A かつ B)」 | 少なくとも一方の入力が 0 のとき |
| NOR   | `a nor b`      | 「not (A または B)」 | 両方の入力が 0 のとき |
| XNOR  | `a xnor b`     | 「A = B」 | 入力が等しいとき |

そして 1 入力の NOT:

```vhdl
y <= not a;
```

## NAND と NOR が特別な理由

デジタル論理の古典的な結果: **NAND だけ**(または NOR だけ)で、他のすべてのゲートを作れます。この理由から、どちらも「機能的完全」と呼ばれます。これが CMOS プロセスライブラリが NAND2 や NOR2 セルを大量に用意する理由です — それらからすべてを合成できます。

- NOT: `not a = a nand a`
- AND: `a and b = not (a nand b)`
- OR:  `a or b = (not a) nand (not b)`

## XOR は数学的なゲート

XOR はしばしば丸に+(⊕)で描かれます。これは「パリティ」を計算するゲート — 入力の奇数個が `1` のときに出力が `1` になります。そのため、次の中核を担います:

- 加算器: `sum = a xor b xor carry_in`
- パリティチェッカと誤り検出符号
- トグルフリップフロップ: `q_next = q xor toggle_input`

## 6種類を1つのファイルで見る

このモジュールの **真理値表エクスプローラ** ラボを開くと、6 つの 2 入力ゲートすべてを一度に計算する 1 つの VHDL エンティティが見つかります。入力 `a` と `b` は刺激のために Ports タブに接続されています。波形ビューアで各出力が各入力組み合わせにどう反応するかが確認できます。

```vhdl
architecture rtl of gates is
begin
  o_and  <= a and b;
  o_or   <= a or  b;
  o_xor  <= a xor b;
  o_nand <= a nand b;
  o_nor  <= a nor  b;
  o_xnor <= a xnor b;
end architecture rtl;
```

この 6 行はそれぞれ、実行される文ではなく **ワイヤ** です。6 つのゲート、6 つのハードウェア片 — すべて同時に評価されます。

## 覚えておくべきこと

- 6 つの 2 入力ゲート + NOT で全集合。
- NAND と NOR は「ユニバーサル」 — それらから何でも作れる。
- VHDL ではゲートは 1 行の並行代入。「呼び出される」のではなく、存在するのです。
