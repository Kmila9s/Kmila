# サンプル: 最初のエンティティ (2-to-1 MUX)

**マルチプレクサ** は「選択」を持つ最も単純な組合せデバイスです。2-to-1 版は 1 つの `sel` ビットに基づいて 2 つの入力から選択します:

```
  sel = 0  →  y = a
  sel = 1  →  y = b
```

その VHDL は 1 行です:

```vhdl
y <= a when sel = '0' else b;
```

## サンプルが行うこと

サンプルを開くと **Your first entity** という名前のプロジェクトが得られ、以下が含まれます:

- `mux21.vhd` (上の設計)
- 40 マイクロ秒にわたって `sel`、`a`、`b` を駆動する付属シミュレーション設定

Run すると、Waveforms タブには 4 行が表示されます — 3 つの入力と 1 つの出力。`sel` がトグルするにつれて `y` が `a` と `b` の間を切り替わる様子を見てください。

## 注目すべきこと

代入 `y <= a when sel = '0' else b;` は **並行文** です: どのプロセスの外にも存在し、恒久的な配線を記述します。「この行はいつ実行されるのか?」というのはありません — ただ存在するだけです。

`when/else` 内の条件は任意のブール式にできます:

```vhdl
y <= a when sel = '0' else
     b when enable = '1' else
     'Z';
```

このような連鎖は優先度マルチプレクサに合成されます(上位のケースが同点を勝つ)。

## 自分でやってみる: 拡張する

サンプルが動くのを見たら:

1. エンティティを **4-to-1 MUX** に変更する — `sel` は 2 ビットになり、`a`、`b`、`c`、`d` の間から選びます。
2. 5 つ目のポート `output_enable` を追加する。`'0'` のとき、`sel` に関係なく `y <= 'Z'` (高インピーダンス) を駆動します。
3. 次のモジュールで出会う `with/select` 版と `when/else` を比較する。

Kmila のエディタは VHDL キーワードをハイライトし、`std_logic` を認識します — `when` の上にホバーすると組込みドキュメントが表示されます。
