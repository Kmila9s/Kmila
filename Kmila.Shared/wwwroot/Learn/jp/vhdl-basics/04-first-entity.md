# サンプル:はじめての entity(2 対 1 MUX)

**マルチプレクサ** は、「選択」を含む組合せ回路としては最もシンプルなものだ。2 対 1 版は、1 本の `sel` ビットに基づいて 2 つの入力のどちらかを選ぶ。

```
  sel = 0  →  y = a
  sel = 1  →  y = b
```

これを表す VHDL は 1 行だ。

```vhdl
y <= a when sel = '0' else b;
```

## ファイル全体

前のレッスンで扱った 4 つのセクションを、一か所でまとめて見られるようにしておく。

```vhdl
library IEEE;
use IEEE.STD_LOGIC_1164.ALL;

entity mux21 is
  port (
    a   : in  std_logic;
    b   : in  std_logic;
    sel : in  std_logic;
    y   : out std_logic
  );
end entity mux21;

architecture rtl of mux21 is
begin
  y <= a when sel = '0' else b;
end architecture rtl;
```

## このサンプルがすること

サンプルを開くと、**はじめての entity** という名前のプロジェクトが得られ、次のものが含まれている。

- `mux21.vhd`(上の設計)
- `sel`、`a`、`b` を 40 マイクロ秒にわたって駆動する、付属のシミュレーション設定

Run すると、Waveforms タブに 4 つの行 — 3 つの入力と 1 つの出力 — が表示される。`sel` が切り替わるのに合わせて、`y` が `a` と `b` の間で切り替わる様子を観察しよう。

## 注目すべき点

代入 `y <= a when sel = '0' else b;` は **並行文(concurrent statement)** だ。どの process の外にも属さず、恒久的な配線を記述する。「この行はいつ実行されるのか?」という問いはない — それはただ *存在している* だけだ。`a`、`b`、`sel` のいずれかが変われば、伝播遅延の後に `y` が再び落ち着く。

`when/else` の中の条件には任意のブール式を書けるし、連ねることもできる。

```vhdl
y <= a   when sel = '0' else
     b   when enable = '1' else
     'Z';
```

このような連鎖は **優先度付き(priority)** マルチプレクサに合成される(一番上の条件が同点を制する)。

## 下に潜む理論:シャノン展開

この 1 行は、ただの便利な構文ではない。ブール代数の定理をハードウェアの形にしたもので、コースでは **シャノンの展開定理(teorema de expansión de Shannon)** と呼ばれているものだ。変数 `s` の任意の関数は、次のように分解できる。

```
f(s, …) = (s' · f(0, …)) + (s · f(1, …))
```

2 対 1 mux は、まさに `y = sel'·a + sel·b` を計算している。言い換えれば、マルチプレクサは選択ビットを軸にしたシャノン展開を物理的に実現したものなのだ。より大きな関数が mux を積み重ねることでよく作られるのは、このためだ。これは頭の片隅に入れておこう。コースの後半に出てくるマルチプレクサ / デマルチプレクサの単元の下地になる考え方だ。

## あなたの番:拡張してみよう

サンプルが動くのを見たら、次を試してみよう。

1. entity を **4 対 1 MUX** に変えてみよう。`sel` を 2 ビットの `std_logic_vector` にし、`a`、`b`、`c`、`d` の中から選ぶ。(ここでは `with sel select` 文がすっきり読める — 組合せ回路の単元で出会う。)
2. 5 つ目のポート `output_enable` を追加しよう。これが `'0'` のときは、`sel` に関係なく `y <= 'Z'`(ハイインピーダンス)を駆動する。
3. **デマルチプレクサ** を作ってみよう — ちょうど鏡写しだ。1 つの入力、`sel`、そして複数の出力があり、入力はちょうど 1 つの出力に振り分けられ、残りは `'0'` のままになる。

Kmila のエディタは VHDL キーワードをハイライトし、`std_logic` を認識している — `when` の上にカーソルを合わせると、組み込みのドキュメントが見られる。

## 覚えておくべきこと

- **entity** はインタフェースに名前を与え、**architecture** は振る舞いを与える。mux は、その両方の完全かつ最小の例だ。
- `y <= a when sel = '0' else b;` は並行条件代入だ — 「実行される」行ではなく、恒久的な配線だ。
- マルチプレクサはシリコン上のシャノン展開だ:`y = sel'·a + sel·b`。この 1 つの考え方が、これから作るあらゆる幅広の mux へとスケールしていく。
