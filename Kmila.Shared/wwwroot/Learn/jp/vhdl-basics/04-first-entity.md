# サンプル:はじめての entity(2 対 1 MUX)

**マルチプレクサ**は「選択」を持つ最も単純な組合せ回路。2 対 1 版は 1 ビットの `sel` で 2 つの入力から 1 つを選ぶ:

```
  sel = 0  →  y = a
  sel = 1  →  y = b
```

これを表す VHDL は 1 行:

```vhdl
y <= a when sel = '0' else b;
```

## サンプルが行うこと

サンプルを開くと **Your first entity** という名前のプロジェクトが手に入る:

- `mux21.vhd`(上の設計)
- 40 マイクロ秒にわたって `sel`、`a`、`b` を駆動する付随シミュレーション config

Run すると、Waveforms タブに 4 行が表示される — 3 つの入力と 1 つの出力。`sel` がトグルするにつれて `y` が `a` と `b` の間で切り替わるのを見る。

## 注目点

代入 `y <= a when sel = '0' else b;` は**並行文** — process の外に住み、永続的な配線を記述する。「この行はいつ実行される?」はない — ただ存在するだけ。

`when/else` 内の条件は任意のブール式でよい:

```vhdl
y <= a when sel = '0' else
     b when enable = '1' else
     'Z';
```

このようなチェーンは優先順位マルチプレクサに合成される(上のケースが同点を制す)。

## あなたの番:拡張する

サンプルが動くのを見たら:

1. entity を **4 対 1 MUX** に変える — `sel` は 2 ビットになり、`a`、`b`、`c`、`d` から選ぶ。
2. 5 つ目のポート `output_enable` を追加。`'0'` のとき、`sel` に関係なく `y <= 'Z'`(ハイインピーダンス)を駆動。
3. `when/else` を、次のモジュールで出会う `with/select` 版と比較する。

Kmila のエディタは VHDL キーワードをハイライトし、`std_logic` も認識する — `when` の上にマウスを置いて組み込みのドキュメントを見てみよう。
