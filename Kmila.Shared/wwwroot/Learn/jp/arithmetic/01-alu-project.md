# プロジェクト:フラグ付き 8 ビット ALU

**算術論理ユニット**(ALU)はあらゆる CPU の鼓動する心臓。2 つのオペランドと opcode を与えれば、結果と、何が起きたかを記述するフラグ(オーバーフローしたか?結果はゼロか?など)を返す。

## 何を作るか

次の操作を持つ 8 ビット ALU:

| Opcode | 名称    | 式                          |
|--------|---------|-----------------------------|
| `000`  | ADD     | `y = a + b`                 |
| `001`  | SUB     | `y = a - b`                 |
| `010`  | AND     | `y = a and b`               |
| `011`  | OR      | `y = a or  b`               |
| `100`  | XOR     | `y = a xor b`               |
| `101`  | SHL     | `y = a を左に 1 ビットシフト` |
| `110`  | SHR     | `y = a を右に 1 ビットシフト` |
| `111`  | PASS_A  | `y = a`(パススルー)         |

加えて 2 つのフラグ出力:

- `zero` — `y` が全部ゼロのときに High
- `carry` — ADD/SUB のキャリーアウト;それ以外は `'0'` を駆動

## 雛形が与えるもの

スタータは entity、`result` と `cout` 信号、そして ADD と SUB をすでに処理する `process(op, a, b)` シェルを宣言済み。あなたの仕事は `case` 文の残り 6 つの分岐を埋めること。

## ヒント

- **AND / OR / XOR** はそれぞれ 1 行 — ビット単位の結果を代入するだけ:

  ```vhdl
  when "010" => result <= a and b;
  ```

- **SHL** と **SHR** は `'0'` でパディング:

  ```vhdl
  when "101" => result <= a(6 downto 0) & '0';
  when "110" => result <= '0' & a(7 downto 1);
  ```

- **PASS_A** は単に `a` を `result` にコピー。

論理演算では `cout <= '0'` を駆動するのを忘れずに — process の先頭で一度だけ書いておけば、上書きしない分岐はすべてそのデフォルトを継承する。便利だが、ある分岐が**ゼロでない**キャリーを欲しいなら明示しなければならない。

## 受け入れ基準

付随する config のスティミュラスで:

| time | op    | a          | b          | 期待 `y`      | `carry` | `zero` |
|------|-------|------------|------------|---------------|---------|--------|
|  0   | `000` | `00001111` | `00000101` | `00010100`    | `0`     | `0`    |
| 20   | `001` | `00001111` | `00001111` | `00000000`    | `0`     | `1`    |
| 40   | `010` | `00001111` | `00001111` | `00001111`    | `0`     | `0`    |
| 60   | `101` | `10110000` | n/a        | `01100000`    | `0`     | `0`    |
| 80   | `111` | `10110000` | n/a        | `10110000`    | `0`     | `0`    |

## さらに進めるなら

- **signed** フラグを追加(2 の補数 SUB で負の結果)。
- **rotate** opcode を追加 — SHL と同じだが、最上位ビットがビット 0 に戻る。
- **multiply** opcode を追加し、2 つの別出力ポートに 16 ビットの結果を出す。多くの小型 FPGA はこのための専用 DSP ブロックを持つ — 再合成時の使用率に注意。

この ALU は Expert レベルの CPU プロジェクトの直接的な構成要素 — 設計をきれいに保てば、そこで配線することになる。
