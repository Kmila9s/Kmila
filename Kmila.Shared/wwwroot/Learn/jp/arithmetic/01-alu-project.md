# プロジェクト: フラグ付き8ビット ALU

**ALU (Arithmetic Logic Unit: 算術論理演算ユニット)** はあらゆる CPU の鼓動する心臓です。2 つのオペランドとオペコードを与えると、結果と、何が起こったかを説明するいくつかのフラグ(オーバーフローした? 結果はゼロ? など)を返します。

## 作るもの

以下の演算を持つ 8 ビット ALU:

| Opcode | 名前    | 式                          |
|--------|---------|-----------------------------|
| `000`  | ADD     | `y = a + b`                 |
| `001`  | SUB     | `y = a - b`                 |
| `010`  | AND     | `y = a and b`               |
| `011`  | OR      | `y = a or  b`               |
| `100`  | XOR     | `y = a xor b`               |
| `101`  | SHL     | `y = a を 1 ビット左シフト` |
| `110`  | SHR     | `y = a を 1 ビット右シフト` |
| `111`  | PASS_A  | `y = a` (素通し)            |

加えて 2 つのフラグ出力:

- `zero` — `y` が全ゼロのときにハイ
- `carry` — ADD/SUB からのキャリーアウト。それ以外のときは `'0'` を駆動する

## スキャフォールドが提供するもの

スターターコードはエンティティ、`result` と `cout` 信号、および ADD と SUB をすでに処理する `process(op, a, b)` のシェルを宣言しています。あなたの仕事は `case` 文の残り 6 つの分岐を埋めることです。

## ヒント

- **AND / OR / XOR** は各 1 行 — ビット単位の結果を代入するだけ:

  ```vhdl
  when "010" => result <= a and b;
  ```

- **SHL** と **SHR** は `'0'` でパディング:

  ```vhdl
  when "101" => result <= a(6 downto 0) & '0';
  when "110" => result <= '0' & a(7 downto 1);
  ```

- **PASS_A** は `a` を `result` にコピーするだけ。

論理演算では `cout <= '0'` を駆動することを忘れずに — プロセス上部ですでに一度行っているので、それを上書きしない分岐はそのデフォルトを継承します。便利ですが、ある分岐が **実際に** ゼロ以外のキャリーを出したいときには明示的にする必要があります。

## 受け入れ基準

付属の設定の刺激で:

| time | op    | a          | b          | 期待 `y`     | `carry` | `zero` |
|------|-------|------------|------------|--------------|---------|--------|
|  0   | `000` | `00001111` | `00000101` | `00010100`   | `0`     | `0`    |
| 20   | `001` | `00001111` | `00001111` | `00000000`   | `0`     | `1`    |
| 40   | `010` | `00001111` | `00001111` | `00001111`   | `0`     | `0`    |
| 60   | `101` | `10110000` | n/a        | `01100000`   | `0`     | `0`    |
| 80   | `111` | `10110000` | n/a        | `10110000`   | `0`     | `0`    |

## さらに進める

- **符号付き** フラグを追加する(2の補数 SUB の負の結果)。
- **回転** オペコードを追加する — SHL と同様だが最上位ビットがビット 0 に戻る。
- 2 つの別個の出力ポートで 16 ビット結果を生成する **乗算** オペコードを追加する。小型の FPGA にはこのための専用 DSP ブロックがあることが多い — 再合成したら利用率を見ておきましょう。

この ALU は上級レベルの CPU プロジェクトに直接使えるビルディングブロックです — この設計をきれいに保てば、そちらで接続することになります。
