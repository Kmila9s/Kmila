# サンプル:非同期リセット付き D フリップフロップ

D フリップフロップ(DFF)はデジタル設計で最も一般的な記憶セル。現代の FPGA は数万から数十万を持つ。あらゆるレジスタ、カウンタ、パイプライン段は DFF で組まれる。

## それが行うこと

`clk` の立ち上がりエッジごとに、`d` の値が `q` にコピーされる。エッジ間は `d` が変わっても `q` は値を保持する。

`reset` が High のとき、`q` は即座に `'0'` に強制される — これが**非同期**リセット。

## コード

```vhdl
process(clk, reset)
begin
  if reset = '1' then
    q <= '0';
  elsif rising_edge(clk) then
    q <= d;
  end if;
end process;
```

行ごとに:

- **感度リスト `(clk, reset)`** — process はどちらでも起動する。これがリセットを非同期にする。
- **`if reset = '1'`** — リセットが優先。リセットピンが High ならクロックや `d` がどうあろうと関係ない。
- **`elsif rising_edge(clk)`** — クロックが 0 から 1 へ変わるときだけ `d` がサンプルされる。

## 波形の追跡

サンプルは最初の 5 µs `reset = '1'` を駆動し、その後解除する。`d` は 10、30、50 µs でトグル。Run の後 Waveforms タブに切り替えて:

- 5 µs 以前:`q = '0'`(リセットで保持)。
- リセット解除後、`q` はクロックの立ち上がりエッジでのみ変わる — エッジでの `d` の値が取り込まれる。
- エッジ間の `d` の変化は無効。

## 同期 vs 非同期リセット

2 つの考え方:

**非同期リセット**(上記のようにエッジブロックの外で `if reset = '1'`):
- 長所:クロックが走っていなくてもリセットする。電源投入をきれいに扱える。
- 短所:非常に高いクロック周波数でタイミングを満たすのが難しい;Xilinx は 7-series 以降で避けることを推奨。

**同期リセット**(`if rising_edge(clk) then if reset = '1'…`):
- 長所:クロックエッジでの他の入力と同じように振る舞う;シンセサイザと相性が良い。
- 短所:リセットするためにクロックが動いている必要がある。

学習中は非同期の方が推論しやすい。プロダクション FPGA 仕事では、ベンダのガイドラインを読む。

## あなたの番

- **enable** 入力を追加。`enable = '1'` の立ち上がりエッジでのみ `q` が更新される。
- 1 ビットではなく **4 ビットバスをレジスタ化**。`d` と `q` を `std_logic_vector(3 downto 0)` に変え、リセット値を `(others => '0')` に調整。
- `q_not` 出力を追加し、常に `q` の反転にする。ボーナス:`q_not` を `d` に配線し、2 分周クロックが出来上がるのを見る。
