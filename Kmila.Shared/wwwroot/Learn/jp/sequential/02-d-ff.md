# サンプル:非同期リセット付き D フリップフロップ

D フリップフロップ(DFF)は、デジタル設計で最もありふれたメモリセルだ — 第 IV 単元の「フリップフロップ型のメモリ素子(elementos de memoria tipo Flip-Flop)」の花形だ。現代の FPGA は、これを数万から数十万個持っている。あらゆるレジスタ、カウンタ、パイプラインステージが DFF で作られている。

## フリップフロップとラッチ(ここだけは押さえたい一つの区別)

どちらも 1 ビットを蓄えるが、聴き方が違う。

- **ラッチ** は *レベル感応* だ。イネーブルが High の間、出力は入力に追従し(「透過的」)、イネーブルが Low のときだけ保持する。
- **フリップフロップ** は *エッジ感応* だ。入力を一瞬 — クロックエッジ — でサンプルし、サイクルの残りの間は保持する。

このレッスンではフリップフロップを作る。次の修正演習では、*うっかり* ラッチを作ってしまうと何が起こるかを見せる。この違いを頭に入れておこう。エッジトリガ = フリップフロップ、レベルトリガ = ラッチだ。

## 何をするか

`clk` の立ち上がりエッジごとに、`d` の値が `q` にコピーされる。エッジの合間は、`d` が変わっても `q` はその値を保持する。`reset` が High のときは、`q` は即座に `'0'` に強制される — これが **非同期** リセットだ。

## コード

```vhdl
process(clk, reset)
begin
  if reset = '1' then
    q <= '0';
  elsif rising_edge(clk) then
    q <= d;
  end if;
end process;
```

1 行ずつ:

- **感度リスト `(clk, reset)`** — process はどちらでも起きる。`reset` をリストに入れることが、リセットを非同期にする。それは次のクロックエッジではなく、`reset` が立ち上がった瞬間に作用する。
- **`if reset = '1'`** — リセットが優先だ。リセットピンが High なら、クロックや `d` が何をしていようと構わない。
- **`elsif rising_edge(clk)`** — クロックが 0 から 1 に変わったときだけ、`d` が `q` にサンプルされる。

## セットアップとホールド:なぜエッジに余裕が要るのか

フリップフロップが `d` を確実に捕らえられるのは、`d` がエッジの **前**(セットアップ時間)と **後**(ホールド時間)の短い窓の間、安定しているときだけだ。その窓を破ると、出力は *メタステーブル* になり得る — 予測不能に落ち着くまで、`'0'` と `'1'` の間をさまよう。このサンプルではこれらの時間をモデル化しないが、実際の設計が非同期入力を使う前に 2 つのフリップフロップを通してレジスタ化する(「同期化器(synchronizer)」)理由はこれだ。名前だけでも今知っておくとよいだろう。また出会う。

## 波形の読み解き

サンプルは最初の 5 µs の間 `reset = '1'` を駆動し、その後解放する。`d` は 10、30、50 µs で切り替わる。Run の後に Waveforms タブに切り替えて、次に注目しよう。

- 5 µs より前は `q = '0'`(リセットに保持されている)。
- リセットが解放された後、`q` はクロックの立ち上がりエッジでしか変わらない — *エッジの瞬間の* `d` の値が捕らえられる。
- クロックエッジの合間の `d` の変化は `q` に影響しない。

## 同期リセット対非同期リセット

2 つの流派があり、選択には現実の帰結がある。

**非同期リセット**(上のように、エッジブロックの外に `if reset = '1'`):
- 長所:クロックが動いていなくてもリセットできる。電源投入時もきれいに扱える。
- 短所:リセットの *解放* がクロックに整列しないので、異なるフリップフロップが別々のエッジでリセットを抜けることがある — メタステービリティのリスク — し、最大クロック周波数を制限することもある。

**同期リセット**(`if rising_edge(clk) then if reset = '1' then …`):
- 長所:他のあらゆる同期入力と同じように振る舞う。フリップフロップの組み込みリセットに直接マッピングされ、タイミングクロージャとうまく折り合う。
- 短所:効力を持つにはクロックが動いている必要がある。

*学習* には非同期リセットのほうが考えやすく、だからこのサンプルはそれを使っている。*本番の FPGA の仕事* では、ベンダのガイダンス(たとえば AMD/Xilinx の "Get Smart About Reset" ホワイトペーパーやその後の方法論ガイド)はおおむね **同期** リセットを好み、自走する論理の一部にはリセットがまったく要らないこともある。ターゲットデバイスの推奨に従おう。

## 他のフリップフロップ

コースは SR、JK、T フリップフロップも扱う。これらはすべて、前段に次状態を計算する少しの組合せ論理を付けた D フリップフロップだ。

- **T(トグル):** `d = q xor t` → `t=0` で保持、`t=1` で反転。
- **JK:** `d = (j and not q) or (not k and q)`。
- **SR:** セット / リセット。`s=r=1` のケースは定義で除外。

だから、きれいな D フリップフロップが書ければ、これらのどれでも作れる。

## あなたの番

- **enable** 入力を追加しよう。`q` は `enable = '1'` のときだけ立ち上がりエッジで更新されるようにする。
- **4 ビットバスをレジスタ化** しよう。`d` と `q` を `std_logic_vector(3 downto 0)` に、リセット値を `(others => '0')` に変える。
- 常に `not q` となる `q_not` 出力を追加しよう。おまけ:`q_not` を `d` に配線で戻すと、それが **2 分周** クロックになる様子を観察できる — 変装した T フリップフロップだ。
- リセットを **同期** に変えて、リセット解放時の波形を比較しよう。

## 覚えておくべきこと

- D フリップフロップはクロックエッジで `d` をサンプルし、エッジの合間は保持する — レベル感応のラッチと違い、エッジトリガだ。
- `process(clk, reset)` でリセットを `rising_edge` の *前に* テストすると非同期リセットになり、エッジの *中に* 置くと同期リセットになる。
- セットアップ / ホールドを尊重し、メタステービリティを避けるために非同期入力を同期化しよう。
- SR、JK、T フリップフロップは、D フリップフロップに次状態論理を足しただけのものだ。
