# サンプル: 非同期リセット付き D フリップフロップ

D フリップフロップ (DFF) はデジタル設計で最も一般的なメモリセルです。現代の FPGA には数万から数十万個あります。すべてのレジスタ、カウンタ、パイプラインステージは DFF で構築されています。

## 何をするか

`clk` の立ち上がりエッジごとに、`d` の値が `q` にコピーされます。エッジ間では、`d` が変化しても `q` は値を保持します。

`reset` がハイのとき、`q` は即座に `'0'` に強制されます — これが **非同期** リセットです。

## コード

```vhdl
process(clk, reset)
begin
  if reset = '1' then
    q <= '0';
  elsif rising_edge(clk) then
    q <= d;
  end if;
end process;
```

1 行ずつ:

- **センシティビティリスト `(clk, reset)`** — プロセスはどちらでも起きます。これがリセットを非同期にします。
- **`if reset = '1'`** — リセットが優先。リセットピンがハイなら、クロックや `d` が何をしているかは気にしません。
- **`elsif rising_edge(clk)`** — クロックが 0 から 1 になるときだけ `d` がサンプルされます。

## 波形の追いかけ

サンプルは最初の 5 µs の間 `reset = '1'` を駆動し、その後解放します。`d` は 10、30、50 µs でトグルします。Run の後に Waveforms タブに切り替えて、以下に注目してください:

- 5 µs 以前: `q = '0'` (リセットで保持)。
- リセット解放後: `q` はクロック立ち上がりエッジでのみ変化 — エッジ時点の `d` の値がキャプチャされる。
- クロックエッジ間の `d` の変化は効果なし。

## 同期 vs 非同期リセット

2 つの考え方があります:

**非同期リセット** (上のように、エッジブロックの外に `if reset = '1'`):
- 利点: クロックが動いていなくてもリセットする。電源投入をきれいに扱う。
- 欠点: 非常に高いクロック速度でタイミングを満たすのが難しい; Xilinx の 7 シリーズ以降では避けるのが推奨。

**同期リセット** (`if rising_edge(clk) then if reset = '1'…`):
- 利点: クロックエッジ上の他の入力と同様に振る舞う; シンセサイザと相性が良い。
- 欠点: リセットにクロックが動いている必要がある。

学習には非同期リセットの方が推論しやすいです。本番 FPGA 作業では、ベンダーのガイダンスを読んでください。

## 自分でやってみる

- **イネーブル** 入力を追加する。`q` は `enable = '1'` のときだけ立ち上がりエッジで更新されるべき。
- 単一ビットの代わりに **4 ビットバスを登録する**。`d` と `q` を `std_logic_vector(3 downto 0)` に変更し、リセット値を `(others => '0')` に調整します。
- 常に `q` の反転である `q_not` 出力を追加する。ボーナス: `q_not` を `d` に戻して配線し、それが 2 分周クロックになるのを見てください。
