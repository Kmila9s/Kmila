# サンプル: 8ビットシフトレジスタ

シフトレジスタは連鎖したフリップフロップの列です。各クロックエッジで保存されたビットが 1 つ位置をシフトし、一方の端に新しいビットが入ります。UART、SPI コントローラ、CRC エンジン、LFSR ベースの乱数生成器の中核です。

## このサンプルが行うこと

`shift8` は **シリアル入力、パラレル出力** のシフトレジスタです:

- `din` は各クロック立ち上がりエッジで到着する新しいビット。
- `r` は内部 8 ビットレジスタ。
- `q` は `r` をパラレルバイトとして外部に公開。

## 本体

```vhdl
signal r : std_logic_vector(7 downto 0) := (others => '0');
...
process(clk, reset)
begin
  if reset = '1' then
    r <= (others => '0');
  elsif rising_edge(clk) then
    r <= r(6 downto 0) & din;
  end if;
end process;

q <= r;
```

魔法はこの行にあります:

```vhdl
r <= r(6 downto 0) & din;
```

`&` は **連結** 演算子です。`r(6 downto 0)` は現在のレジスタの下位 7 ビットです。右端に `din` を貼り付け、新しい 8 ビット値にして、`r` に代入します。

これはクロック同期プロセス内の信号代入なので、シフトは立ち上がりエッジごとに起こります。

## 波形の追いかけ

シミュレーション設定は `din` をパターン `1, 0, 1, 1, 0, 1, 0, 1` で駆動します。時間を通じて `q` を見てください:

- 最初のティック後: `q = 00000001`
- 2 番目: `q = 00000010`
- 3 番目: `q = 00000101`
- …など。新しいビットは LSB に到着し、古いビットは MSB に向かって行進します。

ズームアウトすると、最上位ビット(ビット 7)が最初の `din` の値を、到着してからちょうど 8 クロックサイクル後に受け取るのが見えます。それが 8 ビットシフトレジスタの往復レイテンシです。

## 自分でやってみる

- **代わりに右シフトする。** 連結を入れ替え: `r <= din & r(7 downto 1);`。
- **パラレルロード。** `load` 入力と `din_parallel` バスを追加します。クロックエッジで `load = '1'` のとき、レジスタはシフトの代わりにバス全体を一度に取り込みます。
- **シリアル出力。** `dout <= r(7);` を追加します。これで SISO (シリアル入力、シリアル出力) シフトレジスタになります — `din` で送った最初のビットが 8 サイクル後に `dout` に現れます。これが UART RX のビット対ビット遅延の仕組みです。
