# サンプル:8 ビットシフトレジスタ

シフトレジスタは、連結された一列のフリップフロップだ。クロックエッジごとに蓄えられたビットが 1 つ分ずれ、新しいビットが一方の端から入ってくる。これは UART、SPI コントローラ、CRC エンジン、LFSR ベースの乱数発生器の中核にある — 前のレッスンのフリップフロップが実務で報われるところだ。

## このサンプルがすること

`shift8` は **シリアル入力・パラレル出力**(SIPO)のシフトレジスタだ。

- `din` は、立ち上がりクロックエッジごとに到着する新しいビットだ。
- `r` は内部の 8 ビットレジスタだ。
- `q` は `r` をパラレルなバイトとして外へ公開する。

ビットが 1 つずつ入るので「シリアル入力」、8 つ全部を一度に読めるので「パラレル出力」だ。これはまさに UART 受信機がすることだ。線から 1 ビットずつクロックで取り込み、組み上がったバイトをシステムの残りの部分へ渡す。

## 本体

```vhdl
signal r : std_logic_vector(7 downto 0) := (others => '0');
...
process(clk, reset)
begin
  if reset = '1' then
    r <= (others => '0');
  elsif rising_edge(clk) then
    r <= r(6 downto 0) & din;
  end if;
end process;

q <= r;
```

魔法はこの行にある。

```vhdl
r <= r(6 downto 0) & din;
```

`&` は **連結(concatenation)** 演算子だ。`r(6 downto 0)` は現在のレジスタの下位 7 ビットだ。その右端に `din` をくっつけて新しい 8 ビットの値を作り、`r` に代入し直す。これはクロック付き process の中の信号代入なので、シフトは立ち上がりエッジごとに起こる — そして信号はステップの終わりに更新されるので、右辺は *古い* `r` を使う。これはまさにシフトが必要とするものだ。

## これはただの、連なった 8 つのフリップフロップ

1 行の本体にハードウェアを隠されないようにしよう。`r` は 8 つの D フリップフロップだ。この代入は、各フリップフロップの出力を次のフリップフロップの入力へ配線し、`din` が最初のものに供給し、ビット 7 が端から落ちていく(ここでは捨てられる)。その連なりが *まさに* シフトレジスタであり、連結はその配線を簡潔に記述する手段にすぎない。

## 波形の読み解き

シミュレーション設定は `din` をパターン `1, 0, 1, 1, 0, 1, 0, 1` に通す。`q` を時間を追って見てみよう。

- 最初のティックの後:`q = 00000001`
- 2 番目の後:`q = 00000010`
- 3 番目の後:`q = 00000101`
- …といった具合だ。新しいビットは LSB に着地し、古いビットは MSB に向かって行進する。

ズームアウトすると、最初の `din` の値が、到着したちょうど 8 クロックサイクル後に最上位ビット(ビット 7)に達する様子が見える。これが 8 ビットシフトレジスタの往復レイテンシであり、シリアルリンクが固定された予測可能な遅延を持つ理由だ。

## 落とし穴:間違った向きにシフトする

初心者はよく向きを逆にして 1 ビット失う。`r <= r(7 downto 1) & din;` と書くと、*上位* 7 ビットを残してビット 0 を落としたことになる — これは左ではなく *右* へのシフトだ。どちらの端から新しいデータが入り、どちらの端が落ちるかを決めてから、スライスをそれに合わせよう。正しい 2 つの形はこうだ。

```vhdl
r <= r(6 downto 0) & din;   -- 左シフト:din -> LSB、MSB を捨てる
r <= din & r(7 downto 1);   -- 右シフト:din -> MSB、LSB を捨てる
```

## あなたの番

- **代わりに右へシフト。** 上の 2 つ目の形を使い、歩くビットが今度は反対へ動くことを確認しよう。
- **パラレルロード(PISO / ユニバーサル)。** `load` 入力と `din_par` バスを追加する。クロックエッジで `load = '1'` のとき `r <= din_par`(バス全体を一度に取る)、そうでなければシフトする。これが *パラレル入力・シリアル出力* の送信機の心臓部だ。
- **シリアル出力。** `dout <= r(7);` を追加する。これでシリアル入力・シリアル出力(SISO)になる — `din` で送った最初のビットが 8 サイクル後に `dout` に現れる。UART の RX が頼りにする遅延だ。
- **LFSR を作る。** `din` の代わりに `r(7) xor r(5) xor r(4) xor r(3)` を入力へフィードバックする。これで疑似乱数列生成器 — CRC やテストパターンに使われるのと同じ構造 — ができる。

## 覚えておくべきこと

- シフトレジスタは D フリップフロップの連なりだ。各エッジですべてのビットが 1 つずれ、一方の端から新しいビットを受け入れる。
- `r <= r(6 downto 0) & din;` は左シフト(新しいビットは LSB)だ。スライスと順序を入れ替えると右シフトになる。
- パラレルロードを追加すると SIPO / PISO 変換器になる — UART や SPI のようなシリアルリンクの中核だ。
- 選んだタップを XOR でフィードバックすれば、CRC や疑似乱数列のための LFSR になる。
