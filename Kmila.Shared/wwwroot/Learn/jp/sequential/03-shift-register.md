# サンプル:8 ビットシフトレジスタ

シフトレジスタは連鎖された一列のフリップフロップ。各クロックエッジで保存されたビットが 1 つずれ、片端から新しいビットが入る。UART、SPI コントローラ、CRC エンジン、LFSR ベース乱数生成器の中核にある。

## このサンプルが行うこと

`shift8` は **シリアル入力、パラレル出力** のシフトレジスタ:

- `din` は各立ち上がりエッジで到着する新しいビット。
- `r` は内部 8 ビットレジスタ。
- `q` は外側にパラレルバイトとして `r` を公開する。

## 本体

```vhdl
signal r : std_logic_vector(7 downto 0) := (others => '0');
...
process(clk, reset)
begin
  if reset = '1' then
    r <= (others => '0');
  elsif rising_edge(clk) then
    r <= r(6 downto 0) & din;
  end if;
end process;

q <= r;
```

魔法はこの行:

```vhdl
r <= r(6 downto 0) & din;
```

`&` は**連結**演算子。`r(6 downto 0)` は現レジスタの下位 7 ビット。`din` を右端にくっつけ、新しい 8 ビット値を作り、`r` に代入する。

これはクロック付き process 内の signal 代入なので、シフトは立ち上がりエッジごとに起きる。

## 波形の追跡

シミュレーション config は `din` をパターン `1, 0, 1, 1, 0, 1, 0, 1` で駆動。時間に沿って `q` を見ると:

- 1 ティック後:`q = 00000001`
- 2 ティック後:`q = 00000010`
- 3 ティック後:`q = 00000101`
- …と続く。新しいビットは LSB に着地;古いビットは MSB に向かって進む。

ズームアウトすると、最上位ビット(ビット 7)が最初の `din` 値をちょうど 8 クロックサイクル後に取るのが見える。これが 8 ビットシフトレジスタのラウンドトリップレイテンシ。

## あなたの番

- **右にシフト**。連結を入れ替え:`r <= din & r(7 downto 1);`。
- **パラレルロード**。`load` 入力と `din_parallel` バスを追加。クロックエッジで `load = '1'` なら、レジスタはシフトせずバス全体を一度に取り込む。
- **シリアル出力**。`dout <= r(7);` を追加。これでシリアル入力・シリアル出力(SISO)シフトレジスタになり、`din` に送った最初のビットが 8 サイクル後に `dout` に現れる。UART RX のビット単位遅延はこう動く。
