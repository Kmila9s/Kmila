# サンプル: 4ビット リップルキャリー加算器

2 つの 2 進数を加算することはデジタル算術の「hello world」です。このサンプルはキャリーインとキャリーアウトを持つ 4 ビット加算器を構築します — より大きな ALU の内部や、CPU のアドレスインクリメントロジックにタイル状に並べる、まさにそのセルです。

## インタフェース

```
port (
  a    : in  std_logic_vector(3 downto 0);
  b    : in  std_logic_vector(3 downto 0);
  cin  : in  std_logic;
  sum  : out std_logic_vector(3 downto 0);
  cout : out std_logic
);
```

## 本体

```vhdl
signal t : unsigned(4 downto 0);
...
t    <= resize(unsigned(a), 5) + resize(unsigned(b), 5) + ("0000" & cin);
sum  <= std_logic_vector(t(3 downto 0));
cout <= t(4);
```

何をしているか:

- `unsigned(a)` と `unsigned(b)` はベクタを `+` 演算子用の数値型に変換します。
- `resize(…, 5)` は 5 ビットにパディングし、和が最上位ビットにオーバーフローできるようにします。
- `("0000" & cin)` は LSB に `cin` だけを持つ 5 ビットのマスクを構築します。
- 加算後、`t(3 downto 0)` が和、`t(4)` がキャリーアウトです。

## なぜ 5 ビットなのか?

キャリーイン付きで 2 つの 4 ビット数を加算すると、結果は `1111 + 1111 + 1 = 11111` という 5 ビットの大きさになり得ます。4 ビットのコンテナで計算すると、最上位ビットが暗黙のうちに失われます。resize は安全な慣用句です。

## サンプルが行うこと

シミュレーション設定は `a` と `b` を 4 つのパターンで駆動します(`3+5 = 8`、その後キャリーを生成する `10 + 6 = 16`、さらに `10 + 15 = 25`…)。波形は `sum` と `cout` が組合せ的に変化する様子を示します — この設計にはレジスタがないのでクロックは不要です。

## 自分でやってみる

- **パラメトリックにする。** エンティティに `generic (N : integer := 4)` を追加し、4 が現れるすべての場所で `N` を使います。これでどんな幅でもインスタンス化できる `adder_N` ができます。
- **減算器を作る。** `b` を反転しさらに `+1` を加える — これが 2 の補数減算です。ビットごとの NOT 1 つ以外に追加のハードウェアはいりません。
- **2 つを配線する。** 下位ニブル用に 1 つ、上位ニブル用に 1 つ置くと、その間でリップルキャリーする 8 ビット加算器ができます。
