# サンプル:4 ビットリップルキャリー加算器

2 つのバイナリ数を加算するのはデジタル算術の「hello world」。このサンプルはキャリーインとキャリーアウト付きの 4 ビット加算器を作る — より大きな ALU の中や CPU のアドレスインクリメントロジックの中で並べるまさにそのセル。

## インタフェース

```
port (
  a    : in  std_logic_vector(3 downto 0);
  b    : in  std_logic_vector(3 downto 0);
  cin  : in  std_logic;
  sum  : out std_logic_vector(3 downto 0);
  cout : out std_logic
);
```

## 本体

```vhdl
signal t : unsigned(4 downto 0);
...
t    <= resize(unsigned(a), 5) + resize(unsigned(b), 5) + ("0000" & cin);
sum  <= std_logic_vector(t(3 downto 0));
cout <= t(4);
```

何が起きているか:

- `unsigned(a)` と `unsigned(b)` がベクトルを `+` 演算子用の数値型に変える。
- `resize(…, 5)` は 5 ビットにパディング、合計が上位ビットへオーバーフローできるように。
- `("0000" & cin)` は LSB だけ `cin` の 5 ビットマスクを構築。
- 加算後、`t(3 downto 0)` は合計、`t(4)` がキャリーアウト。

## なぜ 5 ビット?

4 ビット 2 つにキャリーインを加えると、最大で `1111 + 1111 + 1 = 11111` — 5 ビット。4 ビットのコンテナで計算すると、上位ビットを黙って失う。resize は安全なイディオム。

## サンプルが行うこと

シミュレーション config は `a` と `b` を 4 つのパターン(`3+5 = 8`、次にキャリーを生む `10 + 6 = 16`、次に `10 + 15 = 25`…)で駆動する。波形は `sum` と `cout` が組合せ的に変化するのを示す — レジスタがないのでクロックは不要。

## あなたの番

- **パラメータ化する。** entity に `generic (N : integer := 4)` を追加し、4 が現れるところすべてで `N` を使う。これで任意の幅でインスタンス化できる `adder_N` が手に入る。
- **減算器を作る。** `b` を反転して `+1` を加える — これが 2 の補数減算。1 ビットあたり NOT 1 つ以外、追加ハードウェアなし。
- **2 つを配線する。** 下位ニブル用 1 つと上位ニブル用 1 つで、それらの間でリップルキャリーする 8 ビット加算器が手に入る。
