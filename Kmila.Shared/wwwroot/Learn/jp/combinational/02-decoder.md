# サンプル: 3-to-8 デコーダ

デコーダは小さな2進コードを受け取り、**ワンホット** 出力に変換します: 正確に 1 つの出力がハイで、その位置がコードと一致します。

```
  sel  │  y
  000  │  00000001
  001  │  00000010
  010  │  00000100
  011  │  00001000
  100  │  00010000
  101  │  00100000
  110  │  01000000
  111  │  10000000
```

デコーダはあらゆるメモリシステムの内部に存在します — アドレス線がデコーダを駆動し、「行一致」出力が正確に 1 つの行を有効にします。「アドレスデコーダ」という言葉を聞いたら、その下にあるのはこれです。

## VHDL

デコーダは `with/select` の教科書的な例です:

```vhdl
with sel select
  y <=
    "00000001" when "000",
    "00000010" when "001",
    "00000100" when "010",
    "00001000" when "011",
    "00010000" when "100",
    "00100000" when "101",
    "01000000" when "110",
    "10000000" when others;
```

末尾の `when others` に注意してください。`sel` は `std_logic_vector(2 downto 0)` — 3 ビット — なので 2³ = 8 通りの 2 進値がありますが、`std_logic` には 9 の状態があるため、コンパイラはすべての組み合わせをカバーする `others` 句を必要とします(`"111"` と同じものに合成されます)。

## サンプルが行うこと

サンプルは `sel` を 3 ビットの 8 つの値すべてにわたって、各値 10 µs ずつサイクルします。Waveforms タブでは `y` の 8 ビットが歩く `'1'` に変わるのが見えます — デジタル版「光が追いかけっこ」です。

## 自分でやってみる

動いたら:

- デコーダを 4-to-16 に拡張する。手作業でもいいですし、本体を `y <= std_logic_vector(shift_left(to_unsigned(1, 16), to_integer(unsigned(sel))));` と書き直すこともできます。どちらも同じ合成結果になります — 読みやすいと思う方を選んでください。
- `enable` 入力を追加する。`enable = '0'` のとき、`sel` に関係なくすべての出力は低になる。
