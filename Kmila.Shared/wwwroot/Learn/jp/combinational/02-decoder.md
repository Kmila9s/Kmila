# サンプル:3-8 デコーダ

デコーダは小さなバイナリコードを取り、**ワンホット**出力に変える:ちょうど 1 つの出力が High になり、その位置がコードに対応する。

```
  sel  │  y
  000  │  00000001
  001  │  00000010
  010  │  00000100
  011  │  00001000
  100  │  00010000
  101  │  00100000
  110  │  01000000
  111  │  10000000
```

デコーダはすべてのメモリシステムの中に住んでいる — アドレス線がデコーダを駆動し、「行マッチ」出力がちょうど 1 つの行を有効化する。「アドレスデコーダ」と聞いたら、下にあるのはこれ。

## VHDL

デコーダは `with/select` の教科書事例:

```vhdl
with sel select
  y <=
    "00000001" when "000",
    "00000010" when "001",
    "00000100" when "010",
    "00001000" when "011",
    "00010000" when "100",
    "00100000" when "101",
    "01000000" when "110",
    "10000000" when others;
```

末尾の `when others` に注意。`sel` は `std_logic_vector(2 downto 0)` — 3 ビット — なので 2³ = 8 個のバイナリ値だが、`std_logic` には 9 状態あるため、コンパイラはあらゆる組み合わせをカバーするために `others` 節を必要とする(`"111"` と同じものに合成される)。

## サンプルが行うこと

サンプルは `sel` を 3 ビットの全 8 値で循環、各値 10 µs。Waveforms タブで `y` の 8 ビットが歩いていく `'1'` になるのが見える — デジタル「ライトチェイサー」。

## あなたの番

動いたら:

- 4-16 デコーダに広げる。手作業でやるか、本体を `y <= std_logic_vector(shift_left(to_unsigned(1, 16), to_integer(unsigned(sel))));` と書き直す。両方とも同じに合成される — 読みやすい方を選ぶ。
- `enable` 入力を追加。`enable = '0'` のときはすべての出力を Low に(`sel` に関係なく)。
