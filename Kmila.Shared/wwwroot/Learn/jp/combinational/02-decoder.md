# サンプル:3-8 デコーダ

デコーダは、小さな 2 進コードを受け取って **one-hot** 出力に変える。ちょうど 1 本の出力線だけが High になり、その位置がコードに対応する。これは組合せの単元で名前の付いている回路の一つ(「エンコーダとデコーダ(codificador y decodificador)」)で、逆の動作をするエンコーダの自然な相棒だ。

```
  sel  │  y
  000  │  00000001
  001  │  00000010
  010  │  00000100
  011  │  00001000
  100  │  00010000
  101  │  00100000
  110  │  01000000
  111  │  10000000
```

デコーダはあらゆるメモリシステムの内部に住んでいる — アドレス線がデコーダを駆動し、「行の一致」出力がちょうど 1 本のワード線を有効にする。「アドレスデコーダ」と聞いたら、その下にあるのはこれだ。同じ構造はミンターム(最小項)の完全な集合も実装する。n 入力デコーダは入力の 2ⁿ 個すべてのミンタームを出力するので、適切なデコーダ出力を OR することで、任意のブール関数を作れる。

## VHDL

デコーダは `with/select` の教科書的なケースだ。

```vhdl
with sel select
  y <= "00000001" when "000",
       "00000010" when "001",
       "00000100" when "010",
       "00001000" when "011",
       "00010000" when "100",
       "00100000" when "101",
       "01000000" when "110",
       "10000000" when others;
```

最後の `when others` に注目しよう。`sel` は `std_logic_vector(2 downto 0)` — 3 ビット — なので、*意図された* 値は 2³ = 8 個だが、各ビットが 9 値の `std_logic` であるため、コンパイラにはもっと多くの可能なパターンが見えており、網羅的であるために `others` が必要だ。ここでは `others` は `"111"` のケースと一緒に畳み込まれる(同じ出力に合成される)。

## スケールする代替案

8 行を書き出すのは 3-8 デコーダなら問題ないが、スケールしない。同じ関数を、シフトを使って 1 行で書くとこうなる。

```vhdl
y <= std_logic_vector(shift_left(to_unsigned(1, 8), to_integer(unsigned(sel))));
```

内側から外へ読もう。`sel` を数値として取り、8 ビットの枠の中で 1 つの `'1'` をその数だけ左へシフトし、`std_logic_vector` に戻す。どちらの版も同一に合成されるので、読みやすいと思うほうを選べばよいのだ。(明示的な表のほうが、初心者には真理値表と照らし合わせて検証しやすく、シフト形式は 32 や 64 出力へと広げたいときのものだ。)

## このサンプルがすること

サンプルは `sel` を 3 ビットの 8 つの値すべてにわたって、1 値あたり 10 µs で巡回させる。Waveforms タブでは、`y` の 8 ビットが歩く `'1'` に変わる様子 — デジタルの「光の追いかけっこ」 — が見られる。

## enable を追加する(そしてデマルチプレクサに出会う)

実際のデコーダには **enable** がある。無効のとき、すべての出力は Low になる。

```vhdl
y <= (others => '0') when enable = '0' else
     std_logic_vector(shift_left(to_unsigned(1, 8), to_integer(unsigned(sel))));
```

ここに素敵なつながりがある。enable 付きのデコーダで、その enable が定数ではなく *データ* 線になったものは、**デマルチプレクサ** だ — enable の値がアドレスの選ぶ 1 本の出力へ振り分けられ、残りは `'0'` のままになる。デコーダとデマルチプレクサは、別のラベルを着けた同じハードウェアなのだ。

## 覚えておくべきこと

- デコーダは n ビットのコードを one-hot の 2ⁿ 出力にマッピングする。その出力は入力のミンタームだ。
- `with/select` に必須の `when others` を付けるのが、真理値表の形で書く分かりやすい書き方だ。
- `shift_left(to_unsigned(1, N), …)` のイディオムが、任意の幅にスケールする版だ。
- データ駆動の enable を持つデコーダはデマルチプレクサだ。その鏡像はエンコーダだ。
