# إسنادات تزامنيَّة: `when/else` و `with/select`

تُكتب المنطق التوافقي في VHDL بالسطور التزامنيَّة — كل سطر خارج process يصف قطعة عتاد مربوطة بشكل دائم. توجد نكهتان من الصياغة للعمل ذاته: إسناد **شرطي** و**انتقائي**.

## `when/else` — شرطي

جيد حين يكون لديك قائمة شروط ذات أولويَّة، أو حين يفحص كل فرع إشارة مختلفة:

```vhdl
y <= '0' when reset = '1' else
     a   when mode  = "read" else
     b   when mode  = "write" else
     'Z';
```

أوَّل شرط مطابق يفوز. الترتيب مهمٌّ — يُترجَم إلى **MUX بأولوية**: للشرط الأعلى أقصر مسار إلى `y`.

## `with/select` — انتقائي

جيد حين تُبدِّل حسب تعبير واحد (تمامًا كما يفعل `switch` في البرمجيَّات):

```vhdl
with mode select
  y <=
    a   when "00",
    b   when "01",
    c   when "10",
    'Z' when others;
```

كل الحالات تقارن بنفس الإشارة (`mode`)، و `when others` إلزامي لتغطية كل نمط ممكن. يُترجَم هذا الأسلوب إلى **MUX متوازن** — لا فرع له امتياز.

## أيُّهما تختار؟

- **نفس الإشارة، أنماط عديدة:** `with/select` تُقرأ كجدول حقيقة. استخدمها.
- **إشارات مختلفة، منطق أولوية:** `when/else`. ملائمة طبيعيَّة.
- **خرج التركيب:** كلاهما يُنتج تقريبًا نفس البوابات على FPGA حديث — اختيار الشكل الأوضح في الشفرة المصدريَّة هو الصواب دومًا.

## فخّ صغير

كلا الصيغتَين تتطلَّب أن يكون `y` مُسندًا في **كل** سيناريو. إن نسيت `else` الأخيرة في `when/else`، أو تخطَّيت `when others` في `with/select`، سيُحذِّرك المُترجم — وقد يستنتج المُركِّب مزلاجًا «ليتذكَّر» القيمة السابقة، وهو نادرًا ما تريده. هذا نفس فخّ المزلاج الذي ستراه في تمرين «أصلحه» بالوحدة التتابعيَّة.

## أين يظهر بعد ذلك

ستستخدم `with/select` في مثال المُفكِّك 3 إلى 8 بعد هذا الدرس مباشرة، و `when/else` في كل مكان من FSM إشارة المرور لاحقًا. كلاهما من VHDL الأساسي.
