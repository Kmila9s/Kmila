# الإسنادات التزامنيَّة: `when/else` و`with/select`

يُكتَب المنطق التوافقي في VHDL بعبارات تزامنيَّة — فكل سطر خارج معالجة يصف قطعة عتاد مربوطة بشكل دائم. وتوجد نكهتان من الصياغة للعمل نفسه: الإسناد **الشرطي** (`when/else`) والإسناد **الانتقائي** (`with/select`). هاتان هما «العبارات التزامنيَّة (sentencias concurrentes)» من وحدة HDL، وهما العمود الفقري لكل دائرة توافقيَّة في المساق: الجوامع، ومحوِّلات الرموز، والمقارنات، والمُجمِّعات، والمُرمِّزات، والمُفكِّكات.

## `when/else` — شرطي

جيِّد حين يكون لديك قائمة شروط ذات أولويَّة، أو حين يفحص كل فرع إشارة *مختلفة*:

```vhdl
y <= (others => '0') when reset = '1' else
     a               when sel = "00"  else
     b               when sel = "01"  else
     c               when sel = "10"  else
     d;
```

أوَّل شرط مطابق يفوز. الترتيب مهمٌّ — فهو يُخلَّق إلى **مُجمِّع أولويَّة**: الشرط الأعلى له أقصر مسار إلى `y`. لاحظ أن كل تعابير القيمة (`a` و`b` و`c` و`d` وتجميع الأصفار) يجب أن تكون من **النوع والعرض نفسهما** لـ `y`، وأن `else` الأخيرة بلا شرط — فهي الحالة الجامعة.

## `with/select` — انتقائي

جيِّد حين تُبدِّل بناءً على تعبير واحد (كما تفعل عبارة `switch`/`case` في البرمجيَّات):

```vhdl
with sel select
  y <= a   when "00",
       b   when "01",
       c   when "10",
       'Z' when others;
```

كل الاختيارات تُقارَن بالتعبير نفسه (`sel`)، وتُفصَل الفروع بـ**فواصل** (لا بـ `else`)، و`when others` **إلزاميَّة** لتغطية كل قيمة ممكنة. يُخلَّق هذا الأسلوب إلى **مُجمِّع متوازن** — لا فرع له امتياز.

### لماذا `when others` غير قابلة للتفاوض

الـ `sel` هنا هو `std_logic_vector(1 downto 0)`. قد تظنُّ أن هذه أربع حالات — `"00"` و`"01"` و`"10"` و`"11"`. لكن كل بِت هو `std_logic` *ذو تسع قيم*، فيحسب المترجم ‎9² = 81‎ نمطًا ممكنًا (`"0X"` و`"ZU"` …). لا يمكنك تعدادها، فتصير `when others` مطلوبة لجعل العبارة شاملة. وفي التخليق تتلاشى القيم الوصفيَّة (metavalues) وتحصل على المُجمِّع الرباعي النظيف الذي قصدته.

يمكنك أيضًا تجميع الاختيارات بعامل الشَّرطة العموديَّة:

```vhdl
with opcode select
  result <= a + b    when "000" | "001",   -- رمزان، الخرج نفسه
            a - b    when "010",
            (others => '0') when others;
```

## أيُّهما تختار؟

- **إشارة واحدة، أنماط عديدة** (مُفكِّك، مُجمِّع، محوِّل رموز): `with/select` تُقرأ كجدول حقيقة. استخدمها.
- **إشارات مختلفة، منطق أولويَّة** (reset يغلب enable يغلب البيانات): `when/else`. ملاءمة طبيعيَّة.
- **خرج التخليق:** على FPGA حديثة يُنتج كلاهما تقريبًا البوابات نفسها، فاختيار الشكل الأوضح على مستوى المصدر هو الصواب دائمًا تقريبًا. لا تلجأ إلى `when/else` إلَّا حين تريد أولويَّة حقيقيَّة؛ وإلَّا فإن `with/select` تُشير للقارئ التالي إلى «لا أولويَّة».

## فخّ المِزلاج (لمحة)

كلا الشكلَين يتطلَّب أن ينتهي `y` مُسنَدًا في **كل** سيناريو. لا يمكن لـ `when/else` أو `with/select` تزامنيَّة أن تترك `y` دون إسناد فعلًا — فالصياغة تفرض `else` / `when others` أخيرة. لكن ما يعادلها من **`if`/`case` داخل معالجة** *يستطيع* ذلك، و*هناك* يستنتج المُخلِّق مِزلاجًا «ليتذكَّر» القيمة الأخيرة، وهو ما لا تريده في الغالب تقريبًا. هذا نفس فخّ المِزلاج الذي ستواجهه مباشرة في تمرين الإصلاح بالوحدة التتابعيَّة، فحافظ على العادة: أسنِد الخرج على كل مسار.

## ربط محلول سريع: مقارِن 2 بت

مقارِن المقدار من المساق يخرج مباشرة من `when/else`:

```vhdl
-- gt/eq/lt مخرجات std_logic مفردة
gt <= '1' when unsigned(a) > unsigned(b) else '0';
eq <= '1' when a = b else '0';
lt <= '1' when unsigned(a) < unsigned(b) else '0';
```

ثلاث عبارات تزامنيَّة مستقلَّة، ثلاثة مقارِنات، كلها حيَّة دفعة واحدة.

## أين يظهر هذا بعد ذلك

ستستخدم `with/select` في مثال المُفكِّك 3 إلى 8 مباشرة بعد هذا الدرس، و`when/else` في كل أعمال الجامع والمقارِن والمُجمِّع. كلاهما خبز VHDL اليومي.

## ما يجب تذكُّره

- `when/else` = شرطي، ذو أولويَّة، يُسمَح بإشارات مختلفة ← مُجمِّع أولويَّة.
- `with/select` = مُحدِّد واحد، اختيارات مفصولة بفواصل، `when others` إلزاميَّة ← مُجمِّع متوازن.
- يجب أن يطابق كل فرع قيمة نوعَ الهدف وعرضه.
- الأشكال التزامنيَّة لا يمكنها إسقاط الخرج، لكن نسخ `if`/`case` المبنيَّة على معالجة *تستطيع* — وهناك تتسلَّل المزالج.
