# عيّنة: مُفكِّك 3-إلى-8

المُفكِّك يأخذ رمزًا ثنائيًا صغيرًا ويحوّله إلى خرج **أحادي النشاط (one-hot)**: خرج واحد بالضبط يكون مرتفعًا، وموقعه يطابق قيمة الرمز.

```
  sel  │  y
  000  │  00000001
  001  │  00000010
  010  │  00000100
  011  │  00001000
  100  │  00010000
  101  │  00100000
  110  │  01000000
  111  │  10000000
```

توجد المُفكِّكات داخل كل نظام ذاكرة — تقود خطوط العنوان مُفكِّكًا، وخرج "تطابق السطر" يُفعِّل سطرًا واحدًا تمامًا. كلما سمعت "مُفكِّك عنوان"، فهذا ما يوجد تحته.

## كود VHDL

المُفكِّك حالة نموذجية لاستخدام `with/select`:

```vhdl
with sel select
  y <=
    "00000001" when "000",
    "00000010" when "001",
    "00000100" when "010",
    "00001000" when "011",
    "00010000" when "100",
    "00100000" when "101",
    "01000000" when "110",
    "10000000" when others;
```

لاحظ وجود `when others` في النهاية. `sel` من نوع `std_logic_vector(2 downto 0)` — 3 بتات — أي ‎2³ = 8‏ قيم ثنائية، لكن لأن `std_logic` يملك تسع حالات، يحتاج المترجم إلى جملة `others` لتغطية كل تراكيب البتات (ستُجمَّع لتعطي النتيجة نفسها الخاصة بـ `"111"`).

## ما الذي تفعله العيّنة

تدور العيّنة بقيمة `sel` عبر القيم الثمانية ذات 3 بتات، بمعدل 10 ميكروثانية لكل قيمة. في تبويب Waveforms سترى البتات الثمانية من `y` تتحول إلى `'1'` سائر — "مطاردة ضوئية" رقمية.

## دورك

بعد تشغيلها:

- وسِّع المُفكِّك إلى نسخة 4-إلى-16. يمكنك فعل ذلك يدويًا، أو يمكنك إعادة كتابة الجسم كالتالي: `y <= std_logic_vector(shift_left(to_unsigned(1, 16), to_integer(unsigned(sel))));`. كلاهما يُجمَّع بصورة متطابقة — اختر الأسهل قراءة لديك.
- أضف مُدخل `enable`. عندما يكون `enable = '0'`، ينبغي أن تكون جميع الخرجات منخفضة بصرف النظر عن `sel`.
