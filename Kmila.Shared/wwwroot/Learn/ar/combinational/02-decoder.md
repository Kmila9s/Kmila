# مثال: مُفكِّك 3 إلى 8

يأخذ المُفكِّك رمزًا ثنائيًا صغيرًا ويحوِّله إلى خرج **one-hot**: خرج واحد بالضبط مرتفع، وموقعه يطابق الرمز.

```
  sel  │  y
  000  │  00000001
  001  │  00000010
  010  │  00000100
  011  │  00001000
  100  │  00010000
  101  │  00100000
  110  │  01000000
  111  │  10000000
```

تعيش المُفكِّكات داخل كل نظام ذاكرة — خطوط العنوان تقود مُفكِّكًا، وخرج «مطابقة الصفّ» يُمكِّن صفًّا واحدًا بالضبط. كلَّما سمعت «مُفكِّك عنوان»، فهذا ما يكمن وراءه.

## VHDL

المُفكِّك حالة كتاب نصِّي لـ `with/select`:

```vhdl
with sel select
  y <=
    "00000001" when "000",
    "00000010" when "001",
    "00000100" when "010",
    "00001000" when "011",
    "00010000" when "100",
    "00100000" when "101",
    "01000000" when "110",
    "10000000" when others;
```

لاحظ `when others` في النهاية. `sel` هو `std_logic_vector(2 downto 0)` — 3 بتات — فهناك 2³ = 8 قيم ثنائيَّة، لكن لأنَّ `std_logic` لها تسع حالات، يحتاج المُترجم بند `others` لتغطية كل التركيبات (سيُركَّب بنفس ما يُركَّب به `"111"`).

## ماذا يفعل المثال

يُدوِّر المثال `sel` عبر القيم الثمان بـ 3 بتات، 10 µs لكل قيمة. في تبويب أشكال الموجة سترى البتات الـ 8 لـ `y` تتحوَّل إلى `'1'` يتحرَّك — «مُطارد ضوء» رقمي.

## دورك

حالما يعمل:

- وسِّع المُفكِّك إلى 4 إلى 16. يدويًّا، أو أعد كتابة الجسم: `y <= std_logic_vector(shift_left(to_unsigned(1, 16), to_integer(unsigned(sel))));`. كلاهما يُركَّب بنفس الطريقة — اختر ما تجده أوضح.
- أضف دخل `enable`. حين `enable = '0'`، كل الخرجات منخفضة بغضِّ النظر عن `sel`.
