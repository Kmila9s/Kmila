# أنواع البيانات: `std_logic`، المتجهات، `unsigned`، `integer`

VHDL لغة ذات أنواع. عندما ترى منفذًا مُصرَّحًا `in std_logic`، لن يسمح المترجم بوصله بشيء من نوع مختلف. اختيار النوع الصحيح لكل إشارة هو نصف كتابة VHDL نظيف.

## `std_logic` — السلك العالمي

بت واحد من **المنطق التسعي القيم** IEEE. نعم، تسع:

| القيمة | المعنى |
|-------|---------|
| `'0'` | دفع قوي للانخفاض |
| `'1'` | دفع قوي للارتفاع |
| `'Z'` | ممانعة عالية (tristate مغلق) |
| `'L'` | منخفض ضعيف (pull-down) |
| `'H'` | مرتفع ضعيف (pull-up) |
| `'X'` | مجهول / موانع متعدّدة تتنازع |
| `'U'` | غير مُهيَّأة — إشارتك لم تُسنَد أبدًا |
| `'W'` | مجهول ضعيف |
| `'-'` | لا يهم (يُستخدم في عبارات case) |

في التجميع تصل إلى العتاد فقط `'0'` و`'1'` و`'Z'`. الباقي تشخيصات محاكاة — إن رأيت `'U'` في الموجة، لديك إشارة تُقرأ قبل أن تُكتب.

## `std_logic_vector` — ناقل

مصفوفة بعرض ثابت من `std_logic`:

```vhdl
signal data : std_logic_vector(7 downto 0);  -- 8 بت، الفهارس 7..0
signal addr : std_logic_vector(0 to 15);     -- 16 بت، الفهارس 0..15
```

`downto` هو الاتجاه الأكثر شيوعًا بفارق كبير — يطابق كيف نكتب الأرقام (MSB على اليسار).

ثوابت حرفية:

```vhdl
data <= "10101010";     -- ثابت ثنائي، محرف واحد لكل بت
addr <= x"CAFE";        -- ثابت سادس عشر (يجب أن يكون مضاعفًا لـ 4 بتات)
data <= (others => '0');-- اختصار لكل الأصفار
data <= (0 => '1', others => '0'); -- LSB مرتفع فقط
```

## `unsigned` / `signed` — متجهات يمكنك إجراء الحساب عليها

`std_logic_vector` هي "مجرد حقيبة بتات". ليست لها دلالة عددية. للجمع أو الطرح، تحتاج إلى `unsigned` أو `signed`:

```vhdl
use IEEE.NUMERIC_STD.ALL;

signal a, b, sum : unsigned(7 downto 0);
...
sum <= a + b;   -- يعمل
```

الانتقال بينها:

```vhdl
-- متجه → unsigned للحساب
u <= unsigned(slv);

-- unsigned → متجه للعالم الخارجي
slv <= std_logic_vector(u);

-- unsigned → integer للفهرسة أو الثوابت
idx <= to_integer(u);

-- integer → unsigned (حدد العرض)
u <= to_unsigned(42, 8);
```

قاعدة عامة: استخدم `std_logic_vector` في **المنافذ** (الأوسع جمهورًا)، وحوّل إلى `unsigned` / `signed` داخل البنى المعمارية حيث تُجري الحساب فعلًا.

## `integer` — للفهرسة والعدّ

استخدم `integer` (أو نوعًا فرعيًا مقيّدًا) لعدّادات الحلقة والثوابت وأي شيء لن يعبر حدود المنافذ:

```vhdl
constant DEPTH : integer := 32;
for i in 0 to DEPTH - 1 loop ...
```

`integer` غير المقيّد عادةً 32 بت في المحاكاة. للعتاد، تريد نطاقًا مقيّدًا:

```vhdl
signal counter : integer range 0 to 255;
```

المُجمِّع حينها يمنحك 8 بتات بالضبط.

## الترقيمات — لحالات FSM

صرّح نوعًا مقروءًا لآلات الحالات:

```vhdl
type state_t is (S_IDLE, S_START, S_ACTIVE, S_DONE);
signal state : state_t;
```

فتكتب `state <= S_ACTIVE` بدلًا من `state <= "010"`. يختار المُجمِّع الترميز الثنائي نيابةً عنك (ويمكنك التلميح بخاصية إن كنت تهتم).

## ما الذي يجب تذكره

- سلك واحد → `std_logic`. ناقل → `std_logic_vector`.
- تحتاج للحساب؟ استخدم `unsigned` (أو `signed`) و`IEEE.NUMERIC_STD`.
- التصريح عن **المنافذ** بـ `std_logic_vector` يجعل كيانك قابلًا للنقل بأقصى قدر.
- لحالات FSM، استخدم الترقيمات — يُقرأ كودك كمواصفات.
