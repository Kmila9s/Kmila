# أنواع البيانات: `std_logic`، المتجهات، `unsigned`، `integer`

VHDL لغة مكتوبة بأنواع. حين ترى منفذًا مُعلَنًا `in std_logic`، لن يسمح لك المُترجم بربطه بشيء من نوع آخر. اختيار النوع الصحيح لكل إشارة هو نصف كتابة VHDL نظيف.

## `std_logic` — السلك العالمي

بت واحد من منطق IEEE ذي **9 قيم**. نعم، تسع:

| القيمة | المعنى |
|--------|--------|
| `'0'` | دفع قوي منخفض |
| `'1'` | دفع قوي مرتفع |
| `'Z'` | مُمانعة عالية (إيقاف ثلاثي الحالات) |
| `'L'` | منخفض ضعيف (pull-down) |
| `'H'` | مرتفع ضعيف (pull-up) |
| `'X'` | مجهول / مُسلَّطات متعدِّدة متناقضة |
| `'U'` | غير مُهيَّأ — إشارتك لم تُسنَد قطّ |
| `'W'` | مجهول ضعيف |
| `'-'` | لا يهمُّ (يُستخدَم في عبارات case) |

في التركيب، فقط `'0'` و`'1'` و`'Z'` تصل إلى العتاد. الباقي تشخيصات محاكاة — إن رأيت `'U'` في شكل موجة، فلديك إشارة تُقرأ قبل أن تُكتب.

## `std_logic_vector` — ناقل

مصفوفة `std_logic` بعرض ثابت:

```vhdl
signal data : std_logic_vector(7 downto 0);  -- 8 بت، فهرس 7..0
signal addr : std_logic_vector(0 to 15);     -- 16 بت، فهرس 0..15
```

`downto` هو الاتجاه الأكثر شيوعًا — يطابق طريقة كتابة الأعداد (MSB على اليسار).

حرفيَّات:

```vhdl
data <= "10101010";     -- حرفي ثنائي، حرف لكل بت
data <= x"AA";          -- حرفي ست عشري (مضاعف 4 بت)
data <= (others => '0');-- اختصار لكل الأصفار
data <= (0 => '1', others => '0'); -- LSB فقط مرتفع
```

## `unsigned` / `signed` — متجهات يمكنك الحساب عليها

`std_logic_vector` هو «كيس بتات» فقط. ليس له معنى عددي. للجمع أو الطرح، تحتاج `unsigned` أو `signed`:

```vhdl
use IEEE.NUMERIC_STD.ALL;

signal a, b, sum : unsigned(7 downto 0);
...
sum <= a + b;   -- يعمل
```

التنقُّل بينها:

```vhdl
-- متجه → unsigned للحساب
u <= unsigned(slv);

-- unsigned → متجه للعالم الخارجي
slv <= std_logic_vector(u);

-- unsigned → integer للفهرسة أو الثوابت
idx <= to_integer(u);

-- integer → unsigned (حدِّد العرض)
u <= to_unsigned(42, 8);
```

قاعدة عامَّة: استخدم `std_logic_vector` في **المنافذ** (الجمهور الأوسع)، وحوِّل إلى `unsigned` / `signed` داخل architectures حيث تحسب فعلًا.

## `integer` — للفهرسة والعدّ

استخدم `integer` (أو نوعًا فرعيًّا مقيَّدًا) لعدَّادات الحلقات والثوابت وكل ما لا يعبر حدود المنفذ:

```vhdl
constant DEPTH : integer := 32;
for i in 0 to DEPTH - 1 loop ...
```

`integer` غير المقيَّد عادةً 32 بت في المحاكاة. للعتاد، تريد نطاقًا مقيَّدًا:

```vhdl
signal counter : integer range 0 to 255;
```

فيُعطيك المُركِّب 8 بتات بالضبط.

## التعدادات — لحالات FSM

أعلِن نوعًا قابلًا للقراءة لآلات الحالات:

```vhdl
type state_t is (S_IDLE, S_START, S_ACTIVE, S_DONE);
signal state : state_t;
```

ثم تكتب `state <= S_ACTIVE` بدل `state <= "010"`. يختار المُركِّب الترميز الثنائي لك (ويمكنك التلميح بمعامل إن أردت).

## ما يجب تذكُّره

- سلك واحد → `std_logic`. ناقل → `std_logic_vector`.
- تحتاج الحساب؟ استخدم `unsigned` (أو `signed`) و`IEEE.NUMERIC_STD`.
- إعلان **المنافذ** بـ `std_logic_vector` يجعل entity أقصى ما يمكن من المحموليَّة.
- لحالات FSM، استخدم التعدادات — شفرتك تُقرأ كمواصفة.
