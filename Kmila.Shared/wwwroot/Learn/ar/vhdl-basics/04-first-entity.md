# عيّنة: كيانك الأول (مضاعِف 2-إلى-1)

**المضاعِف** هو أبسط جهاز توافقي يحوي "اختيارًا". النسخة 2-إلى-1 تختار بين مدخلَين اعتمادًا على بت `sel`:

```
  sel = 0  →  y = a
  sel = 1  →  y = b
```

VHDL لذلك هو سطر واحد:

```vhdl
y <= a when sel = '0' else b;
```

## ما الذي تفعله العيّنة

افتح العيّنة وستحصل على مشروع اسمه **كيانك الأول** مع:

- `mux21.vhd` (التصميم أعلاه)
- إعداد محاكاة مرافق يقود `sel` و`a` و`b` على مدى 40 ميكروثانية

عند Run، يُظهر تبويب Waveforms أربعة صفوف — المدخلات الثلاثة والخرج. راقب `y` تنقلب بين `a` و`b` عندما تتبدّل `sel`.

## أشياء للملاحظة

الإسناد `y <= a when sel = '0' else b;` **عبارة متزامنة**: يعيش خارج أي عملية، ويصف توصيلًا دائمًا. لا يوجد "متى يُنفَّذ هذا السطر؟" — هو ببساطة موجود.

يمكن أن يكون الشرط داخل `when/else` أي تعبير بولي:

```vhdl
y <= a when sel = '0' else
     b when enable = '1' else
     'Z';
```

سلاسل كهذه تُجمَّع إلى مضاعِف أولوية (الحالة العلوية تفوز في التعادل).

## دورك: وسِّعها

بعد أن ترى العيّنة تعمل:

1. غيّر الكيان إلى **مضاعِف 4-إلى-1** — تصبح `sel` بـ 2 بت، وتختار بين `a`، `b`، `c`، `d`.
2. أضف منفذًا خامسًا `output_enable`. عندما يكون `'0'`، اقد `y <= 'Z'` (ممانعة عالية) بغض النظر عن `sel`.
3. قارن `when/else` مقابل نسخة `with/select` التي ستلتقي بها في الوحدة التالية.

محرر Kmila يُبرز كلمات VHDL المفتاحية ويعرف `std_logic` — حرّك المؤشر فوق `when` لترى الوثائق المضمّنة.
