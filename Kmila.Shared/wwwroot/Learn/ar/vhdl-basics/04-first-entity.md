# مثال: أوَّل entity لك (MUX 2 إلى 1)

**المُجمِّع (multiplexer)** هو أبسط جهاز توافقي يحوي «اختيارًا» في داخله. تختار نسخة 2 إلى 1 بين دخلَين بناءً على بِت `sel` واحد:

```
  sel = 0  →  y = a
  sel = 1  →  y = b
```

شفرة VHDL لذلك سطر واحد:

```vhdl
y <= a when sel = '0' else b;
```

## الملف كاملًا

كي ترى الأقسام الأربعة من الدروس السابقة في مكان واحد:

```vhdl
library IEEE;
use IEEE.STD_LOGIC_1164.ALL;

entity mux21 is
  port (
    a   : in  std_logic;
    b   : in  std_logic;
    sel : in  std_logic;
    y   : out std_logic
  );
end entity mux21;

architecture rtl of mux21 is
begin
  y <= a when sel = '0' else b;
end architecture rtl;
```

## ماذا يفعل المثال

افتح المثال وستحصل على مشروع باسم **Your first entity** يحوي:

- `mux21.vhd` (التصميم أعلاه)
- إعدادات محاكاة مرافقة تدفع `sel` و`a` و`b` على مدى 40 ميكروثانية

حين تضغط Run، يُظهِر تبويب أشكال الموجة أربعة صفوف — المداخل الثلاثة والمخرج. شاهد `y` يقفز بين `a` و`b` كلَّما تبدَّل `sel`.

## أشياء يجدر ملاحظتها

الإسناد `y <= a when sel = '0' else b;` **عبارة تزامنيَّة**: يعيش خارج أي process، ويصف ربطًا دائمًا. لا يوجد سؤال «متى يُنفَّذ هذا السطر؟» — فهو موجود ببساطة. إن تغيَّر `a` أو `b` أو `sel`، يستقرُّ `y` من جديد بعد تأخير انتشار.

يمكن أن يكون الشرط داخل `when/else` أيَّ تعبير منطقي، ويمكنك أن تسلسل عدَّة شروط:

```vhdl
y <= a   when sel = '0' else
     b   when enable = '1' else
     'Z';
```

تُخلَّق سلاسل كهذه إلى مُجمِّع **أولويَّة** (الشرط الأعلى يفوز عند التعادل).

## النظريَّة الكامنة: تمدُّد شانون

ذلك السطر الواحد ليس مجرَّد صياغة مريحة — إنه الشكل العتادي لنظريَّة من الجبر البولياني يُسمِّيها المساق **نظريَّة تمدُّد شانون (teorema de expansión de Shannon)**. أي دالة لمتغيِّر `s` يمكن تقسيمها إلى:

```
f(s, …) = (s' · f(0, …)) + (s · f(1, …))
```

يحسب مُجمِّع 2 إلى 1 بالضبط `y = sel'·a + sel·b`. بعبارة أخرى، المُجمِّع هو التحقُّق المادِّي لتمدُّد شانون حول بِت الاختيار — ولهذا كثيرًا ما تُبنى الدوال الأكبر برصِّ مُجمِّعات فوق بعضها. احتفظ بهذه الفكرة في جيبك؛ فهي الأساس وراء وحدة المُجمِّع/المُفرِّق لاحقًا في المساق.

## دورك: وسِّعه

حالما ترى المثال يعمل:

1. حوِّل الـ entity إلى **MUX 4 إلى 1** — يصير `sel` متجه `std_logic_vector` بعرض بِتَين، وتختار بين `a` و`b` و`c` و`d`. (عبارة `with sel select` تُقرأ بوضوح هنا — ستلتقي بها في وحدة المنطق التوافقي.)
2. أضف منفذًا خامسًا `output_enable`. حين يكون `'0'`، ادفع `y <= 'Z'` (ممانعة عالية) بغضِّ النظر عن `sel`.
3. ابنِ **مُفرِّقًا (demultiplexer)** — الصورة المرآتيَّة. دخل واحد، و`sel`، وعدَّة مخرجات؛ يُوجَّه الدخل إلى مخرج واحد بالضبط بينما يستقرُّ الباقي على `'0'`.

محرِّر Kmila يُبرز كلمات VHDL المفتاحيَّة ويعرف `std_logic` — مرِّر فوق `when` لترى التوثيق المدمج.

## ما يجب تذكُّره

- الـ **entity** تُسمِّي الواجهة؛ والـ **architecture** تعطي السلوك. المُجمِّع مثال كامل وأدنى على كليهما.
- `y <= a when sel = '0' else b;` إسناد شرطي تزامني — ربط دائم، لا سطر «يُنفَّذ».
- المُجمِّع هو تمدُّد شانون في السيليكون: `y = sel'·a + sel·b`. تلك الفكرة الواحدة تتوسَّع لكل مُجمِّع أعرض ستبنيه.
