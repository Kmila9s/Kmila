# مثال: أوَّل entity لك (MUX 2 إلى 1)

**المُجمِّع** هو أبسط جهاز توافقي يحوي «اختيارًا». نسخة 2 إلى 1 تختار بين دخلَين بناءً على بت `sel` واحد:

```
  sel = 0  →  y = a
  sel = 1  →  y = b
```

VHDL لذلك سطر واحد:

```vhdl
y <= a when sel = '0' else b;
```

## ماذا يفعل المثال

افتح المثال وستحصل على مشروع باسم **Your first entity** يحوي:

- `mux21.vhd` (التصميم أعلاه)
- إعدادات محاكاة مرافقة تدفع `sel` و`a` و`b` على مدى 40 ميكروثانية

حين تضغط Run، يُظهر تبويب أشكال الموجة أربعة صفوف — المداخل الثلاثة والمخرج. شاهد `y` يقفز بين `a` و`b` كلَّما تبدَّل `sel`.

## أشياء يجدر ملاحظتها

الإسناد `y <= a when sel = '0' else b;` **سطر تزامني**: يعيش خارج أي process، ويصف ربطًا دائمًا. لا يوجد «متى يُنفَّذ هذا السطر؟» — فهو موجود ببساطة.

الشرط داخل `when/else` يمكن أن يكون أي تعبير منطقي:

```vhdl
y <= a when sel = '0' else
     b when enable = '1' else
     'Z';
```

تُركَّب مثل هذه السلاسل إلى مُجمِّع أولويَّة (الحالة الأعلى تفوز عند التعادل).

## دورك: وسِّعه

حالما ترى المثال يعمل:

1. حوِّل الـ entity إلى **MUX 4 إلى 1** — يصير `sel` 2 بت، وتختار بين `a` و`b` و`c` و`d`.
2. أضف منفذًا خامسًا `output_enable`. حين يكون `'0'`، ادفع `y <= 'Z'` (مُمانعة عالية) بغضِّ النظر عن `sel`.
3. قارن `when/else` بنسخة `with/select` التي ستلتقي بها في الوحدة التالية.

محرِّر Kmila يُبرز كلمات VHDL المفتاحيَّة ويعرف `std_logic` — مرِّر فوق `when` لرؤية التوثيق المدمج.
