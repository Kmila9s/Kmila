# دلتا-الدورات وحالات السباق

يجب على المحاكي أن يُعطي «حدثَين يجريان في الوقت نفسه» ترتيبًا حتميًّا. جواب VHDL: **دلتا-الدورة**: شريحة زمن صغيرة لا نهائيًّا تفصل السبب عن الأثر.

## ما هي دلتا-الدورة

يتقدَّم زمن المحاكاة بخطوات حقيقيَّة (ns، µs، ms). لكن داخل خطوة زمن واحدة، يمكن أن تحدث التغييرات بترتيب **دلتا-الدورة**:

- δ₀: تُجدوِل تحديث إشارة.
- δ₁: يدخل التحديث حيِّز التنفيذ؛ كل process حسَّاس لتلك الإشارة لديه الآن دخل جديد.
- δ₂: تلك المعالجات تُجدوِل تحديثاتها.
- δ₃: تلك التحديثات تدخل حيِّز التنفيذ.
- …

كل دلتا «زمن حقيقي صفر» لكنه يُمثِّل خطوة سببيَّة. يستمرُّ المحاكي في الدوران عبر الدلتا حتى لا يبقى شيء يتحدَّث — وعندها فقط يتقدَّم الزمن الحقيقي.

## لماذا توجد

افترض إشارتَين تتحدَّثان على نفس حافة الساعة:

```vhdl
process(clk)
begin
  if rising_edge(clk) then
    a <= x;
    b <= y;
  end if;
end process;
```

بدون دلتا، كان على المحاكي اختيار ترتيب اعتباطي — هل تتحدَّث `a` قبل `b`؟ بعدها؟ في نفس اللحظة؟ تتجاوز الدلتا ذلك: تُجدوَل كلتا الإسنادتَين في δ₀ وتدخلان حيِّز التنفيذ في δ₁. أي process يقرأ `a` أو `b` يرى القيمتَين الجديدتَين في نفس الوقت.

## فخّ حالة السباق

انظر:

```vhdl
process(a)
begin
  b <= a;
end process;

process(b)
begin
  c <= b;
end process;
```

حين تتغيَّر `a`، ينطلق المعالج الأوَّل ويُجدوِل `b`. عند δ₁، تكون `b` بقيمتها الجديدة. ينطلق المعالج الثاني، يُجدوِل `c`. عند δ₂، تكون `c` بالقيمة الصحيحة.

الآن بدِّل المعالجَين. هل يتغيَّر شيء؟ **لا**. تضمن الدلتا أن المسارَين يُنتجان النتيجة النهائيَّة ذاتها — حتى لو كان «ترتيب» المعالجَين في الملف مختلفًا. هذا تمامًا سبب وجود الدلتا.

## أين تفسد الأمور

المشكلة حين تخلط دلالات **الإشارة** مع «أحتاج أن يحدث هذا قبل ذاك في نفس التكَّة». مثال:

```vhdl
process(clk)
begin
  if rising_edge(clk) then
    a <= b + 1;     -- a تتحدَّث في نهاية التكَّة
    b <= a + 1;     -- b تقرأ a القديم
  end if;
end process;
```

إن افترضت «السطر 1 يجري أوَّلًا، فـ `a` متحدِّث عند السطر 2»، فأنت مخطئ. تتحدَّث `a` في نهاية التكَّة. تقرأ `b` قيمة `a` القديمة. النتيجة: كلاهما يتزايد بناءً على بيانات قديمة، لا بيانات الآخر الجديدة.

استبدل الإشارات بمتغيِّرات للحصول على دلالات C-المعتادة:

```vhdl
process(clk)
  variable aa, bb : integer;
begin
  if rising_edge(clk) then
    aa := bb + 1;   -- فوري
    bb := aa + 1;   -- يرى aa الجديد
  end if;
end process;
```

الآن يعمل كما يتوقَّع مبرمجو البرمجيَّات.

## الخلاصة

- دلتا-الدورات وسيلة المحاكي لجعل المنطق التزامني حتميًّا.
- إسنادات الإشارات تدخل حيِّز التنفيذ **بعد** دلتا-الدورات. المتغيِّرات لا.
- إن تصرَّف مقعد اختبارك «غريبًا» قرب حافة الساعة، اشتبه في مشكلة ترتيب دلتا قبل أن تلوم الأداة.

التمرين التالي في المنهج يُظهر حالة سباق صغيرة وهي تعمل. اعثر عليها، سمِّها، أصلحها — لن تنسى القاعدة بعدها أبدًا.
