# مثال: RAM بمنفذ واحد بقراءة write-first

ذاكرة القراءة-الكتابة هي النصف الآخر من «استنتاج BRAM». نمط `type…array…of` نفسه يعمل، لكن المصفوفة الآن **إشارة**، وتكتب عند بعض حافات الساعة وتقرأ عند غيرها.

## القالب

```vhdl
type mem_t is array(0 to 31) of std_logic_vector(7 downto 0);
signal mem : mem_t := (others => (others => '0'));
...
process(clk)
begin
  if rising_edge(clk) then
    if we = '1' then
      mem(to_integer(unsigned(addr))) <= din;
      dout <= din;                             -- قراءة write-first
    else
      dout <= mem(to_integer(unsigned(addr)));
    end if;
  end if;
end process;
```

## سياسات القراءة الثلاث

أيُّ RAM متزامنة عليها أن تُقرِّر ما يفعله `dout` **خلال كتابة**. ثلاث أعراف:

- **Write-first (المعروض أعلاه):** عند كتابة، يُظهر `dout` البيانات المكتوبة حديثًا. أنظف الدلالات — قراءة وكتابة لنفس العنوان في نفس الدورة تعطيك القيمة الجديدة.
- **Read-first:** عند كتابة، يُظهر `dout` **المحتوى القديم** للخليَّة. تستخدم بعض ملفَّات سجلَّات المعالجات ذلك.
- **No-change:** عند كتابة، لا يتحدَّث `dout`. بعض تصاميم الطاقة المنخفضة.

كلها تُسقط على block RAM في أي FPGA حديث، لكن المُركِّب يختار الوضع بناءً على الشكل الدقيق لمعالجتك. قالب write-first هو الأكثر محمولًا — إن شككت، اكتبه.

## ماذا يفعل المثال

خلال أوَّل 30 µs تكتب المحاكاة في ثلاثة عناوين (`0`، `1`، `2`) بثلاثة أنماط بايت مختلفة. ثم ينزل `we`، ويُعاد `addr` إلى 0 عند 40 µs. يُظهر تبويب أشكال الموجة `dout` يتبع `din` خلال الكتابات، ثم يُخرج القيمة المُخزَّنة عند القراءة.

## دورك

- **رقِّ إلى RAM ثنائي المنفذ كامل.** مجموعتان كاملتان `addr`/`din`/`dout`/`we`، كلتاهما بساعة `clk`. هذا النمط الذي تستخدمه كل FIFOs وDPRAMs ثنائيَّة الساعة من المصنِّعين تحت الغطاء.
- **أضف سجل خرج.** Block RAM في Xilinx يدعم سجلًّا تجميعيًّا ثانيًا بعد مصفوفة الذاكرة. أضف `dout_reg <= dout;` في كتلة متزامنة ثانية وراقب ما يتغيَّر على شكل الموجة (تلميح: دورة كُمون إضافيَّة، لكن إغلاق توقيت أفضل بكثير).
- **غيِّر المحتويات الأوَّليَّة.** حمِّل أوَّل بضع مدخلات بنمط مميَّز بتغيير مُهيِّء `signal mem`. لا تحترم كل المُركِّبات مُهيِّآت BRAM في VHDL المحمول — راجع هدفك قبل الاعتماد عليها في الإنتاج.
