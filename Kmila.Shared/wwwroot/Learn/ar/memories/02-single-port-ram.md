# عيّنة: RAM بمنفذ مفرد بقراءة "الكتابة أولًا"

ذاكرة القراءة/الكتابة هي النصف الآخر من "استنتاج BRAM". يعمل نمط `type…array…of` ذاته، لكن الآن المصفوفة **إشارة**، وتكتب على بعض حواف الساعة وتقرأ على الأخرى.

## القالب

```vhdl
type mem_t is array(0 to 31) of std_logic_vector(7 downto 0);
signal mem : mem_t := (others => (others => '0'));
...
process(clk)
begin
  if rising_edge(clk) then
    if we = '1' then
      mem(to_integer(unsigned(addr))) <= din;
      dout <= din;                             -- الكتابة أولًا
    else
      dout <= mem(to_integer(unsigned(addr)));
    end if;
  end if;
end process;
```

## سياسات القراءة الثلاث

كل RAM متزامن يجب أن يقرّر ماذا تفعل `dout` **أثناء الكتابة**. توجد ثلاث اصطلاحات:

- **الكتابة أولًا (الموضّحة أعلاه):** عند الكتابة، تُظهر `dout` البيانات المكتوبة حديثًا. أنظف الدلالات — قراءة وكتابة لنفس العنوان في نفس الدورة تعطيك القيمة الجديدة.
- **القراءة أولًا:** عند الكتابة، تُظهر `dout` المحتوى **القديم** للخلية. تستخدمه بعض ملفات سجلات وحدات CPU.
- **بدون تغيير:** عند الكتابة، لا تُحدَّث `dout`. بعض التصاميم ذات القدرة المنخفضة.

الثلاثة جميعها تُخطَّط إلى Block RAM على أي FPGA حديثة، لكن المُجمِّع يختار النمط بناءً على الشكل الدقيق لعمليتك. قالب "الكتابة أولًا" هو الأكثر قابلية للنقل — عند الشك، اكتبه.

## ما الذي تفعله العيّنة

خلال أول 30 ميكروثانية، يكتب المحاكي إلى ثلاثة عناوين (`0`، `1`، `2`) بثلاثة أنماط بايت مختلفة. ثم تنخفض `we`، وتُعاد `addr` إلى الصفر عند 40 ميكروثانية. يُظهر تبويب Waveforms `dout` تتبع `din` أثناء الكتابات، ثم تُنتج القيمة المخزّنة عندما تقرأ.

## دورك

- **ترقّى إلى RAM ثنائي المنفذ حقيقي.** مجموعتان كاملتان من `addr`/`din`/`dout`/`we`، كلتاهما مع `clk`. هذا النمط تستخدمه FIFOs وDPRAMs ثنائيات الساعة لكل مورّد تحتها.
- **أضف سجل خرج.** Block RAM على Xilinx يدعم سجل خط أنابيب ثانيًا بعد مصفوفة الذاكرة. أضف `dout_reg <= dout;` في كتلة محكومة بالساعة ثانية وراقب ما يتغير على الموجة (تلميح: دورة زمن استجابة إضافية، لكن إغلاق توقيت أفضل بكثير).
- **غيّر المحتويات الأولية.** حمِّل الإدخالات الأولى بنمط يمكن التعرف عليه بتغيير تهيئة `signal mem`. ليس كل المُجمِّعين يحترمون تهيئة BRAM في VHDL القابل للنقل — تحقق من هدفك قبل الاعتماد على ذلك في الإنتاج.
