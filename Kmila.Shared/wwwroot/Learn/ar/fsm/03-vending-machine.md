# مشروع: آلة بيع تعمل بالعملة

هذا أول مشروع حقيقي لك. المواصفات محددة، والقالب المبدئي يقدم لك السباكة، ومهمتك أن تكتب المنطق الذي يُكمله.

## ما الذي ستبنيه

آلة FSM تتبع المال الذي أدخله الزبون وتُصرِف منتجًا (نبضة خرج واحدة، `dispense`) عندما يصل المجموع إلى 25 سنتًا. المدخلات:

- `nickel` — نبضة بدورة واحدة تعني "سقطت للتو عملة 5 سنتات"
- `dime` — نبضة بدورة واحدة تعني "سقطت للتو عملة 10 سنتات"
- `clk`, `reset`

والمخرجات:

- `dispense` — نبضة مرتفعة لدورة ساعة واحدة بالضبط عند بلوغ ‎≥ 25 سنتًا‏
- `change` — نبضة مرتفعة لدورة واحدة مع `dispense` إن كان المجموع **أكثر** من 25 سنتًا (فتحتاج الآلة لإرجاع مال)

## معايير القبول

| تسلسل العملات       | السلوك المتوقّع          |
|----------------------|-------------------------------|
| 5 nickels            | `dispense=1, change=0`        |
| 2 dimes + 1 nickel   | `dispense=1, change=0`        |
| 3 dimes (= 30¢)      | `dispense=1, change=1`        |
| 2 nickels + 1 dime   | لا صرف (20 سنتًا فقط)         |

## ما الذي يعطيك القالب المبدئي

الكيان ومُراكِم `total` موصولان. كل نبضة `nickel` تضيف 5؛ كل نبضة `dime` تضيف 10. لكن القالب يقود دائمًا `dispense = '0'` و`change = '0'`. **هذا ما عليك أن تغيّره.**

```vhdl
process(clk, reset)
begin
  if reset = '1' then
    total <= (others => '0');
  elsif rising_edge(clk) then
    if    nickel = '1' then total <= total + 5;
    elsif dime   = '1' then total <= total + 10;
    end if;
  end if;
end process;

dispense <= '0';  -- TODO
change   <= '0';  -- TODO
```

## منهج مقترح

1. **اكتشف شرط البيع.** عند كل حافة ساعة صاعدة، تحقق ما إذا كان `total >= 25` بعد إضافة العملة الحالية. (انتبه: عليك حساب المجموع *الجديد*، لا ذاك من الدورة السابقة.)
2. **نبّض `dispense` لدورة واحدة بالضبط.** الحيلة: عند اكتشاف البيع، ارفع إشارة راية وأعد تعيين `total` إلى الصفر. الراية تحيا لدورة واحدة.
3. **احسب `change`.** إن كان المجموع عند لحظة البيع أكبر من 25، فنبّض `change` أيضًا.

تلميح: من الأسهل إن حسبت "المجموع التالي" كإشارة محلية (أو `variable` داخل العملية):

```vhdl
variable next_total : unsigned(5 downto 0);
...
next_total := total;
if    nickel = '1' then next_total := total + 5;
elsif dime   = '1' then next_total := total + 10;
end if;

if next_total >= 25 then
  dispense <= '1';
  change   <= '1' when next_total > 25 else '0';
  total    <= (others => '0');
else
  dispense <= '0';
  change   <= '0';
  total    <= next_total;
end if;
```

## للتعمق أكثر

- أضف زر **استرداد** يُصفّر `total` دون صرف.
- ادعم عملة **ربع** (25 سنتًا) — يجب أن تصرف فورًا.
- تتبّع عدد المنتجات المباعة في عدّاد 8 بت منفصل مرئي كخرج. هذا نوع التغذية الراجعة التي ترسلها آلات البيع الحقيقية للأعلى.
