# مشروع: آلة بيع تعمل بالعملات

هذا أوَّل مشروع حقيقي. المواصفات مثبَّتة، شفرة البداية تُسلِّمك السباكة، وعملك أن تكتب المنطق المكمِّل لها.

## ما الذي تبنيه

FSM تتتبَّع المال الذي أدخله الزبون وتُسلِّم منتجًا (نبضة خرج واحدة `dispense`) حين تبلغ الجملة 25¢. المداخل:

- `nickel` — نبضة دورة واحدة معناها «سقطت قطعة 5¢ توًّا»
- `dime` — نبضة دورة واحدة معناها «سقطت قطعة 10¢ توًّا»
- `clk`، `reset`

والمخارج:

- `dispense` — نبضة مرتفعة لدورة واحدة بالضبط حين تبلغ ≥ 25¢
- `change` — نبضة مرتفعة لدورة واحدة بجانب `dispense` إن كانت الجملة **أكثر** من 25¢ (يجب على الآلة إرجاع باقٍ)

## معايير القبول

| تتابع العملات        | السلوك المتوقَّع              |
|----------------------|-------------------------------|
| 5 قطع nickel         | `dispense=1, change=0`        |
| 2 dime + 1 nickel    | `dispense=1, change=0`        |
| 3 dime (= 30¢)       | `dispense=1, change=1`        |
| 2 nickel + 1 dime    | لا تسليم (20¢ فقط)            |

## ما يمنحك إيَّاه البداية

الـ entity ومُجمِّع `total` موصولان. كل نبضة `nickel` تضيف 5؛ كل نبضة `dime` تضيف 10. لكن البداية تدفع دومًا `dispense = '0'` و `change = '0'`. **هذا ما عليك تغييره.**

```vhdl
process(clk, reset)
begin
  if reset = '1' then
    total <= (others => '0');
  elsif rising_edge(clk) then
    if    nickel = '1' then total <= total + 5;
    elsif dime   = '1' then total <= total + 10;
    end if;
  end if;
end process;

dispense <= '0';  -- TODO
change   <= '0';  -- TODO
```

## مقاربة مقترحة

1. **اكتشف شرط البيع.** عند كل حافة صاعدة، تحقَّق إن كان `total >= 25` *بعد* إضافة العملة الحاليَّة. (انتبه: عليك حساب الجملة *الجديدة*، لا تلك من الدورة السابقة.)
2. **انبض `dispense` لدورة واحدة بالضبط.** الحيلة: حين تكتشف البيع، عيِّن راية وأعد `total` إلى صفر. الراية تعيش دورة واحدة.
3. **احسب `change`.** إن كانت الجملة لحظة البيع > 25، انبض `change` أيضًا.

تلميح: أسهل إن حسبت «الجملة التالية» كإشارة محلِّيَّة (أو `variable` داخل المعالجة):

```vhdl
variable next_total : unsigned(5 downto 0);
...
next_total := total;
if    nickel = '1' then next_total := total + 5;
elsif dime   = '1' then next_total := total + 10;
end if;

if next_total >= 25 then
  dispense <= '1';
  change   <= '1' when next_total > 25 else '0';
  total    <= (others => '0');
else
  dispense <= '0';
  change   <= '0';
  total    <= next_total;
end if;
```

## للمضي أبعد

- أضف زر **استرداد** يُصفِّر `total` بلا تسليم.
- ادعم قطعة **quarter** (25¢) — يجب أن تُسلِّم فورًا.
- تتبَّع عدد القطع المباعة في عدَّاد 8 بت منفصل ظاهر كخرج. هذا نوع التغذية الراجعة الذي ترسله آلات البيع الحقيقيَّة لأعلى.
