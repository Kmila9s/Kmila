# مثال: آلة حالات لإشارة المرور

إشارة المرور هي آلة Moore النموذجيَّة: ثلاث حالات (`RED`، `GREEN`، `YELLOW`)، خرج لكل لون، ومؤقِّت يقول «أبقِ كل حالة لبضع دورات قبل الانتقال».

## البنية

يتَّبع المثال **نمط المعالجتَين**:

- المعالجة 1 هي **سجل الحالة** — قلَّاب D كلاسيكي يحفظ `state` ويُكِّت عدَّاد انتظار.
- المعالجة 2 هي **منطق الحالة التالية** — توافقيَّة محضة، تُقرِّر ما `next_state` بناءً على الحالة الحاليَّة.
- إسنادات الخرج (أسفل الهيكليَّة) خرجات Moore توافقيَّة — قيمها تعتمد على `state` فقط.

## استعراض الشفرة

```vhdl
type state_t is (S_RED, S_GREEN, S_YELLOW);
signal state, next_state : state_t;
signal count : unsigned(3 downto 0) := (others => '0');
constant HOLD : unsigned(3 downto 0) := "0111";  -- 7 تكَّات لكل لون
```

`state_t` **تعداد** — يختار المُركِّب الترميز الثنائي الفعلي، ونحن نشير إلى حالات مسمَّاة فحسب. `count` يتتبَّع مدَّة بقائنا في الحالة الحاليَّة. و`HOLD` هو زمن البقاء.

سجل الحالة:

```vhdl
process(clk, reset)
begin
  if reset = '1' then
    state <= S_RED;
    count <= (others => '0');
  elsif rising_edge(clk) then
    if count = HOLD then
      state <= next_state;
      count <= (others => '0');
    else
      count <= count + 1;
    end if;
  end if;
end process;
```

تفصيلان يستحقَّان التسمية. أوَّلًا، هذا **تصفير لاتزامني** (`reset` في قائمة الحساسيَّة ويُختبَر قبل `rising_edge`) — تقفز الإشارة إلى `S_RED` لحظة تأكيد التصفير. أمَّا التصفير المتزامن فيُسقط `reset` من قائمة الحساسيَّة ويختبره فقط داخل فرع `rising_edge`؛ كلاهما صحيح، فاختر أسلوبًا وابقَ متَّسقًا معه. ثانيًا، يحوِّل العدَّاد انتقالًا واحدًا للحالة إلى بقاء 8 دورات — فلا تتقدَّم الحالة إلَّا في الدورة التي يكون فيها `count = HOLD`.

منطق الحالة التالية:

```vhdl
process(state)
begin
  case state is
    when S_RED    => next_state <= S_GREEN;
    when S_GREEN  => next_state <= S_YELLOW;
    when S_YELLOW => next_state <= S_RED;
  end case;
end process;
```

لأنَّ هذه المعالجة تُسنِد `next_state` على كل فرع، ولأنَّ `case` شامل على `state_t`، فلا مِزلاج مُستنتَج هنا. وقائمة الحساسيَّة هي `(state)` فقط — وهذا صحيح، لأنَّ `next_state` لا يعتمد على أي شيء آخر. وفي اللحظة التي تجعل فيها الحالة التالية تعتمد على دخل، يجب أن ينضمَّ ذلك الدخل إلى قائمة الحساسيَّة (وإلَّا حاكَت المعالجة التوافقيَّة خطأً)، وينبغي أن تضيف إسنادًا افتراضيًّا `next_state <= state;` في السطر الأوَّل كتأمين.

الخرجات (Moore محضة):

```vhdl
red    <= '1' when state = S_RED    else '0';
green  <= '1' when state = S_GREEN  else '0';
yellow <= '1' when state = S_YELLOW else '0';
```

كل خرج دالة في `state` وحده — فلا تتغيَّر إلَّا حين يُكِّت السجل، ولا يمكن أن تقفز بين الحافات. هذه هي كل جاذبيَّة آلة Moore لشيء يقود إشارة ماديَّة.

## ماذا يفعل المثال

تشتغل الساعة نحو 400 µs. كل 8 ساعات (7 انتظار + 1 انتقال) تتقدَّم الآلة. سترى ثلاث موجات مربَّعة تدور تتابعيًّا: `red` يصير مرتفعًا 8 تكَّات، ثم `green` 8 تكَّات، ثم `yellow`، ثم العودة إلى `red`.

## من المحاكاة إلى تقاطع حقيقي

`HOLD = 7` راحة محاكاة. على FPGA بـ 50 ميجاهرتز، التكَّة الواحدة 20 نانوثانية، فسبع تكَّات 140 نانوثانية — ليست إشارة مرور بل وميضًا. ولبقاء حقيقي مقداره ثانية واحدة ستَعدُّ إلى 50٬000٬000، ما يعني توسيع `count` والثابت `HOLD`. والطريقة النظيفة هي **generic**:

```vhdl
generic ( HOLD : natural := 7 );
...
signal count : unsigned(31 downto 0);
```

حاكِ بقيمة `HOLD` صغيرة، وركِّب بقيمة كبيرة — نفس الـ RTL بلا تعديلات. والتقاطعات الحقيقيَّة تضيف أيضًا **حالة أمان بالأحمر الكامل** بين الأخضرَين المتعارضَين؛ وإضافة واحدة تمرين جيد في توسيع آلة Moore دون كسر ضمان خلوّها من القفزات.

## دورك

- **أضف دخلًا لطلب المشاة.** حين `ped = '1'` والحالة `S_GREEN`، أجبِر الحالة التالية على أن تكون `S_YELLOW` (فتقصر الدورة للسماح للمشاة بالعبور). هذا يحوِّل آلة Moore إلى شيء شبيه بـ Mealy — إذ تعتمد الحالة التالية الآن على `state` **و** على الدخل `ped`، فأضِف `ped` إلى قائمة الحساسيَّة وإسنادًا افتراضيًّا.
- **أصدِر إشارة `walk`** ترتفع فقط حين `state = S_RED`. هذا خرج Moore جديد.
- **اجعل `HOLD` بارامتريًّا** كـ generic — 7 جيد للمحاكاة، لكن على FPGA بـ 50 ميجاهرتز ستريد 50 مليون دورة لتُحقِّق بقاءً مقداره ثانية واحدة.

## الصلة بالمساق

هذا المثال هو *التطبيقات بالمؤتمتات ولغة وصف العتاد* من الوحدة الثانية في صورة مصغَّرة: مؤتمتة Moore حتميَّة، تُرسَم كمخطَّط بثلاث حالات، ثم تُوصَف بـ HDL. والعدَّاد الذي يمطُّ كل حالة إلى بقاء مؤقَّت هو أيضًا أوَّل مذاق لك من الوحدة الثالثة (العدَّادات) وهي تعيش داخل آلة حالات.

## ما يجب تذكُّره

- إشارة المرور آلة Moore من كتاب: الخرجات تعتمد على `state` وحده، فهي خالية من القفزات.
- فصل المعالجتَين (سجل مُساعَ بالساعة + حالة تالية توافقيَّة) يُبقي التصميم مقروءًا وخاليًا من المزاليج.
- عدَّاد داخل سجل الحالة يحوِّل انتقالًا واحدًا إلى بقاء مؤقَّت؛ اجعل البقاء بارامتريًّا بـ generic كي يخدم الـ RTL الواحد المحاكاة والسيليكون معًا.
- في اللحظة التي يؤثِّر فيها دخل على الحالة التالية، أضِفه إلى قائمة الحساسيَّة وأسنِد `next_state` افتراضيًّا.
