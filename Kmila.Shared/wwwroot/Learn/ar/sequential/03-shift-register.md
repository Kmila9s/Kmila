# مثال: سجل إزاحة 8 بت

سجل الإزاحة صفٌّ من القلَّابات المتسلسلة. كل حافة ساعة تُزيح البتات المخزَّنة موقعًا، ويدخل بت جديد من طرف ما. وهي في قلب UARTs ومتحكِّمات SPI ومحرِّكات CRC ومولِّدات الأرقام شبه العشوائيَّة المعتمدة على LFSR.

## ما يفعله هذا المثال

`shift8` سجل إزاحة **مدخل تسلسلي/خرج متوازٍ**:

- `din` البت الجديد القادم عند كل حافة صاعدة.
- `r` السجل الداخلي 8 بت.
- `q` يُظهر `r` للخارج كبايت متوازٍ.

## الجسم

```vhdl
signal r : std_logic_vector(7 downto 0) := (others => '0');
...
process(clk, reset)
begin
  if reset = '1' then
    r <= (others => '0');
  elsif rising_edge(clk) then
    r <= r(6 downto 0) & din;
  end if;
end process;

q <= r;
```

السحر في هذا السطر:

```vhdl
r <= r(6 downto 0) & din;
```

`&` عامل **التسلسل**. `r(6 downto 0)` هي البتات السبع السفلى من السجل الحالي. نلصق `din` على الطرف الأيمن، فنُكوِّن قيمة 8 بت جديدة، ونُسندها إلى `r`.

ولأن هذا إسناد إشارة داخل معالجة متزامنة، تحدث الإزاحة عند كل حافة صاعدة.

## استعراض شكل الموجة

تدفع إعدادات المحاكاة `din` عبر نمط: `1, 0, 1, 1, 0, 1, 0, 1`. راقب `q` عبر الزمن:

- بعد التكَّة الأولى: `q = 00000001`
- بعد الثانية: `q = 00000010`
- بعد الثالثة: `q = 00000101`
- …وهكذا. البت الجديد يهبط في LSB؛ البتات الأقدم تمشي نحو MSB.

لو ابتعدت بالعدسة، سترى البت الأعلى (البت 7) يستلم أوَّل قيمة `din` بعد 8 دورات ساعة بالضبط. تلك زمن الرحلة ذهابًا وإيابًا لسجل 8 بت.

## دورك

- **أزِح إلى اليمين بدلًا.** بدِّل التسلسل: `r <= din & r(7 downto 1);`.
- **تحميل متوازٍ.** أضف دخل `load` وناقل `din_parallel`. حين `load = '1'` عند حافة، يأخذ السجل الناقل كاملًا دفعة بدل الإزاحة.
- **خرج تسلسلي.** أضف `dout <= r(7);`. أصبح الآن سجل إزاحة دخل-تسلسلي/خرج-تسلسلي (SISO) — أوَّل بت أرسلته على `din` يظهر على `dout` بعد 8 دورات. هكذا يعمل تأخير البت ببت في استقبال UART.
