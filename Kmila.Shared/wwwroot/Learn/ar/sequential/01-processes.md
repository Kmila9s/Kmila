# المعالجات وقوائم الحساسيَّة

كل ما في VHDL خارج process تزامني — أسلاك وبوابات. لحظة أن تريد دائرة **تتذكَّر** شيئًا من دورة ساعة إلى التي تليها، تحتاج process.

## ما هو process

`process` كتلة من الشفرة المتتابعة داخل architecture في VHDL. تُقرأ سطورها من الأعلى للأسفل كالبرمجيَّات. لكن المعالجة نفسها لا «تجري» إلَّا عند تغيُّر شيء في **قائمة حساسيَّتها**.

```vhdl
process(clk, reset)
begin
  if reset = '1' then
    q <= '0';
  elsif rising_edge(clk) then
    q <= d;
  end if;
end process;
```

تعني هذه الكتلة: «حالما يتغيَّر `clk` أو `reset`، أعد تقييم جسمي.»

## شكلان ستراهما 99٪ من الوقت

### معالجة توافقيَّة

قائمة الحساسيَّة = كل دخل مقروء في الداخل. بلا ساعة. الخرج دالة محضة في الدخل.

```vhdl
process(a, b, sel)
begin
  if sel = '0' then
    y <= a;
  else
    y <= b;
  end if;
end process;
```

تُركَّب إلى MUX 2 إلى 1. بلا تخزين.

### معالجة متزامنة (تتابعيَّة)

قائمة الحساسيَّة = `(clk, reset)`. تحدث الإسنادات داخل `rising_edge(clk)` فقط (أو `falling_edge`، إن كنت سيِّء الحظ). الخرج **مُسجَّل** — يتغيَّر فقط على حافات الساعة.

```vhdl
process(clk, reset)
begin
  if reset = '1' then
    q <= (others => '0');
  elsif rising_edge(clk) then
    q <= d;
  end if;
end process;
```

هذا النمط الكلاسيكي لقلَّاب D.

## فخّ قائمة الحساسيَّة

إن نسيت إدراج إشارة يقرؤها الجسم، تختلف المحاكاة عن التركيب:

- **المحاكاة**: المعالجة لا تُعاد تقييمها عند تغيُّر تلك الإشارة. شكل الموجة يبدو خاطئًا.
- **التركيب**: تقرأ الأداة الجسم، ترى كل قراءة، وتبني العتاد الصحيح على أيِّ حال.

النتيجة: منصّة اختبارك تجتاز، لكن اللوحة لا تعمل — أو العكس. VHDL-2008 يُتيح لك كتابة `process(all)` لتفادي ذلك تمامًا:

```vhdl
process(all)  -- يضمُّ كل إشارة مقروءة في الجسم
begin
  ...
end process;
```

محلِّل Kmila يقبل `process(all)`، وهو ما تستخدمه معظم الفرق في التصاميم الجديدة.

## قاعدة عامَّة

- الحساسيَّة = `(clk, reset)` فقط → أنت تصف **مسجِّلات** (قلَّابات).
- الحساسيَّة = كل دخل مقروء → أنت تصف **منطقًا توافقيًّا**.
- الحساسيَّة تخلط الساعة مع غير الساعة → غالبًا لديك خلل.

## ما يجب تذكُّره

- المعالجة وحدة الشفرة المتتابعة داخل ملف تزامني في الأصل.
- المعالجات المتزامنة (`rising_edge(clk)`) تُركَّب إلى قلَّابات. بهذا تحصل على ذاكرة.
- أدرج كل إشارة تقرؤها، أو استخدم `process(all)` لتدع الأداة تفعل ذلك عنك.
