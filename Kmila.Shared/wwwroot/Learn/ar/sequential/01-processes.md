# العمليات وقوائم الحساسية

كل شيء في VHDL خارج العملية `process` يكون متزامنًا — أسلاك وبوابات. في اللحظة التي تريد فيها دائرة أن **تتذكّر** شيئًا من دورة ساعة إلى التالية، تحتاج إلى عملية.

## ما هي العملية

العملية `process` كتلة كود تتابعي داخل بنية VHDL معمارية. تُقرأ أسطرها من الأعلى إلى الأسفل، تمامًا كالبرمجيات. لكن العملية نفسها "لا تعمل" إلا عندما يتغير شيء في **قائمة حساسيتها**.

```vhdl
process(clk, reset)
begin
  if reset = '1' then
    q <= '0';
  elsif rising_edge(clk) then
    q <= d;
  end if;
end process;
```

تعني هذه الكتلة: "كلما تغيّرت `clk` أو `reset`، أعد تقييم جسمي."

## شكلان ستراهما 99% من الوقت

### عملية توافقية

قائمة الحساسية = كل مدخل يُقرأ في الداخل. بلا ساعة. الخرج دالة محضة في المدخلات.

```vhdl
process(a, b, sel)
begin
  if sel = '0' then
    y <= a;
  else
    y <= b;
  end if;
end process;
```

تُجمَّع إلى مضاعِف 2-إلى-1. لا تخزين.

### عملية مُسيَّرة بالساعة (تتابعية)

قائمة الحساسية = `(clk, reset)`. تحدث الإسنادات فقط داخل `rising_edge(clk)` (أو `falling_edge` إن كنت غير محظوظ). الخرج **مسجَّل** — لا يتغير إلا عند حواف الساعة.

```vhdl
process(clk, reset)
begin
  if reset = '1' then
    q <= (others => '0');
  elsif rising_edge(clk) then
    q <= d;
  end if;
end process;
```

هذا نمط قلّاب D الكلاسيكي.

## فخ قائمة الحساسية

إن نسيت أن تدرج إشارة يقرأها الجسم، تختلف المحاكاة والتجميع:

- **المحاكاة**: العملية لن تُعاد تقييمها عندما تتغير تلك الإشارة. الموجة تبدو خاطئة.
- **التجميع**: الأداة تقرأ الجسم، وترى كل قراءة، وتبني العتاد الصحيح على أية حال.

النتيجة: بنك اختبارك ينجح، لكن اللوح لا يعمل — أو العكس. تتيح لك VHDL-2008 كتابة `process(all)` لتجنّب ذلك كليًا:

```vhdl
process(all)  -- يضم كل إشارة تُقرأ في الجسم
begin
  ...
end process;
```

مُفسِّر Kmila يقبل `process(all)`، وهو ما تستخدمه معظم الفرق في التصاميم الجديدة.

## قاعدة عامة

- الحساسية = `(clk, reset)` فقط → أنت تصف **سجلات** (قلّابات).
- الحساسية = كل مدخل تقرأه → أنت تصف **منطقًا توافقيًا**.
- الحساسية تخلط إشارات مع ساعة وبدونها → شبه مؤكد أن لديك خلل.

## ما الذي يجب تذكره

- العملية هي وحدة الكود التتابعي داخل ملف متزامن بطبيعته.
- العمليات المسيَّرة بالساعة (`rising_edge(clk)`) تُجمَّع إلى قلّابات. بها تحصل على ذاكرة.
- أدرج كل إشارة تقرأها، أو استخدم `process(all)` لتدع الأداة تفعل ذلك عنك.
