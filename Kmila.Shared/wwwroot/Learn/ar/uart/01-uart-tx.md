# مشروع: مرسل UART

UART (مستقبل/مرسل غير متزامن عالمي) هو أول بروتوكول حقيقي يبنيه معظم مصممي الأنظمة المدمجة. وصلة نقطة-إلى-نقطة، ازدواج تام، ولا يحتاج إلا ثلاثة أسلاك (TX، RX، GND). كل محوّل FTDI USB-تسلسلي، وكل `Serial.print` في Arduino، وكل طرفية قديمة هو UART تحت السطح.

يبني هذا المشروع الجانب **المُرسِل**. الجانب المُستقبِل مشروع ممتاز تالٍ بعد أن تُنهي هذا.

## شكل الإطار (بلا تكافؤ، بيانات 8 بت، بت إيقاف واحد)

```
  Idle  Start   Bit0  Bit1  Bit2  Bit3  Bit4  Bit5  Bit6  Bit7   Stop   Idle
  ────┐      ┌───── ... ─────────────────────────────── ... ─────┐──────
      │      │
      └──────┘
    الخط عادة مرتفع ('1')؛ بت البدء حافة هابطة.
```

يُحتفظ بكل بت على `tx` لمدة `clk_freq / baud` دورة ساعة بالضبط. لساعة 50 ميغاهرتز و115200 باود، هذا ≈ 434 دورة لكل بت.

## مهمتك

1. ابنِ عدّاد ساعة ينتج نبضة `baud_tick` بدورة واحدة كل ~434 دورة.
2. عند `send = '1'`، الجم `data` في سجل إزاحة 10 بت: `{ stop_bit, data[7..0], start_bit } = 1 & data & 0`. اقد `busy <= '1'`.
3. عند كل `baud_tick`، أَزِح السجل لليمين (فيخرج بت البدء أولًا، ثم من LSB إلى MSB للبيانات، ثم بت الإيقاف).
4. بعد النبضة العاشرة، أسقط `busy` واجعل `tx` خاملًا مرتفعًا.

## الهيكل

الكيان وحالة الخمول مقدّمان؛ `tx` افتراضيًا مرتفعة، `busy` افتراضيًا منخفضة. كل ما بين هذين الافتراضيين مسؤوليتك.

```vhdl
architecture rtl of uart_tx is
  signal tx_reg : std_logic := '1';
begin
  tx   <= tx_reg;
  busy <= '0';       -- TODO
end architecture rtl;
```

## بنية مقترحة

عدّادان + سجل إزاحة واحد:

```vhdl
signal clk_count  : unsigned(9 downto 0);   -- 0..434
signal bit_count  : unsigned(3 downto 0);   -- 0..9
signal shift_reg  : std_logic_vector(9 downto 0);
signal sending    : std_logic := '0';
```

- عندما `send = '1'` و`sending = '0'`:
  - حمّل `shift_reg <= '1' & data & '0';`
  - `sending <= '1';  clk_count <= 0;  bit_count <= 0;`
- بينما `sending = '1'`:
  - `clk_count <= clk_count + 1;`
  - إذا `clk_count = BAUD_PERIOD - 1`:
    - `tx_reg <= shift_reg(0);`
    - `shift_reg <= '1' & shift_reg(9 downto 1);` — أَزِح لليمين، احشُ الأعلى بخمول
    - `bit_count <= bit_count + 1;`
    - `clk_count <= 0;`
  - إذا `bit_count = 10`:
    - `sending <= '0';`

اجعل `BAUD_PERIOD` عامًا (generic) حتى تتمكن من تصغيره للمحاكاة (مثلًا 5 دورات/بت) مع بقاء المنطق نفسه يعمل بالسرعة الكاملة على العتاد.

## ماذا تختبر

اقد `send = '1'` بـ `data = "01001000"` (ASCII `'H'`). بعد اكتمال الإطار، يجب أن تُظهر موجة `tx` بالضبط 10 فترات بت من النشاط:

1. Start (منخفض)
2. Bit 0 من البيانات (وهو LSB: `0`)
3. `0`
4. `0`
5. `1`
6. `0`
7. `0`
8. `1`
9. `0` (MSB)
10. Stop (مرتفع)

ثم عودة إلى الخمول المرتفع. كبّر في تبويب Waveforms وتحقق من النمط بتًا بتًا.

## للتعمق أكثر

- أضف **FIFO** لتتمكن من وضع عدة بايتات في طابور؛ يصبح `send` هو "push".
- ابنِ جانب **RX**: اعتبر عينة لكل بت وارد عند 1.5 × فترة البت، ثم عند 1 × من هنا فصاعدًا.
- اجعل الإطار بارامتريًا: التكافؤ، بيانات 7 بت مقابل 8، بت إيقاف 1 مقابل 2.
