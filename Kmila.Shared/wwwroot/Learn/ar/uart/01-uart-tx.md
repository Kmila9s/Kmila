# مشروع: مُرسِل UART

UART (مُستقبِل/مُرسِل لاتزامني عالمي) هو أوَّل بروتوكول حقيقي يبنيه معظم مصمِّمي الأنظمة المضمَّنة. نقطة-إلى-نقطة، ثنائي الاتجاه كاملًا، ويحتاج ثلاثة أسلاك فقط (TX، RX، GND). كل محول USB-تسلسلي من FTDI، كل `Serial.print` في Arduino، كل طرفيَّة قديمة هو UART في القاع.

هذا المشروع يبني جانب **الإرسال**. جانب الاستقبال مشروع تالٍ ممتاز بعد إنهاء هذا.

## شكل الإطار (بلا تكافؤ، 8 بتات بيانات، توقُّف 1)

```
  Idle  Start   Bit0  Bit1  Bit2  Bit3  Bit4  Bit5  Bit6  Bit7   Stop   Idle
  ────┐      ┌───── ... ─────────────────────────────── ... ─────┐──────
      │      │
      └──────┘
    الخط عادةً مرتفع ('1')؛ بت البدء حافة نازلة.
```

كل بت يُمسَك على `tx` لـ `clk_freq / baud` دورة ساعة بالضبط. لساعة 50 ميجاهرتز و115200 باود، ذلك ≈ 434 دورة لكل بت.

## مهمَّتك

1. ابنِ عدَّاد ساعة يُنتج `baud_tick` بدورة واحدة كل ~434 دورة.
2. عند `send = '1'`، أغلق `data` في سجل إزاحة بـ 10 بتات: `{ stop_bit, data[7..0], start_bit } = 1 & data & 0`. ادفع `busy <= '1'`.
3. في كل `baud_tick`، أزِح السجل يمينًا (يخرج بت البدء أوَّلًا، ثم LSB إلى MSB من البيانات، ثم بت التوقُّف).
4. بعد التكَّة العاشرة، أنزل `busy` واترك `tx` خاملًا مرتفعًا.

## الهيكل

الـ entity وحالة الخمول مقدَّمتان؛ `tx` مرتفع بالافتراض، `busy` منخفض بالافتراض. كل ما بين هذه الافتراضات على عاتقك.

```vhdl
architecture rtl of uart_tx is
  signal tx_reg : std_logic := '1';
begin
  tx   <= tx_reg;
  busy <= '0';       -- TODO
end architecture rtl;
```

## بنية مقترحة

عدَّادان + سجل إزاحة:

```vhdl
signal clk_count  : unsigned(9 downto 0);   -- 0..434
signal bit_count  : unsigned(3 downto 0);   -- 0..9
signal shift_reg  : std_logic_vector(9 downto 0);
signal sending    : std_logic := '0';
```

- حين `send = '1'` و `sending = '0'`:
  - حمِّل `shift_reg <= '1' & data & '0';`
  - `sending <= '1';  clk_count <= 0;  bit_count <= 0;`
- ما دام `sending = '1'`:
  - `clk_count <= clk_count + 1;`
  - إذا `clk_count = BAUD_PERIOD - 1`:
    - `tx_reg <= shift_reg(0);`
    - `shift_reg <= '1' & shift_reg(9 downto 1);` — أزِح يمينًا، بطِّن الأعلى بالخمول
    - `bit_count <= bit_count + 1;`
    - `clk_count <= 0;`
  - إذا `bit_count = 10`:
    - `sending <= '0';`

اجعل `BAUD_PERIOD` generic كي تستطيع تقليصه للمحاكاة (مثلًا 5 دورات/بت) ويبقى نفس المنطق يعمل بسرعة كاملة على العتاد.

## ماذا تختبر

ادفع `send = '1'` بـ `data = "01001000"` (ASCII لـ `'H'`). بعد اكتمال الإطار، يجب أن يُظهر شكل موجة `tx` بالضبط 10 فترات بت من النشاط:

1. بدء (منخفض)
2. بت 0 من البيانات (LSB: `0`)
3. `0`
4. `0`
5. `1`
6. `0`
7. `0`
8. `1`
9. `0` (MSB)
10. توقُّف (مرتفع)

ثم العودة إلى خمول مرتفع. كبِّر في تبويب أشكال الموجة وتأكَّد من النمط بتًا بتًا.

## للمضي أبعد

- أضف **FIFO** كي تستطيع تكديس عدَّة بايتات؛ يصير `send` "دفع".
- ابنِ جانب **RX**: عيِّن كل بت وارد عند 1.5 × فترة البت، ثم عند 1 × بعدها.
- اجعل الإطار بارامتري: تكافؤ، 7 بت مقابل 8 بت، توقُّف 1 مقابل 2.
