# الجبر البولي والقوانين المهمة

الجبر البولي هو رياضيات القيم صواب/خطأ والعمليات التي يمكنك إجراؤها عليها. كل دائرة رقمية — من بوابة واحدة إلى CPU بمليون ترانزستور — هي في النهاية تعبير بولي.

الخبر الطيّب: لا تحتاج إلا إلى تذكّر حفنة قليلة من المتطابقات. بها تستطيع تبسيط أي تعبير تقريبًا يدويًا.

## العمليات الأساسية الثلاث

| العملية | الرمز (رياضي) | الرمز (VHDL) | تُقرأ |
|----|---------------|---------------|----------|
| AND | · أو تجاور | `and` | "A وB" |
| OR  | +          | `or`  | "A أو B" |
| NOT | شرطة عليا (`Ā`) | `not` | "نفي A" |

جداول الحقيقة للمعاملين الثنائيين:

```
 A  B  │  A·B   A+B
──────┼────────────
 0  0  │   0     0
 0  1  │   0     1
 1  0  │   0     1
 1  1  │   1     1
```

## المتطابقات التي ستستخدمها فعلًا

**الإبدالية** — الترتيب لا يهم:

```
A · B = B · A
A + B = B + A
```

**التجميعية** — التجميع لا يهم:

```
(A · B) · C = A · (B · C)
(A + B) + C = A + (B + C)
```

**التوزيعية** — تلك التي تبدو غريبة في حالة OR:

```
A · (B + C) = A·B + A·C
A + (B · C) = (A + B) · (A + C)   ← نعم، حقًا
```

**المحايد والهيمنة**:

```
A + 0 = A      A · 1 = A
A + 1 = 1      A · 0 = 0
```

**المتمم**:

```
A + Ā = 1      A · Ā = 0
```

**قانونا دي مورغان** — أنفع إعادتَي كتابة في التصميم الرقمي:

```
not(A · B) = Ā + B̄
not(A + B) = Ā · B̄
```

يتيح لك دي مورغان تحويل NAND إلى "OR للمتممات"، أو NOR إلى "AND للمتممات"، أو إلغاء شُرَط NOT الطويلة. كل سلسلة أدوات FPGA تستخدمهما باستمرار أثناء التحسين.

## تبسيط مشروح

ابدأ بـ:

```
Y = A·B + A·B̄·C + A·B̄·C̄
```

استخرج `A` من العامل المشترك:

```
Y = A · (B + B̄·C + B̄·C̄)
```

استخرج `B̄` من الداخل:

```
Y = A · (B + B̄ · (C + C̄))
```

`C + C̄ = 1` (متمم)، إذن:

```
Y = A · (B + B̄ · 1)
  = A · (B + B̄)
  = A · 1
  = A
```

أربعة حدود بخمس عمليات AND-OR تتقلّص إلى سلك. هذا نوع العمل الذي يقوم به المُجمِّع نيابةً عنك تلقائيًا — لكن فهمه يشحذ قراءتك لقائمة الشبكة الخاصة بشخص آخر.

## ما الذي يجب تذكره

- AND / OR / NOT كل ما تحتاج. NAND وNOR هما AND/OR مع NOT ملصقة.
- دي مورغان هو سكين الجيش السويسري — تعلّم كيف تتعرّف عليه في الاتجاهين.
- عندما يُقيَّم تعبير فرعي إلى `1` بالتمم، فإن الجداء كاملًا يُبسَّط.
