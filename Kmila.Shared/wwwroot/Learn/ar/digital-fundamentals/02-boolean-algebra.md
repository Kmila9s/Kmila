# جبر بُول والقوانين التي تهمّ

جبر بُول رياضيَّات قيم صحيح/خاطئ والعمليَّات التي تُجريها عليها. كل دائرة رقميَّة — من بوابة واحدة إلى معالج بمليون ترانزستور — هي في النهاية تعبير منطقي.

الخبر الجيد: تحتاج فقط حفنة من المتطابقات. بها تستطيع تبسيط أي تعبير تقريبًا يدويًّا.

## العمليَّات الأساسيَّة الثلاث

| العمليَّة | الرمز (رياضيًّا) | الرمز (VHDL) | تُقرأ |
|----------|-------------------|---------------|-------|
| AND     | · أو التجاور      | `and`         | «A و B» |
| OR      | +                 | `or`          | «A أو B» |
| NOT     | شرطة فوقيَّة (`Ā`)| `not`         | «ليس A» |

جداول الحقيقة للعاملَين الثنائيَّين:

```
 A  B  │  A·B   A+B
──────┼────────────
 0  0  │   0     0
 0  1  │   0     1
 1  0  │   0     1
 1  1  │   1     1
```

## المتطابقات التي ستستخدمها فعلًا

**الإبدال** — لا يهمُّ الترتيب:

```
A · B = B · A
A + B = B + A
```

**التجميع** — لا يهمُّ التجميع:

```
(A · B) · C = A · (B · C)
(A + B) + C = A + (B + C)
```

**التوزيع** — الذي يبدو غريبًا في حالة OR:

```
A · (B + C) = A·B + A·C
A + (B · C) = (A + B) · (A + C)   ← نعم، فعلًا
```

**التطابق والهيمنة**:

```
A + 0 = A      A · 1 = A
A + 1 = 1      A · 0 = 0
```

**التتميم**:

```
A + Ā = 1      A · Ā = 0
```

**قانونا دي مورغان** — أكثر إعادة كتابة فائدةً في التصميم الرقمي:

```
not(A · B) = Ā + B̄
not(A + B) = Ā · B̄
```

دي مورغان يُتيح لك تحويل NAND إلى «OR متمَّمَين»، أو NOR إلى «AND متمَّمَين»، أو إلغاء شرطات NOT طويلة. كل أدوات FPGA تستخدمه باستمرار خلال التحسين.

## تبسيط مُنفَّذ

ابدأ بـ:

```
Y = A·B + A·B̄·C + A·B̄·C̄
```

أخرج `A`:

```
Y = A · (B + B̄·C + B̄·C̄)
```

أخرج `B̄` داخليًّا:

```
Y = A · (B + B̄ · (C + C̄))
```

`C + C̄ = 1` (تتميم)، فإذن:

```
Y = A · (B + B̄ · 1)
  = A · (B + B̄)
  = A · 1
  = A
```

أربعة حدود بخمس عمليَّات AND-OR تنهار إلى سلك. هذا نوع العمل الذي يقوم به المُركِّب آليًّا — لكن فهمه يجعلك أكثر دقَّة في قراءة netlist شخص آخر.

## ما يجب تذكُّره

- AND / OR / NOT كل ما تحتاج. NAND و NOR هما AND/OR مع NOT مُلصَق.
- دي مورغان هو سكين الجيش السويسري — تعلَّم التعرُّف عليه في الاتجاهَين.
- حين يُقيَّم تعبير فرعي بـ `1` عبر التتميم، يُبسَّط كامل الجداء.
