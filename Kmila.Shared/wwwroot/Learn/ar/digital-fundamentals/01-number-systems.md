# الأنظمة العدديَّة: البتات، الست عشرية، المتمَّم الثنائي

الدوائر الرقميَّة لا تعرف «سبعة» — هي تعرف صفوفًا من المفاتيح إمَّا مفتوحة وإمَّا مغلقة. لتصمِّم بها، تحتاج راحة في التنقُّل بين التمثيل الذي يحبُّه البشر (العشري) والتمثيل الذي يفهمه السيليكون (الثنائي)، مع الست عشرية كاختصار مفيد في الوسط.

## الثنائي (الأساس 2)

**البت** قيمة منفردة on/off، تُكتب `0` أو `1`. **البايت** ثمانية بتات.

أكوام البتات تُرمِّز الأعداد الصحيحة موضعيًّا، تمامًا كالعشري — كل خانة قوَّة لاثنين:

```
  1 0 1 1 0
  │ │ │ │ └── 2⁰ = 1
  │ │ │ └──── 2¹ = 2
  │ │ └────── 2² = 0
  │ └──────── 2³ = 8
  └────────── 2⁴ = 16

  16 + 0 + 0 + 2 + 0 = 18
```

إذن `10110₂ = 18₁₀`.

## الست عشري (الأساس 16)

كتابة 32 بت بالثنائي تُعطيك حساءً من 32 حرفًا لا يستطيع أحد تدقيقه:

```
00000000 00000000 11001010 11111110
```

الست عشري يُجمِّع البتات أربعة-أربعة. كل خانة ست عشرية تُغطِّي نِبلًا واحدًا بالضبط (4 بتات)، فيصير 32 بت سلسلة أنيقة من 8 خانات:

```
0x0000CAFE
```

الخريطة ثابتة:

| bin  | hex | bin  | hex |
|------|-----|------|-----|
| 0000 | 0   | 1000 | 8   |
| 0001 | 1   | 1001 | 9   |
| 0010 | 2   | 1010 | A   |
| 0011 | 3   | 1011 | B   |
| 0100 | 4   | 1100 | C   |
| 0101 | 5   | 1101 | D   |
| 0110 | 6   | 1110 | E   |
| 0111 | 7   | 1111 | F   |

في VHDL ستكتب حرفيَّات ست عشرية لمتجهات طولها مضاعف للأربعة:

```vhdl
signal addr : std_logic_vector(7 downto 0) := x"CA";  -- 8 بت: 11001010
```

## المتمَّم الثنائي (الأعداد الصحيحة بإشارة)

الثنائي كما أعلاه يُرمِّز **الأعداد غير السالبة** فقط. لإدخال السالبة في النمط نفسه، يستخدم مصمِّمو الرقمي **المتمَّم الثنائي**:

1. اكتب العدد الموجب بالثنائي.
2. اقلب كل بت.
3. أضف 1.

لتمثيل `-5` في 8 بتات: `+5 = 00000101`، اقلب → `11111010`، +1 → `11111011`.

لماذا هذا الترميز؟ لأن الجمع يعمل على هيئة واحدة سواء بإشارة أم بدون — لا تحتاج جامعَين. `-5 + 7` بمتمَّم ثنائي 8 بت:

```
  11111011   (-5)
+ 00000111   ( 7)
-----------
 100000010
```

البت التاسع يفيض من القمَّة، والبتات الثمانية السفلى تساوي `00000010 = 2`. وهذا الجواب الصحيح.

## ما يجب تذكُّره

- البتات ذرَّات؛ البايتات مجموعات من 8.
- الثنائي والست عشري **نفس العدد** بجلدَين مختلفَين. الست عشري أيسر للقراءة.
- المتمَّم الثنائي يُرمِّز السوالب بقلب-وإضافة-واحد — ولهذا يعمل `A + B` في ALU بغضِّ النظر عن الإشارة.
