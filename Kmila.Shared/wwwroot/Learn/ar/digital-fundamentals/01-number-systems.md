# أنظمة الأرقام: البتات، السادس عشر، المتمم الثاني

الدوائر الرقمية لا تعرف "سبعة" — إنها تعرف صفوف مفاتيح إما مفتوحة أو مغلقة. للتصميم بها، ينبغي أن تكون مرتاحًا في التنقّل بين التمثيل الذي يحبّه البشر (العشري) والتمثيل الذي يفهمه السيليكون (الثنائي)، ومعهما النظام السادس عشر كاختصار مفيد في المنتصف.

## النظام الثنائي (الأساس 2)

**البت** قيمة واحدة مفتوحة/مغلقة، تُكتَب `0` أو `1`. **البايت** ثمانية بتات.

تُرمّز أكوام البتات الأعداد الصحيحة موضعيًا، تمامًا كالعشري — كل موضع قوة للعدد اثنين:

```
  1 0 1 1 0
  │ │ │ │ └── 2⁰ = 1
  │ │ │ └──── 2¹ = 2
  │ │ └────── 2² = 0
  │ └──────── 2³ = 8
  └────────── 2⁴ = 16

  16 + 0 + 0 + 2 + 0 = 18
```

إذن `10110₂ = 18₁₀`.

## النظام السادس عشر (الأساس 16)

كتابة 32 بتًا في الثنائي تعطيك حساءً من 32 محرفًا لا يستطيع أحد تدقيقه:

```
00000000 00000000 11001010 11111110
```

يجمع النظام السادس عشر البتات أربعة أربعة. كل رقم سادس عشري يغطي بالضبط نبلًا واحدًا (4 بتات)، فتصبح 32 بتًا سلسلة مرتبة من 8 محارف:

```
0x0000CAFE
```

المقابلة ثابتة:

| bin  | hex | bin  | hex |
|------|-----|------|-----|
| 0000 | 0   | 1000 | 8   |
| 0001 | 1   | 1001 | 9   |
| 0010 | 2   | 1010 | A   |
| 0011 | 3   | 1011 | B   |
| 0100 | 4   | 1100 | C   |
| 0101 | 5   | 1101 | D   |
| 0110 | 6   | 1110 | E   |
| 0111 | 7   | 1111 | F   |

في VHDL ستكتب ثوابت سادسة عشرية لمتجهات طولها من مضاعفات الأربعة:

```vhdl
signal addr : std_logic_vector(7 downto 0) := x"CA";  -- 8 bits: 11001010
```

## المتمم الثاني (الأعداد الصحيحة المُوقَّعة)

الثنائي كما هو معروض أعلاه يرمّز الأعداد **غير السالبة** فقط. لإدخال الأعداد السالبة في نمط البتات نفسه، يستخدم مصممو الدوائر الرقمية **المتمم الثاني**:

1. اكتب العدد الموجب في الثنائي.
2. اقلب كل بت.
3. أضف 1.

لتمثيل `-5` في 8 بتات: `+5 = 00000101`، اقلب → `11111010`، أضف 1 → `11111011`.

لماذا هذا المخطط؟ لأن الجمع يعمل بصورة متطابقة سواء كانت الأعداد مُوقَّعة أم لا — لا تحتاج إلى جامعَين. `-5 + 7` بالمتمم الثاني 8 بت:

```
  11111011   (-5)
+ 00000111   ( 7)
-----------
 100000010
```

يفيض البت التاسع خارج القمة، والـ 8 السفلى هي `00000010 = 2`. وهي الإجابة الصحيحة.

## ما الذي يجب تذكره

- البتات هي الذرات؛ البايتات مجموعات من 8.
- الثنائي والسادس عشر هما **الرقم نفسه** بقشرتين مختلفتين. السادس عشر أسهل للقراءة.
- يرمّز المتمم الثاني السوالب بقلب البتات وإضافة واحد — وهو السبب في أن `A + B` في ALU الخاصة بك تعمل بصرف النظر عن الإشارة.
